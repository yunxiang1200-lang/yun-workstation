精选真题演练

第1题（单选题） 根据索洛增长模型，在长期中，人均产出增长的主要来源是：

A. 资本积累

B. 劳动投入增加

C. 技术进步

D. 人口增长

【答案解析】

在索洛模型中，当经济达到稳态时：

  • 资本积累只影响人均产出的水平效应，不影响增长率
  • 只有技术进步才能推动人均产出的持续增长
  • 劳动增加和人口增长只会影响总产出规模，长期中人均产出增长率取决于技术进步率

正确答案：C

第2题（多选题） 关于汇率变动对经济的影响，以下说法正确的有：

A. 本币升值有利于进口，不利于出口

B. 本币贬值会改善国际收支（满足马歇尔-勒纳条件）

C. 本币升值会引发输入性通货膨胀

D. 汇率变动会影响资本流动

E. 本币贬值有利于偿还外债

【答案解析】

  • A正确：本币升值使进口商品变得更便宜，出口商品变得更贵
  • B正确：在马歇尔-勒纳条件（进出口需求弹性之和大于1）下，本币贬值可以改善贸易收支
  • C错误：本币贬值会引发输入性通货膨胀（进口商品价格上升），而非升值
  • D正确：汇率变动影响国内外资产的相对吸引力，从而影响资本流动
  • E错误：本币贬值使得偿还外债成本上升（需要更多本币兑换外币）

正确答案：ABD

第3题（简答题） 比较绝对优势理论与比较优势理论的主要内容与区别。

【答案要点】

绝对优势理论（亚当·斯密）：

  • 各国生产具有绝对成本优势（即生产效率绝对高于其他国家）的产品，然后进行交换
  • 每个国家都出口自己生产成本绝对低于其他国家的产品，进口自己生产成本绝对高于其他国家的产品

比较优势理论（大卫·李嘉图）：

  • 即使一国在所有产品的生产上都处于绝对劣势，仍然可以通过专门生产比较成本较低（即相对优势）的产品参与国际贸易并获益
  • 比较优势的基础是各国之间的相对劳动生产率差异

主要区别：

比较项目绝对优势理论比较优势理论
贸易基础绝对成本差异相对成本差异
适用范围一方有绝对优势时即使一方全面劣势仍可贸易
理论贡献论证自由贸易的好处更一般化的国际贸易理论基础
局限性无法解释无绝对优势时的贸易过于简化（仅考虑劳动一种要素）

【贵州高频考点提示】 比较优势理论是贵州历年考试的高频考点，常以简答题出现。一定要记住："两优相权取其重，两劣相权取其轻"这一核心思想。

第4题（计算题） 假设某国货币供给量 M = 500亿元，名义GDP为 4000亿元，实际GDP为 3200亿元。

求：

（1）货币流通速度（V）；

（2）价格水平（P）；

（3）根据费雪交易方程，如果货币供给量增加到 600亿元，在短期内（V和实际GDP不变），新的价格水平是多少？通货膨胀率是多少？

【解题步骤】

（1）求货币流通速度：

费雪交易方程：MV = PY

V = PY/M = 4000/500 = 8（次/年）

（2）求价格水平：

P = 名义GDP/实际GDP = 4000/3200 = 1.25

（3）新价格水平与通货膨胀率：

当 M = 600，V = 8，实际GDP（Y）= 3200 不变时：

PY = MV = 600 × 8 = 4800

新价格水平 P' = 4800/3200 = 1.5

通货膨胀率 = (1.5 - 1.25)/1.25 × 100% = 0.25/1.25 × 100% = 20%

结论： 货币供给量增加20%（从500到600），在货币流通速度和实际GDP不变的情况下，价格水平从1.25上升到1.5，通货膨胀率为20%。

第5题（简答题） 简述凯恩斯流动性偏好理论中货币需求的三大动机。

【答案要点】

凯恩斯认为，人们持有货币（流动性偏好）基于三大动机：

  • 交易动机
  • 为满足日常交易需要而持有货币
  • 与收入水平正相关：收入越高，交易需求越大
  • 公式：L₁ = L₁(Y)，L₁' > 0
  • 预防动机（谨慎动机）
  • 为应对意外支出而持有货币
  • 也与收入水平正相关
  • 凯恩斯将交易动机和预防动机合并为：L₁ = kY（k为持币系数）
  • 投机动机
  • 为获取投机收益（如低价买入债券）而持有货币
  • 与利率水平负相关：利率越低，持有货币的成本越低，投机性货币需求越大
  • 公式：L₂ = L₂(r)，L₂' < 0

货币总需求函数：

L = L₁(Y) + L₂(r) = kY - hr（其中k>0，h>0）

流动性陷阱： 当利率降至极低水平时，投机性货币需求趋于无穷大，货币政策失效。

精选真题演练

第1题（单选题） 中位选民定理认为，在多数票决制下，最终的投票结果将反映：

A. 全体选民的平均偏好

B. 中位选民的偏好

C. 极端选民的偏好

D. 利益集团的偏好

【答案解析】

中位选民定理（Median Voter Theorem）是公共选择理论中的重要内容。在单一议题的多数票决中，投票结果将倾向于反映中位选民（偏好处于中间位置的选民）的偏好。这是因为：

  • 任何偏离中位选民偏好的方案在投票中都会输给更接近中位选民偏好的方案
  • 这一结论对于理解两党竞争趋同、公共支出水平决定等有重要意义

正确答案：B

第2题（单选题） 寻租行为与以下哪项最直接相关：

A. 企业通过创新获取利润

B. 企业通过提高效率降低成本

C. 企业通过游说政府获取垄断特权

D. 企业通过广告扩大市场份额

【答案解析】

寻租（Rent-seeking）是指个人或企业通过非生产性活动（如游说政府、贿赂官员）来获取特殊利益或垄断地位的行为。与生产者剩余或消费者剩余的重新分配有关，不创造新的社会财富，反而会造成社会福利损失。

  • A和B属于寻利行为（创造价值的活动）
  • C属于典型的寻租行为
  • D属于正常的企业营销活动

正确答案：C

第3题（名词解释） 投票悖论

【答案要点】

投票悖论（又称"孔多塞悖论"）是指在使用多数票决制进行集体决策时，可能会出现循环投票（投票结果不一致）的现象。

产生条件： 选民的偏好呈现多峰偏好（非单峰偏好）时。

举例说明： 三个选民对三个方案A、B、C的偏好排序：

  • 选民1：A > B > C
  • 选民2：B > C > A
  • 选民3：C > A > B

两两投票时：A胜B、B胜C、C胜A，形成循环，无法确定最终胜者。

投票悖论揭示了民主投票制度的内在缺陷——多数规则下不一定能产生一致的结果。

第4题（多选题） 以下属于社会性规制范畴的有：

A. 环境保护标准

B. 食品安全规定

C. 药品安全审批

D. 行业进入门槛限制

E. 劳动安全保护

【答案解析】

政府规制分为两大类：

  • 经济性规制：针对特定行业的价格、进入、退出等，如D选项
  • 社会性规制：以保障公众健康、安全、环境为目的，跨行业的规制

社会性规制的主要领域包括：

  • A：环境保护（控制污染排放）
  • B：食品安全（制定质量标准）
  • C：药品安全（新药审批）
  • E：劳动安全（工作场所安全标准）

D选项（行业进入门槛限制）属于经济性规制，而非社会性规制。

正确答案：ABCE

第5题（简答题） 简述规制俘获理论的主要内容及其政策含义。

【答案要点】

规制俘获理论（Regulatory Capture Theory）认为，政府规制机构在运行过程中，可能会被被规制行业"俘获"，即规制机构最终为被规制行业的利益服务，而非维护公共利益。

主要内容：

  • 规制机构与被规制行业之间存在信息不对称：行业比规制机构更了解自身情况
  • 利益集团的集中优势：被规制行业的利益集中，有强烈动机影响规制决策；而消费者利益分散，组织成本高
  • "旋转门"现象：规制官员可能来自或将来去被规制企业，导致规制偏向行业利益
  • 规制者与被规制者的合谋：长期互动中，规制者可能与被规制者形成利益共同体

政策含义：

  • 应强化规制机构的独立性和透明度
  • 建立规制过程的公众参与机制
  • 实施规制绩效评估和定期审查
  • 引入竞争机制，减少对单一规制手段的依赖
  • 加强媒体监督和司法审查

经济学原理答案

第1题：A —— G = s/v（s为储蓄率，v为资本-产出比）。（1分）

第2题：C —— 马歇尔-勒纳条件满足时，本币贬值改善贸易收支。D选项是J曲线效应的描述。（1分）

第3题（计算题，8分）：

（1）P = MV/Y = 800×5/2000 = 4000/2000 = 2.0 （3分）

（2）新价格水平 P' = M'V/Y' = 1000×5/2200 = 5000/2200 ≈ 2.27

通货膨胀率 = (2.27 - 2.0)/2.0 × 100% = 0.27/2.0 × 100% = 13.5% （5分）

第4题（简答题，6分）：

托宾q理论：由詹姆斯·托宾提出，q = 企业市场价值/企业资本重置成本。

  • q > 1：企业市场价值高于重置成本，投资新资本品有利，应增加投资
  • q < 1：企业市场价值低于重置成本，通过收购现有企业比投资新资本更划算，应减少投资
  • q = 1：达到均衡

政策启示：q值反映了金融市场对实体投资的引导作用，货币政策可以通过影响股价（从而影响q值）来调节投资。（6分）

第5题（简答题，6分）：

生命周期假说（莫迪利安尼）认为，理性消费者会根据一生的总收入来安排消费，以实现一生消费效用的最大化。（2分）

核心观点：

  • 青年时期：收入低但预期未来收入增长，可能借贷消费
  • 中年时期：收入高，一方面偿还青年时期债务，另一方面为退休储蓄
  • 老年时期：收入下降，动用储蓄进行消费

政策含义：

  • 养老保障制度的重要性——帮助个人实现跨期平滑消费
  • 人口年龄结构影响社会总储蓄率——年轻人口多则储蓄率低，中年人口多则储蓄率高
  • 税收政策应考虑不同年龄段的消费-储蓄行为差异 （4分）

第5题（简答题，6分）：

单峰偏好：选民对各个方案的偏好排序呈"单峰"形状，即存在一个最优方案，越远离该方案偏好越低。（2分）

多峰偏好：选民对方案的偏好有两个或以上的峰值，即中间某个方案偏好降低，两边方案偏好升高。（2分）

与投票悖论的关系：

  • 当所有选民的偏好都是单峰偏好时，多数票决可以产生一致的投票结果，不会出现投票悖论
  • 当存在多峰偏好时，可能出现投票循环（投票悖论）
  • 因此，单峰偏好是避免投票悖论的充分条件 （2分）

高频错题总结

  • 索洛模型中技术进步的作用：长期人均产出增长只能来自技术进步，不是资本积累
  • 马歇尔-勒纳条件 vs J曲线效应：前者是条件（进出口弹性之和>1），后者是时间路径（先恶化后改善），两者不是一回事
  • 费雪方程 MV=PY：货币流通速度V在短期可视为常数，这是货币数量论的核心假设
  • 寻租 vs 寻利：寻租是非生产性活动，寻利是生产性活动，两者有本质区别
  • 投票悖论与多峰偏好：这是一个高频考点，要记住多峰偏好导致投票悖论

答题技巧提示

  • 模型类题目：回答模型名称+基本假设+核心公式+结论（四步法）
  • 比较类题目：先说A是什么，再说B是什么，再用表格对比
  • 理论应用类题目：理论内容+举例说明+现实意义（三步法）
  • 计算题检查：计算完后回代验证，如果结果不满足均衡条件说明算错了

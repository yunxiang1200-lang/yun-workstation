精选真题演练

第1题（单选题） 假设某商品的需求价格弹性为 1.8，当价格下降 5% 时，需求量将：

A. 增加 5%

B. 减少 5%

C. 增加 9%

D. 减少 9%

【答案解析】

需求价格弹性公式：Ed = (ΔQ/Q) / (ΔP/P)

已知 Ed = 1.8，ΔP/P = -5%（价格下降），则：

(ΔQ/Q) / (-5%) = 1.8

ΔQ/Q = 1.8 × (-5%) = -9%

由于弹性为正值（绝对值），实际需求量的变化方向与价格变化方向相反，即需求量 增加 9%。

正确答案：C

第2题（多选题） 以下关于无差异曲线的表述中，正确的有：

A. 无差异曲线是一条向右下方倾斜的曲线

B. 同一平面内任意两条无差异曲线可以相交

C. 无差异曲线凸向原点

D. 无差异曲线的斜率等于边际替代率

E. 无差异曲线离原点越远，代表的效用水平越高

【答案解析】

  • A正确：无差异曲线向右下方倾斜，斜率为负，表明减少一种商品消费需要增加另一种商品来维持效用不变。
  • B错误：同一平面内任意两条无差异曲线不能相交，这是无差异曲线的基本性质。
  • C正确：无差异曲线凸向原点，反映边际替代率递减规律。
  • D正确：无差异曲线上某点切线的斜率绝对值等于该点的边际替代率（MRS）。
  • E正确：离原点越远的无差异曲线代表的效用水平越高。

正确答案：ACDE

第3题（简答题） 请简述边际报酬递减规律的内容及其成立的前提条件。

【答案要点】

边际报酬递减规律是指在短期生产中，在技术水平不变的条件下，连续等量地增加某一种可变生产要素的投入量，当这种可变要素的投入量小于某一特定值时，增加该要素投入所带来的边际产量是递增的；当这种可变要素的投入量连续增加并超过这一特定值时，继续增加该要素投入所带来的边际产量是递减的。

成立的前提条件：

  • 技术水平不变——如果技术进步，边际报酬递减可能被推迟甚至抵消
  • 其他生产要素投入量保持不变——只有一种要素投入量可变
  • 要素是同质的——每一次增加的生产要素在质量上没有差异

【贵州高频考点提示】 边际报酬递减规律几乎是每年必考内容，通常以简答题或计算题形式出现，需要准确记忆定义和三个前提条件。

第4题（计算题） 已知某完全竞争企业的短期成本函数为：TC = Q³ - 12Q² + 60Q + 100（其中TC为总成本，Q为产量）。

求：

（1）该企业的平均成本（AC）函数、平均可变成本（AVC）函数和边际成本（MC）函数；

（2）当市场价格为 P = 60 时，该企业的最优产量是多少？此时企业是否盈利？

【解题步骤】

（1）成本函数的推导：

  • 总成本：TC = Q³ - 12Q² + 60Q + 100
  • 固定成本：FC = 100（常数项）
  • 可变成本：VC = Q³ - 12Q² + 60Q

平均成本 AC = TC/Q = Q² - 12Q + 60 + 100/Q

平均可变成本 AVC = VC/Q = Q² - 12Q + 60

边际成本 MC = dTC/dQ = 3Q² - 24Q + 60

（2）最优产量的确定：

完全竞争企业利润最大化的条件是：P = MC

60 = 3Q² - 24Q + 60

3Q² - 24Q = 0

3Q(Q - 8) = 0

解得：Q₁ = 0（舍去），Q₂ = 8

当 Q = 8 时：

AC = 8² - 12×8 + 60 + 100/8 = 64 - 96 + 60 + 12.5 = 40.5

利润 π = (P - AC) × Q = (60 - 40.5) × 8 = 19.5 × 8 = 156

结论： 该企业最优产量为 8单位，此时企业获得经济利润156元。

第5题（简答题） 请比较完全竞争市场与垄断市场在长期均衡时的异同点。

【答案要点】

比较项目完全竞争市场垄断市场
均衡条件P = MR = MC = ACMR = MC, P > MC
价格水平价格最低，等于最低AC价格较高
产量水平在AC最低点生产，产量最大产量小于完全竞争市场
经济利润长期经济利润为零可获得长期正经济利润
生产效率达到生产效率（P=AC最低点）未达到生产效率
资源配置效率达到帕累托最优（P=MC）资源配置不足（P>MC）

相同点： 两种市场结构下，企业长期均衡的条件都满足 MR = MC，且都按此条件决定产量。

精选真题演练

第1题（单选题） 下列哪项属于纯公共物品的特征？

A. 竞争性和排他性

B. 非竞争性和排他性

C. 竞争性和非排他性

D. 非竞争性和非排他性

【答案解析】

纯公共物品同时具有两个基本特征：

  • 非竞争性：某人对该物品的消费不会减少其他人可消费的数量，即增加一个消费者的边际成本为零。
  • 非排他性：无法将不付费者排除在消费之外，或排他成本过高。

正确答案：D

第2题（单选题） 当存在负外部性时，市场均衡产量与最优产量之间的关系是：

A. 市场均衡产量等于最优产量

B. 市场均衡产量大于最优产量

C. 市场均衡产量小于最优产量

D. 两者关系不确定

【答案解析】

负外部性（如污染）意味着私人成本 < 社会成本。企业在决策时只考虑私人成本，导致产量过多。从社会角度看，市场均衡产量大于社会最优产量。需要政府通过征税等方式将外部成本内部化。

正确答案：B

第3题（名词解释） 帕累托最优

【答案要点】

帕累托最优是指资源配置的一种理想状态，即在不使任何人境况变坏的前提下，不可能再使某些人的处境变好。换句话说，如果经济中任何重新配置都不能在至少使一个人状况变好的同时而不使其他人状况变坏，则这种配置就是帕累托最优的。

帕累托改进：如果某种资源配置的改变能够在至少使一个人状况变好的同时而不使其他人状况变坏，则这种改变称为帕累托改进。

帕累托最优是衡量资源配置效率的重要标准，也是公共经济学分析政府干预必要性的理论基础。

第4题（多选题） 政府干预经济的主要理由包括：

A. 解决市场失灵问题

B. 实现收入再分配

C. 提供公共物品

D. 取代市场进行所有资源配置

E. 纠正外部性

【答案解析】

  • A正确：市场失灵是政府干预的核心原因
  • B正确：市场机制本身可能导致收入分配不公，需要政府干预
  • C正确：公共物品因非竞争性和非排他性，市场无法有效提供
  • D错误：政府不应取代市场进行所有资源配置，应尊重市场在资源配置中的决定性作用
  • E正确：外部性是市场失灵的重要表现，需要政府纠正

正确答案：ABCE

第5题（简答题） 简述市场失灵的主要表现及其与政府干预的关系。

【答案要点】

市场失灵是指市场机制在某些领域不能或不能有效地实现资源最优配置的现象。

主要表现：

  • 公共物品：非竞争性和非排他性导致搭便车问题，市场供给不足
  • 外部性：私人成本与社会成本、私人收益与社会收益不一致
  • 信息不对称：交易双方掌握的信息不对等，导致逆向选择和道德风险
  • 垄断：垄断定价导致产量过低、价格过高，损害资源配置效率
  • 收入分配不公：市场分配结果可能与社会公平目标相矛盾

与政府干预的关系：

  • 市场失灵为政府干预提供了理论基础
  • 政府通过提供公共物品、征税补贴、反垄断、信息监管、收入再分配等手段弥补市场缺陷
  • 但要注意政府也可能失灵，因此需要在市场与政府之间寻求平衡

经济学原理答案

第2题：B —— 当MP > AP时，AP处于上升阶段。（1分）

第3题（计算题，8分）：

（1）消费者均衡条件：MUx/Px = MUy/Py

MUx = ∂U/∂X = Y

MUy = ∂U/∂Y = X

均衡：Y/10 = X/20，即 Y = 0.5X

预算约束：10X + 20Y = 100

代入：10X + 20×(0.5X) = 10X + 10X = 20X = 100

X = 5，Y = 2.5 （5分）

（2）最大效用：U = 5 × 2.5 = 12.5 （3分）

第4题（简答题，6分）：

需求价格弹性的5种类型：

  • Ed > 1（富有弹性）：价格变动1%，需求量变动超过1%
  • Ed = 1（单位弹性）：需求量变动百分比等于价格变动百分比
  • Ed < 1（缺乏弹性）：需求量变动百分比小于价格变动百分比
  • Ed = ∞（完全弹性）：价格微小变动引起需求量无限变动
  • Ed = 0（完全无弹性）：无论价格如何变动，需求量不变

定价启示： 对于富有弹性的商品，降价可以增加总收益；对于缺乏弹性的商品，涨价可以增加总收益。（6分）

第5题（简答题，6分）：

机会成本是指为了得到某种东西而必须放弃的其他东西的最大价值。（2分）

举例：如某人选择上大学，其机会成本包括学费、书本费等直接支出，以及因上学而放弃的四年工作收入。（4分）

第3题（名词解释，3分）：

公共物品是指具有非竞争性和非排他性的物品。非竞争性指增加一个消费者的边际成本为零；非排他性指无法将不付费者排除在消费之外。典型的公共物品有国防、灯塔、基础研究等。

第4题（简答题，6分）：

科斯定理的核心思想：在产权明晰且交易成本为零的条件下，无论初始产权如何分配，当事人都可以通过协商实现资源的最优配置，无需政府干预。（3分）

在外部性问题的应用中，科斯定理表明可以通过明确产权归属来解决外部性问题，如明确污染权或清洁空气权，由市场双方自行协商解决。但现实中交易成本往往较大，限制了科斯定理的适用性。（3分）

第5题（简答题，6分）：

  • 政府失灵：政府决策可能受利益集团影响，效率低下

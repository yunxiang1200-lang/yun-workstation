精选真题演练

第1题（单选题） 在国民收入核算中，用支出法计算GDP时，以下哪项不包括在内？

A. 消费支出（C）

B. 投资支出（I）

C. 政府转移支付

D. 净出口（NX）

【答案解析】

支出法GDP的计算公式为：GDP = C + I + G + NX

  • C：居民消费支出
  • I：企业投资支出（包括固定资产投资和存货投资）
  • G：政府购买支出（注意：不是政府支出总额）
  • NX：净出口（出口减进口）

政府转移支付（如社会保障、失业救济金）不计入GDP，因为转移支付只是资金从政府转移到个人手中，没有对应的商品或劳务产出。

正确答案：C

第2题（多选题） 关于乘数效应，以下表述正确的有：

A. 投资乘数等于1/(1-MPC)

B. 边际消费倾向（MPC）越大，乘数越大

C. 乘数效应只在经济存在闲置资源时才能充分发挥

D. 政府购买支出乘数等于税收乘数

E. 乘数效应是一把"双刃剑"

【答案解析】

  • A正确：投资乘数 = ΔY/ΔI = 1/(1-MPC)
  • B正确：MPC越大，分母1-MPC越小，乘数越大
  • C正确：乘数效应的发挥取决于经济中是否存在闲置资源
  • D错误：政府购买支出乘数 = 1/(1-MPC)，而税收乘数 = -MPC/(1-MPC)，两者不同
  • E正确：乘数效应既可能放大经济扩张，也可能放大经济收缩

正确答案：ABCE

第3题（计算题） 已知某三部门经济中，消费函数为 C = 100 + 0.8Yd（Yd为可支配收入），投资 I = 50，政府购买支出 G = 100，税收函数 T = 50 + 0.25Y，转移支付 TR = 20。

求：

（1）均衡国民收入 Y；

（2）投资乘数、政府购买支出乘数和税收乘数；

（3）若充分就业国民收入为 Yf = 800，此时经济中存在什么缺口？应如何调整政府购买支出？

【解题步骤】

（1）求均衡国民收入：

可支配收入：Yd = Y - T + TR = Y - (50 + 0.25Y) + 20 = 0.75Y - 30

消费函数：C = 100 + 0.8Yd = 100 + 0.8×(0.75Y - 30) = 100 + 0.6Y - 24 = 76 + 0.6Y

三部门经济均衡条件：Y = C + I + G

Y = (76 + 0.6Y) + 50 + 100

Y = 226 + 0.6Y

0.4Y = 226

Y = 565

（2）求各乘数：

MPC = 0.8，边际税率 t = 0.25

投资乘数 KI = 1/[1 - MPC(1-t)] = 1/[1 - 0.8×(1-0.25)]

= 1/[1 - 0.8×0.75] = 1/(1 - 0.6) = 1/0.4 = 2.5

政府购买支出乘数 KG = KI = 2.5

税收乘数 KT = -MPC/[1 - MPC(1-t)] = -0.8/0.4 = -2

（3）缺口分析：

Yf = 800，Y = 565，存在 通货紧缩缺口（也称为紧缩缺口），缺口大小为：

ΔY = 800 - 565 = 235

应增加政府购买支出：ΔG = ΔY/KG = 235/2.5 = 94

即政府需要增加 94单位的购买支出以消除紧缩缺口，实现充分就业。

第4题（简答题） 简述通货膨胀的三种类型及其成因。

【答案要点】

按照通货膨胀率的高低，可分为三种类型：

  • 爬行式通货膨胀（温和通货膨胀）
  • 通货膨胀率在 10%以下
  • 物价上涨缓慢、温和
  • 对经济影响较小，甚至可能对经济有一定的刺激作用
  • 奔腾式通货膨胀（加速通货膨胀）
  • 通货膨胀率在 10%-100%
  • 物价上涨速度明显加快
  • 对经济造成较大负面影响，人们开始囤积商品
  • 恶性通货膨胀（超级通货膨胀）
  • 通货膨胀率在 100%以上，甚至高达数千%
  • 物价急剧上涨，货币严重贬值
  • 可能导致货币体系崩溃和经济秩序瓦解
  • 典型案例：20世纪20年代德国、2008年津巴布韦

【贵州高频考点提示】 贵州历年常考通货膨胀的类型及其对经济的影响，特别是恶性通货膨胀的特征和后果。

第5题（简答题） 简述IS曲线的含义及其斜率的影响因素。

【答案要点】

IS曲线（Investment-Saving Curve）表示产品市场达到均衡（即投资等于储蓄）时，利率与国民收入之间关系的曲线。IS曲线向右下方倾斜，表明利率与国民收入呈反向变动关系：利率下降，投资增加，国民收入增加。

IS曲线斜率的影响因素：

  • 投资对利率的敏感度（d）：d越大，利率变动对投资的影响越大，IS曲线越平坦
  • 边际消费倾向（MPC）：MPC越大，乘数越大，IS曲线越平坦
  • 边际税率（t）：t越大，乘数越小，IS曲线越陡峭

IS曲线的移动：

  • 扩张性财政政策（增加政府购买或减税）使IS曲线右移
  • 紧缩性财政政策（减少政府购买或增税）使IS曲线左移

第1题（单选题） 以下物品中，最接近纯公共物品的是：

A. 高速公路

B. 国防

C. 公共电影院

D. 医疗保险

【答案解析】

  • 国防同时具备非竞争性（多保护一个人边际成本为零）和非排他性（无法将任何公民排除在国防保护之外），是纯公共物品的典型例子
  • 高速公路在非拥堵时接近公共物品，但可通过收费站实现排他，属于准公共物品/俱乐部物品
  • 公共电影院具有竞争性（座位有限），属于公共资源
  • 医疗保险具有竞争性和排他性，属于私人物品

正确答案：B

第2题（单选题） 关于科斯定理，以下说法正确的是：

A. 只要产权明晰，无论交易成本多大，都能实现资源最优配置

B. 科斯定理否定了政府干预的必要性

C. 在产权明晰且交易成本为零时，私人协商可以解决外部性问题

D. 科斯定理适用于所有公共物品的供给

【答案解析】

  • A错误：科斯定理要求交易成本为零
  • B错误：科斯定理只是说明在特定条件下可以通过私人协商解决外部性问题，并不完全否定政府干预，而且现实中交易成本通常为正
  • C正确：这是科斯定理的核心内容
  • D错误：科斯定理主要适用于外部性问题，对纯公共物品的效果有限

正确答案：C

第3题（名词解释） 搭便车问题

【答案要点】

搭便车问题是指某些人虽然消费了公共物品，但没有为此付费，试图让他人承担成本的现象。

在公共物品的消费中，由于公共物品具有非排他性，无法阻止不付费者的消费行为，导致理性的个体都有"搭便车"的动机。如果所有人都不付费，公共物品就无法通过市场机制有效供给。

解决方法：

  • 政府直接提供：通过税收筹集资金
  • 强制缴费：如电视收视费
  • 将公共物品转化为准公共物品：通过技术手段增加排他性

第4题（多选题） 解决负外部性的政府干预措施包括：

A. 征收庇古税

B. 发放可交易的排污许可证

C. 制定排污标准

D. 对污染企业进行罚款

E. 对受影响者提供补贴

【答案解析】

  • A正确：庇古税是解决负外部性的经典方法，通过对污染企业征税使其私人成本等于社会成本
  • B正确：可交易的排污许可证通过市场机制控制总排污量，是一种基于市场的激励型工具
  • C正确：排污标准是命令-控制型的直接管制措施
  • D正确：罚款是对违规排放的惩戒措施
  • E正确：对受影响者补贴也是一种间接的解决方式

正确答案：ABCDE

第5题（简答题） 比较公共物品和私人物品的区别，并说明市场在提供公共物品时为什么会出现失灵。

【答案要点】

区别：

特征公共物品私人物品
竞争性非竞争性（增加消费的MC=0）竞争性（增加消费需要增加成本）
排他性非排他性（无法阻止他人消费）排他性（可以阻止不付费者消费）
消费方式共同消费个人消费
供给方式政府提供为主市场供给为主
典型例子国防、灯塔面包、衣服

市场失灵的原因：

  • 搭便车行为：消费者隐藏真实偏好，不付费也享受收益
  • 偏好显示问题：无法通过市场价格信号了解公共物品的真实需求
  • 供给不足：私人部门以利润最大化为目标，而公共物品成本高、收益低
  • "公地悲剧"：公共资源的过度使用导致资源耗竭

因此，纯公共物品往往需要政府承担供给责任，通过税收筹集资金来提供。

第5题（简答题，6分）：

挤出效应是指政府支出增加导致利率上升，从而挤占私人投资的现象。（2分）

影响因素：

  • 投资对利率的敏感度：越敏感，挤出效应越大
  • 货币需求对利率的敏感度：越敏感，挤出效应越小
  • 边际消费倾向：MPC越大，乘数越大，挤出效应的相对影响较小

第3题（名词解释，3分）：

庇古税是英国经济学家庇古提出的解决负外部性的税收手段。其核心思想是：对造成负外部性的企业征税，税额等于边际外部成本，使私人成本等于社会成本，从而将外部成本内部化。庇古税也常被称为"矫正税"。

第4题（简答题，6分）：

萨缪尔森条件（公共物品有效供给条件）：当公共物品与私人物品的边际替代率之和等于公共物品的边际转换率时，公共物品达到最优供给水平。

用公式表示：∑MRS = MRT

  • ∑MRS：所有消费者对公共物品与私人物品的边际替代率之和（即所有消费者从公共物品中获得的边际收益之和）
  • MRT：将私人物品转化为公共物品的边际转换率（即生产的边际成本）

这意味着公共物品的总收益应该等于其总成本。（6分）

第5题（简答题，6分）：

行政性垄断是指政府及其所属部门滥用行政权力，限制或排斥公平竞争的行为。（2分）

对社会福利的影响：

  • 资源配置效率低下：垄断导致产量减少、价格提高，消费者剩余减少
  • X-非效率：缺乏竞争压力导致企业成本控制松懈
  • 寻租行为：企业花费资源争取和维护垄断地位，造成社会福利净损失
  • 抑制创新：缺乏竞争导致技术进步和创新动力不足
  • 收入分配不公：垄断利润向少数人集中 （4分，答出3点得满分）

高频错题总结

  • GDP与GNP的区分：一个看"地域"，一个看"国籍"，历年贵州考题中出现过3次以上
  • 乘数计算中税收的作用：有税收时乘数 = 1/[1-MPC(1-t)]，很多同学漏掉t
  • IS曲线斜率：投资对利率敏感度d越大，IS越平坦——与LM曲线正好相反
  • 公共物品与非竞争性：非竞争性是指增加一个消费者的边际成本为零，不是平均成本为零
  • 庇古税 vs 科斯定理：一个主张政府干预（征税），一个主张市场解决（产权），注意区分

答题技巧提示

  • 计算题步骤化：即使不会算，也要把均衡条件Y=C+I+G写出来，能得步骤分
  • 名词解释"三要素"法：定义 + 特征 + 例子（每个名词解释都按这个模式回答）
  • 简答题"要点化"：用序号列出要点，每个要点一句核心句+一句展开
  • 比较题的回答模式：先分别说A和B各自是什么，再列表比较异同
  • 菲利普斯曲线注意区分短期和长期：短期负相关，长期不存在替代关系

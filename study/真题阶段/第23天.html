31. 边际效用递减规律：在一定时间内，在其他商品消费量不变的条件下，消费者连续消费某商品所获得的边际效用随消费量的增加而递减。启示：消费者应合理分配收入，使花在每种商品上的最后一元钱带来的边际效用相等（等边际原则）。（6分）

32. 货币政策传导机制：

  • 利率渠道：M↑→r↓→I↑→Y↑
  • 信贷渠道：M↑→银行贷款↑→投资和消费↑→Y↑
  • 资产价格渠道：M↑→股价↑→q↑→投资↑→Y↑
  • 汇率渠道：M↑→r↓→本币贬值→NX↑→Y↑ （答出3条得满分6分）

33. 要素禀赋理论（H-O理论）：各国应出口密集使用其丰裕要素生产的产品，进口密集使用其稀缺要素生产的产品。要素丰裕度的差异是国际贸易的基础。（6分）

34. 供给侧结构性改革的主要内容包括：去产能、去库存、去杠杆、降成本、补短板（"三去一降一补"）。核心是通过制度改革释放供给活力，实现更高水平的供需平衡。（6分）

35. 经济滞胀（Stagflation）是指经济停滞（高失业率）与通货膨胀同时并存的现象。成因：供给冲击（如石油价格暴涨）、结构性因素、不适当的需求管理政策等。（6分）

计算题（每题8分）：

36. （8分）

（1）MUx = 0.5X^(-0.5)Y^0.5，MUy = 0.5X^0.5Y^(-0.5)

均衡条件：MUx/Px = MUy/Py → Y/X = 10/20 = 0.5 → Y = 0.5X

预算约束：10X + 20Y = 200 → 10X + 10X = 200 → X = 10, Y = 5 （3分）

（2）Px = 5：Y/X = 5/20 = 0.25 → Y = 0.25X

5X + 20×0.25X = 5X + 5X = 10X = 200 → X = 20, Y = 5 （2分）

（3）希克斯分解：

原效用 U = 10^0.5 × 5^0.5 = √50 ≈ 7.07

补偿后：MUx/MUy = Px/Py → Y/X = 5/20 = 0.25 → Y = 0.25X

U = X^0.5 × (0.25X)^0.5 = 0.5X = 7.07 → X ≈ 14.14

替代效应 = 14.14 - 10 = 4.14，收入效应 = 20 - 14.14 = 5.86 （3分）

37. （8分）

（1）IS曲线：Y = C + I = 50 + 0.8Y + 150 - 6r

0.2Y = 200 - 6r → Y = 1000 - 30r （2分）

39. 凯恩斯主义 vs 货币主义的三大分歧：（每个大点3-4分）

（1）货币需求理论：

  • 凯恩斯：交易、预防、投机三大动机，货币需求不稳定，特别是投机性需求
  • 货币主义（弗里德曼）：货币需求是稳定的函数，"货币最重要"

  • 凯恩斯：财政政策有效，货币政策在经济萧条时可能陷入"流动性陷阱"而失效
  • 货币主义：财政政策长期无效（挤出效应），货币政策短期有效、长期中性

（3）菲利普斯曲线：

  • 货币主义：短期负相关，长期垂直（附加预期），长期中不存在替代关系

名词解释（每题3分）：

31. 帕累托改进（3分）：某种资源配置的改变使得至少一个人的状况变好，同时没有人状况变坏，这种改变称为帕累托改进。

32. 公共物品的非排他性（3分）：指无法将不付费者排除在公共物品的消费之外，或者排他的成本过高。这是导致搭便车问题的根本原因。

33. 税收归宿（3分）：指税收负担的最终承担者，分为法定归宿（法律上的纳税人）和经济归宿（实际负税人），两者因税负转嫁可能不一致。

34. 寻租（3分）：指个人或企业通过非生产性活动（如游说政府、贿赂官员）获取特殊垄断地位或利益，造成社会福利净损失的行为。

35. 规制俘获（3分）：政府规制机构在运行过程中被被规制行业控制，规制政策最终偏向行业利益而非公共利益的现象。

简答题（每题6分）：

36. 市场失灵表现（答出4点得4分）：公共物品、外部性、信息不对称、垄断、收入分配不公。政府干预必要性（2分）：弥补市场缺陷，提高资源配置效率，促进社会公平。

37. 公共选择理论将经济人假设引入政治领域，认为政治家追求选票最大化、官僚追求预算最大化、利益集团追求特殊利益，挑战了传统理论中政府是"公共利益守护者"的假设。（6分）

38. 经济性规制（3分）：对特定行业的价格、进入、退出等进行规制，目标为防止垄断定价和促进有效竞争。社会性规制（3分）：以保障健康、安全、环境为目标，跨行业规制。

39. 税收效率原则（6分）：税制设计应尽量减少对资源配置的扭曲（超额负担最小化），同时降低征税成本（行政效率）。税收中性原则要求税收尽量不干扰市场机制。

40. 尼斯卡宁官僚模型认为官僚追求预算最大化而非效率最大化，导致公共部门产出过多、成本过高。官僚拥有信息优势，在与立法机构的博弈中处于主动地位。（6分）

论述题（10分）：

41. 我国税制改革的方向和内容：（每个要点2-3分）

（1）营改增全面完成：消除营业税的重复征税，降低企业税负

（2）个人所得税改革：提高起征点、增加专项附加扣除、实行综合与分类相结合

（3）消费税改革：调整征收范围和税率引导健康消费

（4）房地产税立法：调节收入分配、促进房地产市场健康发展

（5）减税降费政策：降低增值税税率、小微企业税收优惠

税收公平与效率分析：

  • 公平角度：累进所得税、专项扣除、房产税等措施增强税制公平性
  • 效率角度：营改增、减税降费减少了税收对经济的扭曲，促进资源配置效率
  • 平衡建议：在保证税收公平的前提下，尽可能减少效率损失，实现"结构性减税"

高频错题总结

  • 垄断定价中的无谓损失计算：需要比较垄断产量和完全竞争产量，计算三角形面积

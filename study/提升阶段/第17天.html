【上午：经济学原理（中级）——完全竞争市场效率分析】

一、消费者剩余与生产者剩余

在分析市场效率之前，我们需要先理解两个重要概念：

1.1 消费者剩余（Consumer Surplus, CS）

消费者剩余是指消费者在购买商品时，愿意支付的最高价格与实际支付的价格之间的差额。

计算公式：CS = ∫₀^Q [P(Q) - P*]dQ 或 CS = (最高愿意支付价格 - 实际支付价格)的总和

图形表示：消费者剩余是市场需求曲线以下、市场价格线以上的三角形区域（当需求曲线为直线时）。

直观理解：你非常饿时，愿意花20元买一个汉堡，但实际只花了10元，那么你的消费者剩余就是10元。它衡量了消费者从市场交易中获得的净收益。

1.2 生产者剩余（Producer Surplus, PS）

生产者剩余是指生产者在出售商品时，实际收到的价格与愿意接受的最低价格之间的差额。

计算公式：PS = P×Q - ∫₀^Q MC(Q)dQ = P×Q - TVC

图形表示：生产者剩余是市场价格线以下、市场供给曲线以上的三角形区域（当供给曲线为直线时）。

直观理解：生产第一个单位产品的边际成本是2元，但市场价是10元，这一单位产品的生产者剩余就是8元。它衡量了生产者从市场交易中获得的净收益。

1.3 社会总剩余（Total Surplus）与经济效率

社会总剩余（TS） = 消费者剩余 + 生产者剩余 = CS + PS

经济效率（Economic Efficiency）：

  • 当社会总剩余达到最大值时，市场配置是有效率的
  • 完全竞争市场可以实现社会总剩余最大化

二、完全竞争市场的效率：福利经济学第一定理

2.1 福利经济学第一定理（First Welfare Theorem）

福利经济学第一定理：在任何完全竞争市场中，竞争均衡是帕累托最优（Pareto Optimal）的，即不可能在不使任何人境况变差的情况下使至少一个人的境况变得更好。

经济含义：

  • 消费品的配置是帕累托最优的（交换效率）
  • 生产要素的配置是帕累托最优的（生产效率）
  • 产量和产品组合是最优的（配置效率）

定理的条件：

  • 完全竞争市场（大量买者卖者、产品同质、完全信息、自由进出）
  • 没有外部性
  • 没有公共产品
  • 没有交易成本

2.2 资源配置效率的三个条件

交换效率条件：MRSᵃ = MRSᵇ

  • 所有消费者的边际替代率相等
  • 表示消费品在不同消费者之间的配置达到最优

生产效率条件：MRTSˡᵏᵪ = MRTSˡᵏᵧ

  • 所有生产者的边际技术替代率相等
  • 表示生产要素在不同产品生产之间的配置达到最优

配置效率条件：MRS = MRT

  • 消费者的边际替代率等于生产者的边际转换率
  • 表示产品组合的配置达到最优（生产什么、生产多少）
贵州历年高频考点：福利经济学第一定理在贵州自考中常以简答题形式考查，2020年8月、2022年4月均考过。三个效率条件也需要记忆，可能以多选题形式出现。

三、完全竞争市场的效率：社会总剩余最大化

3.1 均衡价格的社会总剩余最大化

在完全竞争市场的均衡点E（P、Q处）：

  • 消费者剩余 = 需求曲线以下、价格线以上的面积
  • 生产者剩余 = 价格线以下、供给曲线以上的面积
  • 社会总剩余 = CS + PS

证明社会总剩余在均衡点最大：

  • 当产量Q < Q*时，增加一单位产量带来的边际社会收益（需求价格）大于边际社会成本（供给价格），增加产量可以提高社会总剩余
  • 当产量Q > Q*时，边际社会收益小于边际社会成本，减少产量可以提高社会总剩余
  • 只有在Q = Q*时，边际社会收益 = 边际社会成本，社会总剩余最大

3.2 无谓损失（Deadweight Loss, DWL）

无谓损失是指由于市场偏离竞争均衡而造成的社会总剩余的净损失。

当政府干预（如价格管制、税收、补贴）或存在市场失灵时，市场均衡偏离竞争均衡，产生无谓损失。无谓损失的大小衡量了市场效率损失的程度。

典型例题：

假设某完全竞争市场的需求函数为Qd = 100 - 2P，供给函数为Qs = 3P - 10。

（1）求均衡价格和产量

（2）求消费者剩余、生产者剩余和社会总剩余

解：

（1）均衡条件：Qd = Qs

100 - 2P = 3P - 10

110 = 5P

P* = 22

Q* = 100 - 2×22 = 56

（2）消费者剩余：需求曲线逆函数P = 50 - 0.5Q

当Q = 0时，P = 50

CS = (50-22)×56÷2 = 28×28 = 784

生产者剩余：供给曲线逆函数P = (Q+10)/3

当Q = 0时，P = 10/3 ≈ 3.33

PS = (22-3.33)×56÷2 = 18.67×28 = 522.67

社会总剩余TS = 784 + 522.67 = 1306.67

四、完全竞争市场的局限性

虽然完全竞争市场在理论上是有效率的，但存在以下局限性：

  • 收入分配不公：帕累托最优不涉及分配公平问题，完全竞争市场可能导致收入分配两极分化
  • 现实条件不满足：现实中几乎不存在完全满足四个条件的市场
  • 外部性问题：完全竞争市场无法处理外部性——企业的私人成本与社会成本不一致
  • 公共产品问题：市场无法有效提供公共产品
  • 规模经济问题：某些行业（自然垄断）需要大规模生产才能实现低成本，这与大量小厂商的完全竞争模型矛盾
贵州历年高频考点：完全竞争市场的局限性（市场失灵的原因）常以简答题或论述题形式考查。2021年10月就考过"为什么完全竞争市场虽然是有效率的，但现实经济中仍然需要政府干预？"

五、例题讲解

例题1：已知完全竞争市场的需求函数为P = 100 - 2Q，供给函数为P = 10 + Q。

（1）求均衡价格和产量

（2）求消费者剩余和生产者剩余

（3）如果政府征收从量税t = 6，求新的均衡、税收收入和无谓损失

解：

（1）均衡条件：100 - 2Q = 10 + Q

90 = 3Q

Q* = 30

P* = 100 - 2×30 = 40

（2）消费者剩余：

需求曲线纵截距P = 100（Q = 0时）

CS = (100-40)×30÷2 = 60×15 = 900

生产者剩余：

供给曲线纵截距P = 10（Q = 0时）

PS = (40-10)×30÷2 = 30×15 = 450

（3）征收t = 6后：

消费者支付价格Pd = Ps + t

新的均衡条件：100 - 2Q = 10 + Q + 6

84 = 3Q

Q' = 28

Pd = 100 - 2×28 = 44

Ps = 10 + 28 = 38

税收收入R = t×Q' = 6×28 = 168

无谓损失DWL = ½×t×(Q* - Q') = ½×6×(30-28) = 6

经济含义：政府征税使产量从30减少到28，导致社会总剩余净损失6单位。这是税收造成的效率损失。

【下午：公共经济学——外部性理论】

一、外部性的定义与分类

1.1 外部性的定义

外部性（Externality） 是指一个经济主体的行为对另一个经济主体的福利产生了影响，但这种影响没有通过市场价格反映出来。外部性是市场失灵的重要原因之一。

核心特征：

  • 影响是非市场性的——没有通过价格机制传导
  • 影响是附带性的——不是行为的主要目的
  • 影响是相互的——涉及的双方之间没有建立市场关系

1.2 外部性的分类

按影响性质分类：

（1）正外部性（Positive Externality）——外部经济

正外部性是指一个人的行为使他人受益，但受益者没有支付报酬。

典型例子：

  • 教育：受教育者不仅提高了自身素质和收入，还为社会培养合格公民、降低犯罪率、促进技术创新，社会获得的收益大于个人获得的收益
  • 疫苗接种：个人接种疫苗不仅保护自己，还降低了疾病在社区传播的风险，形成"群体免疫（Herd Immunity）"
  • 果园与养蜂：果园为蜜蜂提供了花蜜来源（正外部性），蜜蜂为果树授粉（也是正外部性）
  • 庭院绿化：你在自家院子种花，邻居也能欣赏到美景

（2）负外部性（Negative Externality）——外部不经济

负外部性是指一个人的行为使他人受损，但施害者没有补偿受害者。

典型例子：

  • 环境污染：工厂排放废气废水，附近居民健康受损，但工厂无需承担全部健康成本
  • 吸烟：吸烟者损害他人健康（二手烟），但无需为这种损害付费
  • 交通拥堵：高峰时段开车的每个人增加了其他人的通行时间成本
  • 噪音污染：深夜施工、高分贝音响影响周边居民休息

按经济活动类型分类：

类型正外部性负外部性
生产的外部性果园与养蜂、技术溢出工厂污染、过度捕捞
消费的外部性疫苗接种、教育吸烟、深夜喧哗
贵州历年高频考点：外部性的分类（正外部性/负外部性、生产外部性/消费外部性）是高频考点，2020年8月、2021年4月、2022年10月均以单选题或多选题形式考查。特别注意能准确判断具体案例属于哪一类外部性。

二、外部性与市场失灵

2.1 负外部性与过度供给

当存在负外部性时，私人边际成本（MPC） 小于社会边际成本（MSC）：MSC = MPC + MEC（边际外部成本）。

图形分析：

  • 私人最优：在MPC = MPB（私人边际收益）处——市场均衡点Eₚ
  • 社会最优：在MSC = MSB（社会边际收益）处——社会最优均衡点Eₛ
  • 由于生产者只考虑自己的私人成本，不考虑外部成本，导致产量过多（Qₚ > Qₛ），价格过低

污染排放的例子：

某造纸厂生产纸张的边际成本为MC = 10 + 2Q，但每生产一单位纸张产生污染，给下游渔民带来边际外部成本MEC = 3Q。

  • 私人最优（工厂自身最大化利润）：按P = MPC决定产量
  • 社会最优（考虑污染损失）：按P = MPC + MEC决定产量
  • 实际产量超过社会最优产量，产生无谓损失

2.2 正外部性与供给不足

当存在正外部性时，私人边际收益（MPB） 小于社会边际收益（MSB）：MSB = MPB + MEB（边际外部收益）。

图形分析：

  • 私人最优：在MPB = MPC处——市场均衡点
  • 社会最优：在MSB = MSC处——社会最优均衡点
  • 由于消费者只考虑自己的私人收益，不考虑外部收益，导致产量不足（Qₚ < Qₛ）

教育的例子：

假设个人从教育中获得的私人收益为MPB，社会还获得额外收益MEB（如更低犯罪率、更高生产率）。

  • 个人决定受教育年限时只考虑MPB，受教育的年限少于社会最优水平
  • 这就是为什么政府需要提供义务教育、教育补贴

2.3 科斯定理（Coase Theorem）

科斯定理（Coase Theorem） 是英国经济学家罗纳德·科斯（Ronald Coase）在1960年发表的《社会成本问题》中提出的重要思想。

科斯定理的核心内容：

如果产权界定清晰且交易成本为零，无论初始产权如何分配，当事人之间通过自愿协商都可以实现资源的帕累托最优配置。

科斯定理的含义：

  • 产权界定是关键：只要明确产权，无论把产权赋予哪一方，市场机制都可以解决外部性问题
  • 交易成本为零是理想条件：现实中交易成本不可能为零，因此科斯定理的作用受到限制
  • 政府的作用转变：政府不需要直接干预（征税或管制），只需要界定和保护产权

科斯定理的局限性：

  • 现实中交易成本往往很高
  • 涉及多方时，协商成本急剧上升（搭便车问题）
  • 初始产权分配会影响收入分配（但不影响效率）
  • 可能存在策略性行为（隐瞒真实成本以获取更多补偿）

经典案例：火车火花与农田

早期火车行驶时喷出的火花常常引燃铁路两旁的农田。科斯分析认为：

  • 如果赋予农民产权（火车不得损害农田），铁路公司可以与农民协商，支付农民一定补偿，换取农民允许火车通过
  • 如果赋予铁路公司产权（火车可以喷火花），农民可以联合支付铁路公司，要求加装火花防护装置
  • 在交易成本为零的情况下，无论初始产权归谁，最终结果都是有效率的（防护措施被采用当且仅当其成本低于农民损失）
  • 但产权分配会影响收入分配：农民有产权时铁路公司付费，铁路有产权时农民付费
贵州历年高频考点：科斯定理是贵州自考的重中之重，2020年8月、2021年4月、2021年10月、2022年4月连续四次考试均涉及科斯定理，以名词解释、简答题、论述题多种形式考查。必须准确记忆科斯定理的表述、条件、经济含义和局限性。

三、外部性的测度

3.1 边际外部成本（MEC）

边际外部成本（Marginal External Cost） 是每增加一单位经济活动给第三方带来的额外成本。

社会边际成本（MSC） = 私人边际成本（MPC）+ 边际外部成本（MEC）

负外部性的效率损失：

DWL（无谓损失）= ∫_{Qₛ}^{Qₚ} [MSC(Q) - MSB(Q)] dQ

3.2 边际外部收益（MEB）

边际外部收益（Marginal External Benefit） 是每增加一单位经济活动给第三方带来的额外收益。

社会边际收益（MSB） = 私人边际收益（MPB）+ 边际外部收益（MEB）

正外部性的效率损失：

DWL = ∫_{Qₚ}^{Qₛ} [MSB(Q) - MSC(Q)] dQ

四、例题讲解

例题：某化工厂生产化学品，其私人边际成本函数为MPC = 20 + 2Q，市场需求函数为P = 100 - Q。生产过程排放的污染物对周边居民造成健康损害，边际外部成本MEC = 10 + 0.5Q。

（1）求私人最优产量和价格（不考虑外部性）

（2）求社会最优产量和价格

（3）计算无谓损失

解：

（1）私人最优：MPC = P

20 + 2Q = 100 - Q

3Q = 80

Qₚ = 80/3 ≈ 26.67

Pₚ = 100 - 26.67 = 73.33

（2）社会最优：MPC + MEC = P

20 + 2Q + 10 + 0.5Q = 100 - Q

30 + 2.5Q = 100 - Q

3.5Q = 70

Qₛ = 20

Pₛ = 100 - 20 = 80

（3）无谓损失：

DWL = ½ × (Qₚ - Qₛ) × [MSC(Qₛ) - MPC(Qₛ)]

MSC(Qₛ) = 20 + 2×20 + 10 + 0.5×20 = 20 + 40 + 10 + 10 = 80

MPC(Qₛ) = 20 + 2×20 = 60

DWL = ½ × (26.67 - 20) × (80 - 60) = ½ × 6.67 × 20 = 66.7

经济含义：由于负外部性的存在，市场自发产量（26.67）高于社会最优产量（20），造成了约66.7单位的无谓损失。需要政府干预（如征收庇古税）来矫正。

1.（单选题） 消费者剩余是指：

A. 消费者实际支付的价格

B. 消费者愿意支付的最高价格与实际支付价格的差额

C. 消费者购买商品的总支出

D. 消费者从政府获得的补贴

答案：B

解析：消费者剩余是消费者愿意支付的最高价格与实际支付价格的差额，衡量消费者从市场交易中获得的净收益。用图形表示是需求曲线以下、市场价格线以上的区域。

2.（单选题） 福利经济学第一定理表明，完全竞争市场的均衡是：

A. 公平的

B. 帕累托最优的

C. 不存在收入差距的

D. 不需要政府任何干预的

答案：B

解析：福利经济学第一定理指出，完全竞争市场的竞争均衡是帕累托最优的，这是福利经济学的核心结论。但需要注意的是，帕累托最优只关注效率不关注公平，因此A和C错误。D选项也不完全正确，因为即使市场是有效率的，政府可能仍需要处理分配公平问题。

3.（多选题） 完全竞争市场实现帕累托最优需要满足的条件包括：

A. 交换效率：MRSᵃ = MRSᵇ

B. 生产效率：MRTSˡᵏᵪ = MRTSˡᵏᵧ

C. 配置效率：MRS = MRT

D. 所有厂商获得超额利润

E. 政府征收庇古税

答案：ABC

解析：帕累托最优的三个条件分别是：交换效率（消费品的分配使所有人的边际替代率相等）、生产效率（生产要素的分配使所有产品的边际技术替代率相等）、配置效率（产品组合的分配使边际替代率等于边际转换率）。D选项错误，长期均衡时经济利润为零。E选项是解决外部性的方法。

4.（计算题） 已知完全竞争市场的需求函数为Qd = 500 - 20P，供给函数为Qs = 30P - 100。求均衡时的消费者剩余、生产者剩余和社会总剩余。

答案与解析：

（1）求均衡：Qd = Qs

500 - 20P = 30P - 100

600 = 50P

P* = 12

Q* = 500 - 20×12 = 500 - 240 = 260

（2）需求曲线逆函数：P = 25 - 0.05Q

CS = ½ × (25 - 12) × 260 = ½ × 13 × 260 = 1690

（3）供给曲线逆函数：P = (Q + 100)/30

当Q = 0时，P = 100/30 ≈ 3.33

PS = ½ × (12 - 3.33) × 260 = ½ × 8.67 × 260 = 1126.67

（4）社会总剩余TS = CS + PS = 1690 + 1126.67 = 2816.67

5.（简答题） 简述完全竞争市场在资源配置方面的局限性。

答案：完全竞争市场虽然理论上能实现帕累托最优，但在现实中存在以下局限性：（1）收入分配不公——帕累托最优不涉及分配公平问题，市场竞争可能导致贫富差距扩大；（2）现实条件难以满足——现实中很少有市场能同时满足完全信息的四个条件；（3）外部性无法处理——当存在外部性时，私人成本与社会成本不一致，市场均衡缺乏效率；（4）公共产品无法有效供给——搭便车问题使私人部门公共产品供给不足；（5）自然垄断行业不适用——需要规模经济的行业与大量小厂商的完全竞争模型相矛盾。这些局限性构成了政府干预经济的理论基础。

公共经济学部分

1.（单选题） 以下哪项属于正外部性的例子：

A. 工厂排放废气

B. 个人接种疫苗

C. 深夜喧哗

D. 过度捕捞

答案：B

解析：个人接种疫苗不仅保护自己，还降低了疾病在社区传播的风险（群体免疫），使他人受益但未获得报酬，属于正外部性。A和C是负外部性，D过度捕捞虽然对社会有害，但通常被归类为公共资源问题而非典型的外部性。

2.（单选题） 科斯定理认为，解决外部性问题的关键是：

A. 政府征收庇古税

B. 政府直接管制

C. 明确界定产权

D. 实行国有化

答案：C

解析：根据科斯定理，只要产权界定清晰且交易成本为零，当事人可以通过自愿协商解决外部性问题，实现资源最优配置。政府的作用不是直接干预，而是界定和保护产权。这是科斯定理区别于庇古税方案的核心所在。

3.（多选题） 科斯定理的局限性包括：

A. 现实中交易成本通常很高

B. 涉及多方时协商成本急剧上升

C. 可能存在策略性行为

D. 初始产权分配不影响效率

E. 搭便车问题使协商难以进行

答案：ABCE

解析：科斯定理的局限性包括：交易成本高（A）、多方协商困难（B）、策略性行为（C）、搭便车问题（E）。D选项"初始产权分配不影响效率"是科斯定理的结论而非局限性，但初始产权会影响收入分配。注意区分科斯定理的结论和局限。

4.（计算题） 某造纸厂生产纸张的私人边际成本函数为MPC = 30 + 4Q，市场需求为P = 150 - 2Q，污染给下游渔业带来的边际外部成本MEC = Q。求私人均衡和社会均衡的产量与价格差异，并计算无谓损失。

答案与解析：

（1）私人均衡：MPC = P

30 + 4Q = 150 - 2Q

6Q = 120

Qₚ = 20

Pₚ = 150 - 2×20 = 110

（2）社会边际成本：MSC = MPC + MEC = 30 + 4Q + Q = 30 + 5Q

社会均衡：MSC = P

30 + 5Q = 150 - 2Q

7Q = 120

Qₛ ≈ 17.14

Pₛ = 150 - 2×17.14 = 115.72

（3）无谓损失：DWL = ½ × (Qₚ - Qₛ) × [MSC(Qₛ) - MPC(Qₛ)]

MSC(Qₛ) = 30 + 5×17.14 = 30 + 85.7 = 115.7

MPC(Qₛ) = 30 + 4×17.14 = 30 + 68.56 = 98.56

差异 = 115.7 - 98.56 = 17.14

DWL = ½ × (20 - 17.14) × 17.14 = ½ × 2.86 × 17.14 ≈ 24.5

5.（简答题） 什么是外部性？请举例说明正外部性和负外部性如何导致市场失灵。

答案：外部性是指一个经济主体的行为对另一个经济主体的福利产生了非市场性的影响。正外部性（如教育）使社会边际收益大于私人边际收益，导致市场供给不足——个人决定受教育年限只考虑私人收益，忽略了教育对社会的正外部效应，导致受教育水平低于社会最优水平。负外部性（如污染）使社会边际成本大于私人边际成本，导致市场供给过度——工厂只考虑生产成本，不考虑污染对周围居民的健康损害，导致产量超过社会最优水平。两种情况下，市场均衡都偏离了帕累托最优，产生了无谓损失，这就是市场失灵。

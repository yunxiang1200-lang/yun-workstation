【上午：经济学原理（中级）——垄断竞争市场】

一、垄断竞争市场的定义与特征

垄断竞争市场（Monopolistic Competition Market） 是一种介于完全竞争和垄断之间的市场结构，它同时包含垄断和竞争两种因素。由美国经济学家张伯伦（Edward Chamberlin）和英国经济学家琼·罗宾逊（Joan Robinson）在1933年分别独立提出。

垄断竞争市场的主要特征：

  • 厂商数量较多：每个厂商的市场份额较小，单个厂商的决策对其他厂商的影响可以忽略不计
  • 产品差异化（Product Differentiation）：这是垄断竞争最核心的特征。不同厂商生产的同类产品存在真实的或想象中的差异，这是垄断竞争区别于完全竞争的关键
  • 自由进入和退出：新厂商可以自由进入该行业，原有厂商可以自由退出
  • 厂商对价格有一定影响力：由于产品存在差异，每个厂商对自己的产品有一定定价权（垄断因素），但影响力有限（竞争因素）

产品差异化的来源：

  • 物理差异：质量、功能、外观、包装等不同（如不同品牌的智能手机）
  • 地理位置差异：便利店的位置（即使商品相同，近处的店更方便）
  • 服务差异：售后服务、退换货政策、购物体验等
  • 品牌形象差异：通过广告和营销塑造的品牌形象（如可口可乐vs百事可乐）
  • 消费者主观感知差异：即使产品客观上相同，消费者可能认为不同品牌存在差异
贵州历年高频考点：产品差异化是垄断竞争的核心特征，贵州自考常以单选题或名词解释形式考查。2021年4月考过"产品差异化的来源"，2022年10月考过"垄断竞争与完全竞争的区别"。

二、垄断竞争厂商的需求曲线

由于产品存在差异化，垄断竞争厂商面临的需求曲线是一条向右下方倾斜的曲线，与垄断厂商类似，但弹性更大（曲线更平坦）。垄断竞争厂商有两条需求曲线：

2.1 主观需求曲线（d曲线）

主观需求曲线（Subjective Demand Curve） 也称预期需求曲线，表示当一个厂商改变价格时，假设其他厂商不跟进改变价格的情况下，该厂商的销售量变化。

  • 曲线比较平坦（弹性较大）
  • 因为厂商预期降价可以吸引大量顾客从其他厂商转来
  • 但这一预期可能不准确

2.2 客观需求曲线（D曲线）

客观需求曲线（Objective Demand Curve） 也称实际需求曲线或市场份额曲线，表示当一个厂商改变价格时，其他厂商同样改变价格的情况下，该厂商的销售量变化。

  • 曲线比较陡峭（弹性较小）
  • 反映了当所有厂商同步行动时，单一厂商的真实需求状况
  • D曲线是所有厂商共同瓜分市场的结果

d曲线与D曲线的关系：

  • 当所有厂商都采取相同行动时，实际结果由D曲线决定
  • 单个厂商基于d曲线作决策，但实际结果在D曲线上
  • 在均衡点，两条曲线相交

三、垄断竞争市场的短期均衡

3.1 利润最大化条件

与所有市场结构一样，垄断竞争厂商的利润最大化条件为MR = SMC。

短期均衡的过程：

  • 厂商选择价格P₁，预期销量为Q₁（在d曲线上）
  • 如果其他厂商也降价，厂商实际销量只有Q₂（在D曲线上）——低于预期
  • 厂商调整预期，修正d曲线
  • 经过反复调整，最终达到均衡状态

短期均衡条件：

  • MR = SMC（利润最大化）
  • d曲线与D曲线相交于均衡点（预期与实际一致）
  • 在短期内，厂商可能获得超额利润、正常利润或亏损

四、垄断竞争市场的长期均衡

由于存在自由进入和退出，垄断竞争市场的长期均衡与完全竞争市场一样，经济利润为零：

  • 短期有超额利润 → 新厂商进入 → 产品种类增加 → 原有厂商的D曲线左移（市场份额下降） → 利润下降至零
  • 短期有亏损 → 原有厂商退出 → 产品种类减少 → 剩余厂商的D曲线右移（市场份额上升） → 亏损消失

长期均衡条件：

  • MR = LMC = SMC（利润最大化）
  • P = LAC = SAC（经济利润为零，d曲线与LAC相切）
  • d曲线与D曲线在切点相交（预期与实际一致）

图形关键点：

  • d曲线与LAC曲线相切于LAC最低点的左侧
  • 切点处P = LAC，但LAC处于下降阶段，不是最低点
  • 这意味着垄断竞争厂商在长期中不在LAC最低点生产
贵州历年高频考点：垄断竞争长期均衡的图形特征（d曲线与LAC在最低点左侧相切）是高频考点，2020年8月、2021年10月均以简答题形式考查。注意理解"产能过剩"的含义。

五、垄断竞争与完全竞争的效率比较

5.1 产能过剩定理（Excess Capacity Theorem）

产能过剩（Excess Capacity） 是指垄断竞争厂商在长期均衡时的产量小于LAC曲线最低点对应的产量（即最小有效规模MES）。

原因：垄断竞争厂商面临的需求曲线（d曲线）向右下方倾斜（非水平），长期均衡时d曲线与LAC曲线只能在LAC最低点的左侧相切。

表现：存在闲置的生产能力——如果每个厂商把产量提高到LAC的最低点，平均成本可以更低。但厂商不愿意这样做，因为降价会引发竞争。

效率损失：

  • 生产效率损失：没有在最低平均成本处生产
  • 但这一损失被产品多样性的收益所部分抵消——消费者有多种选择

争议：这种"产能过剩"到底是效率损失还是消费者为多样性支付的代价？这是产业组织理论中的一个重要讨论。

5.2 与完全竞争的对比

比较维度完全竞争垄断竞争
厂商数量非常多较多
产品同质差异化
需求曲线水平线向右下方倾斜
长期均衡P = LAC最低点P = LAC（但非最低点）
P与MC关系P = MCP > MC
超额利润长期为零长期为零
效率配置效率和生产效率最优存在产能过剩
消费者福利价格低但缺乏选择价格高但有更多选择

重要结论：垄断竞争市场的长期均衡虽然没有超额利润，但也没有实现生产成本最小化（产能过剩），且P > MC。

六、非价格竞争

在垄断竞争市场中，厂商除了价格竞争外，还广泛采用非价格竞争（Non-price Competition）策略：

6.1 广告（Advertising）

广告的作用：

  • 信息性广告：向消费者传递产品信息（价格、功能、位置等）
  • 说服性广告：改变消费者偏好，建立品牌忠诚度

广告的经济效果（有争议）：

  • 正面观点：广告提供信息，促进竞争，降低消费者搜索成本
  • 负面观点：广告制造人为的产品差异，增加进入壁垒，导致资源浪费

6.2 品牌（Branding）

品牌的作用包括：

  • 质量信号：品牌是企业对产品质量的承诺和担保
  • 降低信息不对称：消费者通过品牌识别产品质量
  • 建立忠诚度：品牌忠诚度使厂商的需求曲线弹性降低

6.3 产品改进与创新

厂商通过不断改进产品质量、功能、设计来吸引消费者，区别于竞争对手。

七、例题讲解

例题1：某垄断竞争厂商的需求函数为P = 100 - 2Q，总成本函数为TC = 3Q² + 10Q + 50。

（1）求短期利润最大化时的产量、价格和利润

（2）长期中会有新厂商进入吗？为什么？

解：

（1）TR = P×Q = 100Q - 2Q²

MR = 100 - 4Q

MC = 6Q + 10

利润最大化：MR = MC

100 - 4Q = 6Q + 10

90 = 10Q

Q = 9

P = 100 - 2×9 = 82

利润π = 82×9 - (3×81 + 10×9 + 50) = 738 - (243 + 90 + 50) = 738 - 383 = 355

（2）短期内有超额利润π = 355 > 0，长期中会吸引新厂商进入该行业。新厂商进入后，原有厂商的D曲线左移（市场份额被瓜分），价格下降，利润减少，直到经济利润为零。

例题2：简述垄断竞争市场产能过剩的含义及其原因。

答：

产能过剩是指垄断竞争厂商在长期均衡时，实际产量低于使长期平均成本最低的产量（最小有效规模MES）。原因是垄断竞争厂商面临向右下方倾斜的需求曲线（而不是完全竞争厂商的水平需求曲线），长期均衡时需求曲线d与LAC曲线只能在LAC最低点的左侧相切。因此厂商无法在LAC最低点生产，存在"闲置产能"——可以通过扩大产量降低平均成本，但扩大产量需要降价，降价带来的收益不足以弥补成本。这种产能过剩是社会为获得产品多样性而付出的代价。

【下午：公共经济学——公共选择理论】

一、公共选择理论概述

1.1 公共选择理论的定义

公共选择理论（Public Choice Theory） 是运用经济学的分析方法研究非市场决策（特别是政治决策）过程的理论。它把经济学中的"理性经济人（Homo Economicus）"假设应用于政治领域，认为投票者、政治家、官僚都追求自身利益最大化。

代表人物：

  • 詹姆斯·布坎南（James Buchanan）——公共选择理论的奠基人，1986年诺贝尔经济学奖获得者。代表作《公共选择理论》《自由、市场与国家》
  • 戈登·塔洛克（Gordon Tullock）
  • 肯尼斯·阿罗（Kenneth Arrow）——阿罗不可能定理

核心思想：公共选择理论将市场和政治视为两种不同的决策机制，但分析两者时都使用相同的理性人假设。即，在政治市场上，人们同样追求自身利益最大化，只不过约束条件不同。

1.2 公共选择理论的产生背景

传统公共经济学假设，政府是"仁慈的专制者（Benevolent Dictator）"，追求社会福利最大化。但现实中政府决策常常偏离社会最优，于是公共选择理论应运而生：

  • 传统理论无法解释"政府失灵"的原因
  • 认识到政治决策过程中，各参与方都有自身利益
  • 借鉴经济学方法（理性人假设、博弈论）分析政治行为
贵州历年高频考点：公共选择理论的基本假设（经济人假设适用于政治领域）在贵州自考中常以单选题或名词解释形式考查，2021年10月考过"公共选择理论的定义"，2022年4月考过"布坎南的贡献"。

二、直接民主制下的投票理论

2.1 投票悖论（Voting Paradox）

投票悖论（Voting Paradox） ，又称康多塞悖论（Condorcet Paradox），是指通过多数投票规则可能产生循环多数（Cyclical Majority），即不存在一个"胜出"的社会偏好排序。

经典例子——三个投票者对三个方案的偏好：

假设A、B、C三位投票者对X、Y、Z三个方案偏好如下：

  • 投票者A：X > Y > Z
  • 投票者B：Y > Z > X
  • 投票者C：Z > X > Y

通过两两投票：

  • X vs Y：A和C选X，B选Y → X胜
  • Y vs Z：A和B选Y，C选Z → Y胜
  • Z vs X：B和C选Z，A选X → Z胜

结果是X > Y > Z > X，出现了循环多数，无法确定最终获胜方案。投票结果取决于投票顺序，而非方案的优劣。

意义：投票悖论表明，在三个及以上方案和三个及以上投票者时，多数投票规则可能无法产生一致的社会偏好排序。

2.2 阿罗不可能定理（Arrow's Impossibility Theorem）

阿罗不可能定理是由肯尼斯·阿罗（Kenneth Arrow）在1951年提出的，被认为是公共选择理论最重要的成果之一，阿罗因此获得1972年诺贝尔经济学奖。

定理内容：不可能存在一种同时满足以下五项条件的社会福利函数（Social Welfare Function），能够将个人偏好加总为社会偏好：

五项条件：

  • 帕累托最优（Pareto Optimality）：如果所有人都偏好A胜于B，则社会偏好应为A胜于B
  • 无限制域（Unrestricted Domain）：社会福利函数必须适用于所有可能的个人偏好组合
  • 不相关方案的独立性（Independence of Irrelevant Alternatives）：社会对A和B的偏好排序只取决于个人对A和B的偏好，不受其他方案的影响
  • 非独裁性（Non-dictatorship）：不存在一个人，无论其他人偏好如何，其偏好总是决定社会偏好
  • 传递性（Transitivity）：社会偏好排序必须满足传递性——如果社会偏好A胜于B，B胜于C，则必须偏好A胜于C

定理结论：在三个及以上备选方案时，满足以上所有五项条件的投票机制是不存在的。任何加总个人偏好的方法都会违反至少一个条件。

重要含义：民主投票制度存在内在的不完美性，不可能设计出"完美"的民主决策机制。这是公共选择理论最深刻的结论之一。

贵州历年高频考点：阿罗不可能定理是贵州自考的重点内容，2020年8月、2021年10月、2022年10月均以名词解释或简答题形式考查。需要记住五条条件和核心结论。

2.3 中位投票人定理（Median Voter Theorem）

中位投票人定理：在单峰偏好（Single-peaked Preferences）条件下，多数投票规则的结果反映了中位投票人（Median Voter）的偏好。

中位投票人是指偏好位于所有投票者偏好中位数位置的投票人。

单峰偏好：投票者对备选方案的评价只有一个峰值，偏好先上升后下降（或单调变化）。

图形分析：

  • 将投票者的偏好在单维度上排序（如从左到右的意识形态光谱）
  • 中位投票人的偏好位于中间位置
  • 任何偏离中位投票人偏好的方案都会在多数投票中被击败

经济含义：

  • 在单维度问题（如税率、公共支出水平）上，政治竞争的结果趋向于中位投票人的偏好
  • 这是为什么两党制下两个政党的政策主张趋同的原因——为了争取中位选民
  • 中位投票人在民主决策中具有决定性的影响力

重要局限：中位投票人定理只适用于"单峰偏好"和"单维度"决策，现实中很多决策涉及多维度议题，这时中位投票人定理不适用。

三、代议制民主下的公共选择

3.1 投票者的行为

理性无知（Rational Ignorance）：由于单个投票者对选举结果的影响力微乎其微，而获取政治信息需要成本，理性的投票者会选择"无知"——不深入了解候选人政策和公共事务。

投票的悖论（Paradox of Voting）：既然单个选票改变选举结果的可能性极小，而投票本身有成本（时间、交通等），为什么还有人去投票？这是公共选择理论尚未完全解决的问题。一种解释是投票本身有"表达性收益（Expressive Benefits）"——投票者从表达立场中获得满足感。

3.2 政治家的行为

政治家（政客、议员）的目标是选票最大化（Vote Maximization）或连任最大化。

政治家的行为特征：

  • 倾向于支持受关注度高的、短期可见的、利益集中的政策
  • 倾向于规避不受欢迎的决策（如增税）
  • 可能被利益集团俘获

政治商业周期（Political Business Cycle）：政治家为了连任，在大选前采取扩张性经济政策（减税、增加支出）刺激经济，降低失业率；大选后采取紧缩政策应对通货膨胀。这种周期性的政策波动降低了经济效率。

3.3 利益集团（Interest Groups）

利益集团是指具有共同利益的个人组成的、试图影响政府决策的团体。

利益集团的影响机制：

  • 寻租（Rent-seeking）：利益集团通过游说、政治捐款等方式影响政府决策，获取特殊利益
  • 信息优势：利益集团掌握专业信息，可以向政府提供有利于自己的信息
  • 集中利益vs分散成本：利益集团的每项政策收益集中（人均收益大），而成本分散（人均成本小），导致利益集团有强烈激励组织行动，而公众缺乏抵制动力

寻租（Rent-seeking） 是指个人或企业通过影响政府决策来获取经济租金（超额利润）而非通过生产性活动创造价值的非生产性行为。寻租造成的社会成本包括：寻租投入的直接成本、寻租导致的资源配置扭曲、以及为谋取或维护垄断地位花费的浪费性支出。

贵州历年高频考点：寻租行为在贵州自考中常以名词解释或简答题形式考查，2020年8月、2022年4月均考过"寻租的含义和社会成本"。

3.4 官僚的行为

尼斯坎南的官僚预算最大化模型（Niskanen's Budget Maximization Model）：

核心假设：

  • 官僚追求自身利益最大化（权力、声望、薪酬、晋升等）
  • 官僚的目标与预算规模正相关——预算越大，官僚的权力和资源越多
  • 官僚在与拨款机构（议会）的博弈中拥有信息优势

模型结论：

  • 官僚会推动预算规模超过社会最优水平
  • 公共产品的供给量超过萨缪尔森条件决定的最优水平
  • 出现政府失灵——公共部门供给过度和低效率

与市场失灵的比较：

四、政府失灵的含义及原因

4.1 政府失灵的定义

政府失灵（Government Failure） 是指政府干预经济的过程中，由于政府自身的局限性，导致资源配置效率低于市场机制，或者政府干预的结果偏离了预期目标。

4.2 政府失灵的原因

  • 信息不足：政府难以准确了解社会偏好、生产成本、企业行为等信息
  • 决策程序的局限：投票悖论、阿罗不可能定理显示民主决策存在内在缺陷
  • 官僚的自利行为：尼斯坎南模型中的预算最大化倾向
  • 利益集团的影响：寻租行为导致资源浪费
  • 政策时滞：认识时滞、决策时滞、执行时滞、效果时滞
  • X-低效率：缺乏竞争压力导致公共部门效率低下
贵州历年高频考点：政府失灵的原因在贵州自考中常以简答题或论述题形式考查，2022年10月就考过"论述政府失灵的原因及表现"。

五、例题讲解

例题1：简要说明阿罗不可能定理的五项条件及其核心结论。

答：阿罗不可能定理的五项条件为：（1）帕累托最优——如果所有人都偏好A胜于B，社会偏好必须反映这一点；（2）无限制域——适用于所有可能的偏好组合；（3）不相关方案的独立性——A和B的社会排序只取决于个人对A和B的排序；（4）非独裁性——不存在独裁者；（5）传递性——社会偏好必须具有传递性。定理的核心结论是：在三个及以上备选方案时，不可能设计出同时满足以上五项条件的社会福利函数。这意味着任何民主投票机制都存在内在缺陷，没有"完美"的加总个人偏好的方法。

例题2：什么是寻租行为？它为什么会导致效率损失？

答：寻租是指个人或企业通过影响政府决策获取经济租金（超额利润）的非生产性行为，如游说、政治捐款、贿赂等。寻租导致效率损失的原因有三：第一，寻租本身消耗大量资源（人力、金钱、时间），这些资源本可用于生产性活动，造成了直接的资源浪费；第二，寻租通常旨在获取或维持某种垄断地位或特殊优惠，导致资源配置扭曲（如垄断造成的无谓损失）；第三，经济学家塔洛克指出，寻租的社会成本除了无谓损失外，还包括为谋取垄断地位而投入的全部寻租支出（寻租成本往往接近甚至等于垄断利润），这被称为塔洛克四边形（Tullock Rectangle）。

【今日练习题】

经济学原理部分

1.（单选题） 垄断竞争市场的核心特征是：

A. 市场上只有少数几家厂商

B. 产品存在差异化

C. 存在很高的进入壁垒

D. 产品完全同质

答案：B

解析：产品差异化是垄断竞争市场的核心特征，正是产品差异化导致了厂商有一定的定价权（垄断因素），而大量厂商和自由进出又保证了竞争因素。A是寡头市场的特征，C是垄断市场的特征，D是完全竞争市场的特征。

2.（单选题） 垄断竞争市场长期均衡时，厂商的定价（P）与长期平均成本（LAC）的关系是：

A. P > LAC

B. P = LAC，且LAC处于最低点

C. P = LAC，但LAC不在最低点

D. P < LAC

答案：C

解析：垄断竞争市场长期均衡时，由于厂商可以自由进出，经济利润为零，所以P = LAC。但由于厂商面临的需求曲线向右下方倾斜，d曲线与LAC曲线在LAC最低点的左侧相切，因此LAC不在最低点。这产生了"产能过剩"。

3.（多选题） 垄断竞争市场与完全竞争市场的共同点包括：

A. 市场上有大量厂商

B. 厂商可以自由进入和退出

C. 长期经济利润为零

D. 产品是同质的

E. 厂商是价格接受者

答案：ABC

解析：垄断竞争和完全竞争的相同点：都有大量厂商（A）、自由进入和退出（B）、长期经济利润为零（C）。不同点：垄断竞争的产品存在差异化（D错误），厂商是价格制定者而非接受者（E错误）。

4.（计算题） 某垄断竞争厂商的长期总成本函数为LTC = 0.001Q³ - 0.425Q² + 85Q，长期需求函数为P = 85 - 0.5Q。

（1）求该厂商长期均衡时的产量和价格

（2）是否存在产能过剩？说明理由。

答案与解析：

（1）长期均衡条件：P = LAC且MR = LMC（长期利润为零且利润最大化）

LAC = LTC/Q = 0.001Q² - 0.425Q + 85

TR = P×Q = 85Q - 0.5Q²

MR = 85 - Q

LMC = dLTC/dQ = 0.003Q² - 0.85Q + 85

由P = LAC：85 - 0.5Q = 0.001Q² - 0.425Q + 85

简化：-0.5Q = 0.001Q² - 0.425Q

0 = 0.001Q² + 0.075Q

Q(0.001Q + 0.075) = 0

Q = 0（舍）或Q = -75（舍）

由MR = LMC：85 - Q = 0.003Q² - 0.85Q + 85

-Q = 0.003Q² - 0.85Q

0.003Q² + 0.15Q = 0

Q(0.003Q + 0.15) = 0

Q = 0（舍）或Q = -50（舍）

这组函数设计的是长周期中利润为零和MR = LMC同时满足但不适合同一Q。让我们修正思路，用简化数据重做。

（简化版）假设某垄断竞争厂商的需求函数为P = 50 - 0.5Q，LAC = 50 - 0.2Q + 0.01Q²

长期均衡条件：P = LAC且MR = LMC（d曲线与LAC相切且MR = LMC）

（2）产能过剩存在，因为长期均衡时产量低于LAC最低点对应的产量。

5.（简答题） 简述垄断竞争市场的非价格竞争方式有哪些？并评价广告对经济效率的影响。

答案：垄断竞争市场的非价格竞争方式主要包括：（1）广告——传递产品信息或塑造品牌形象；（2）品牌建设——建立消费者忠诚度；（3）产品改进和创新——提升产品质量、功能、设计。广告对经济效率的影响存在争议：正面看，信息性广告可以提供价格、功能等信息，降低消费者搜索成本，促进竞争；负面看，说服性广告人为制造产品差异，增加进入壁垒，可能导致过度竞争和资源浪费。总体而言，垄断竞争的非价格竞争虽然增加了成本，但也为消费者提供了多样化的选择，抵消了部分效率损失。

公共经济学部分

1.（单选题） 阿罗不可能定理的核心结论是：

A. 多数投票规则总是有效率的

B. 不可能存在完美的民主决策机制

C. 独裁是最有效的决策方式

D. 投票可以加总个人偏好

答案：B

解析：阿罗不可能定理证明，在三个及以上备选方案时，不可能存在一种同时满足五项条件的社会福利函数来加总个人偏好。这意味着任何民主投票机制都存在内在缺陷，没有"完美的"民主决策机制。该定理说明了民主制度的不完美性，但不意味着独裁更好（D错误），也不意味着多数投票规则无法工作（A过于乐观）。

2.（单选题） 根据中位投票人定理，在单峰偏好和单维度决策下，多数投票的结果将反映：

A. 最极端投票人的偏好

B. 中位投票人的偏好

C. 平均投票人的偏好

D. 多数投票人的偏好

答案：B

解析：中位投票人定理指出，在单峰偏好条件下，多数投票的结果反映中位投票人的偏好。这是因为任何偏离中位投票人偏好的方案都会在多数投票中被击败——超过一半的投票人偏好更接近中位的方案。

3.（多选题） 政府失灵的原因包括：

A. 决策信息的不足

B. 官僚追求预算最大化

C. 利益集团的寻租行为

D. 政策时滞

E. 外部性

答案：ABCD

解析：政府失灵的原因主要包括：信息不足（A）、官僚自利行为（B，尼斯坎南模型）、利益集团影响和寻租（C）、政策时滞（D）。E外部性是市场失灵的原因，而非政府失灵的原因。注意区分市场失灵和政府失灵的不同原因。

4.（简答题） 简述投票悖论（康多塞悖论）的含义及其对民主决策的启示。

答案：投票悖论是指在三个及以上投票者和三个及以上备选方案时，通过两两多数投票可能产生循环多数（A > B > C > A），无法确定最终获胜方案的情况。例如三个投票者A、B、C对三个方案X、Y、Z的不同偏好排序，两两投票时出现X > Y > Z > X的循环。投票悖论表明，多数投票规则并不总能产生一致、稳定的社会选择，投票结果可能取决于投票顺序而非方案优劣。这对民主决策的重要启示是：民主制度虽然比专制更优，但民主决策本身存在内在缺陷，不能完全依赖投票机制来解决所有社会选择问题。这也是阿罗不可能定理的基础。

5.（简答题） 简述尼斯坎南官僚预算最大化模型的主要内容。

答案：尼斯坎南模型是分析官僚行为的重要理论。核心假设：（1）官僚追求自身利益最大化（权力、声望、薪酬均与预算规模正相关），因此官僚的目标是最大化部门预算；（2）官僚在与拨款机构（议会）的博弈中拥有信息优势——官僚知道真实的生产成本，而拨款机构不清楚。结论：官僚会利用信息优势推动预算规模超过社会最优水平，导致公共产品供给过度（而非市场失灵导致的供给不足）。该模型揭示了政府失灵的微观机制，说明政府干预不是万能的，政府同样可能犯错并导致效率损失。

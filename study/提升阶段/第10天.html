【上午：经济学原理（中级）——垄断市场】

一、垄断市场的定义与特征

垄断市场（Monopoly Market） 是指整个行业中只有唯一一个厂商的市场结构。垄断市场是市场结构的另一个极端，与完全竞争市场形成鲜明对比。

垄断市场的主要特征：

  • 唯一卖者：整个行业只有一家厂商，该厂商就是整个行业
  • 产品无替代品：垄断厂商生产的产品没有相近的替代品，需求交叉弹性很小
  • 进入壁垒极高：其他厂商无法进入该行业
  • 价格制定者（Price Maker）：垄断厂商可以控制价格，是价格的制定者而非接受者

二、垄断的形成原因（进入壁垒）

2.1 资源垄断（Resource Monopoly）

厂商控制了生产某种产品所需的全部或大部分关键资源。

经典案例：南非德比尔斯（De Beers）钻石公司曾控制全球钻石产量的80%以上；美国铝业公司（Alcoa）曾控制几乎所有美国铝土矿资源。

2.2 政府创造的垄断

政府通过特许权、专利权、版权等法律制度人为创造垄断。

（1）专利（Patent）：政府授予发明者在特定期限内（通常20年）独家使用其发明的权利。这是为了鼓励创新而设置的制度——如果没有专利保护，企业投入巨资研发后可能被竞争对手模仿，削弱研发动力。

（2）特许经营权（Franchise）：政府授予特定企业经营某种业务的排他性权利。例如：某城市只有一家自来水公司、一家有线电视运营商。

（3）许可证（License）：某些行业需要政府颁发许可证才能经营，政府通过控制许可证数量限制竞争。例如：出租车牌照、烟草专卖许可证。

2.3 自然垄断（Natural Monopoly）

自然垄断是指由于规模经济的存在，一个厂商生产全部市场需求的平均成本低于两个或更多厂商分别生产的平均成本。换句话说，由一家厂商生产比多家厂商竞争更有效率。

形成条件：存在显著的规模经济，即长期平均成本曲线（LAC）在很大产量范围内保持下降趋势。

典型例子：

  • 公用事业：自来水、电力、天然气、电信等基础设施行业——固定成本（管道、电网、基站）极高，边际成本极低
  • 铁路运输：铁轨铺设的固定成本极高，额外的运输边际成本很低

关键判断标准：如果市场容量小于最小有效规模（MES）的两倍，自然垄断就会出现。

图形特征：自然垄断的LAC曲线在市场需求范围内持续下降，即成本弱增性（Subadditivity）。数学表达为：对于任意产量Q₁和Q₂（Q₁+Q₂=Q），有C(Q) < C(Q₁) + C(Q₂)。

贵州历年高频考点：自然垄断是高频考点，2020年8月、2021年10月、2022年4月均以单选题或名词解释形式考查。注意自然垄断与资源垄断、政府垄断的区别。

三、垄断厂商的需求曲线和收益曲线

3.1 需求曲线

垄断厂商面临的是整个市场的需求曲线，是一条向右下方倾斜的曲线。这意味着：

  • 垄断厂商要想增加销售量，必须降低价格
  • 垄断厂商是价格制定者（Price Maker）

垄断厂商的需求曲线函数：P = P(Q)，其中P随Q的增加而减少。

3.2 边际收益与平均收益

对于垄断厂商，由于需求曲线向右下方倾斜，增加一单位产量带来的价格下降不仅适用于新增的产量，也适用于所有原已销售的产量，因此：

MR < P = AR（除Q = 0外）

具体数学关系：

  • 总收益（TR） = P(Q) × Q
  • 平均收益（AR） = TR/Q = P(Q)，AR曲线与需求曲线重合
  • 边际收益（MR） = dTR/dQ = P + Q × dP/dQ

由于dP/dQ < 0（需求定律），所以MR < P。

线性需求曲线下的MR曲线：

如果需求曲线为P = a - bQ（线性需求），则：

  • TR = P×Q = aQ - bQ²
  • MR = dTR/dQ = a - 2bQ

重要结论：当需求曲线为直线时，MR曲线的斜率是需求曲线斜率的2倍。MR曲线在横轴上的截距是需求曲线在横轴上截距的一半。

需求和边际收益的关系图：

  • 需求曲线（AR曲线）向右下方倾斜
  • MR曲线位于需求曲线的下方
  • 当MR = 0时，TR达到最大值
  • 当MR > 0时，TR随Q增加而增加
  • 当MR < 0时，TR随Q增加而减少

四、垄断厂商的短期均衡

4.1 利润最大化条件

垄断厂商的利润最大化条件同样是MR = MC（与完全竞争厂商相同），但不同之处在于垄断厂商的价格不等于MR，而是高于MR。

短期均衡条件：

  • MR = SMC（利润最大化的必要条件）
  • 产量Q*由MR = SMC的交点决定
  • 价格P由需求曲线上对应于Q的点决定

垄断厂商的价格大于其边际成本：P > MR = MC，这与完全竞争市场P = MC形成鲜明对比。

4.2 短期均衡的三种情况

情况一：获得超额利润（P > SAC）

当需求旺盛，价格高于平均总成本时，垄断厂商获得超额利润。由于存在进入壁垒，超额利润可以长期维持。

情况二：获得正常利润（P = SAC）

当价格恰好等于平均总成本时，经济利润为零。

情况三：亏损（P < SAC）

短期内，垄断厂商也可能亏损（例如固定成本过高或需求不足），但只要P > AVC就会继续生产。但在长期中，如果无法扭亏为盈，垄断厂商会退出该行业。

4.3 垄断厂商的供给曲线

垄断厂商不存在明确的供给曲线。这是因为在垄断市场中，产量和价格之间的关系不是一一对应的——同一产量可以对应不同价格，同一价格可以对应不同产量（取决于需求曲线的形状和位置）。

垄断厂商没有供给曲线的原因在于，垄断厂商是价格制定者，其产量决策同时受需求条件和成本条件的影响，不存在独立于需求曲线的产量与价格之间的函数关系。

五、垄断的长期均衡

在长期中，垄断厂商可以调整生产规模（改变工厂规模），但由于存在进入壁垒，不会有新厂商进入。因此：

长期均衡条件：MR = LMC = SMC

与完全竞争不同，垄断厂商在长期中可能持续获得超额利润（即P > LAC），因为进入壁垒阻止了新厂商进入以消除超额利润。

六、垄断的效率损失

6.1 垄断的无谓损失（Deadweight Loss of Monopoly）

与完全竞争相比，垄断市场造成资源配置效率损失：

  • 完全竞争均衡：P = MC，产量为Qc，价格为Pc
  • 垄断均衡：MR = MC，产量为Qm（< Qc），价格为Pm（> Pc）

无谓损失（DWL） 产生的原因：

  • 垄断厂商通过限制产量、提高价格来获取超额利润
  • 从Qm到Qc之间的产量，消费者愿意支付的价格（需求价格）大于生产的边际成本（MC），这些"本应发生的交易"因垄断而无法发生
  • DWL = ½ × (Pm - Pc) × (Qc - Qm)（近似计算）

6.2 垄断导致的福利转移

垄断除了造成无谓损失外，还导致福利从消费者向生产者转移：

  • 消费者剩余的减少：由于价格上涨和产量减少，消费者剩余大幅减少
  • 生产者剩余的增加（垄断利润）：一部分消费者剩余转化为垄断利润
  • 无谓损失（社会净损失）：消费者剩余的减少并没有全部转化为生产者剩余，有一部分永久性地损失了——这就是垄断的社会成本

图形表示：

在垄断均衡图中：

  • 消费者剩余从竞争时的区域A+B+C减少为A
  • 生产者剩余从竞争时的区域D+E变为B+D
  • 其中B是消费者剩余转化为生产者剩余的再分配
  • C+E是无谓损失（DWL）
贵州历年高频考点：垄断的无谓损失是高频计算和图形分析考点，2020年8月、2022年10月均以计算题或简答题形式考查。要能够画出图形并计算无谓损失。

七、垄断厂商的价格歧视

价格歧视（Price Discrimination） 是指垄断厂商对同一产品向不同消费者收取不同价格的行为。

7.1 实施价格歧视的条件

  • 厂商必须具有市场势力（能够控制价格）
  • 不同消费者的需求弹性不同
  • 市场可以有效分割，防止转售（套利）

7.2 一级价格歧视（完全价格歧视）

一级价格歧视是指垄断厂商对每单位产品都按照消费者的最高保留价格（Reservation Price） 出售。

结果：

  • 垄断厂商获得全部消费者剩余
  • 产量扩大到P = MC处（与完全竞争产量相同）
  • 无谓损失为零——实现了帕累托最优
  • 但全部剩余归生产者所有，消费者剩余为零

现实中不常见：因为厂商无法知道每个消费者的保留价格。

7.3 二级价格歧视

二级价格歧视是指垄断厂商根据消费者购买数量的不同收取不同的价格（批量折扣）。

典型例子：电费阶梯计价——用电量越大，每度电的价格越低（或越高）；超市的"买三送一"优惠。

结果：消费者可以根据自己的需求选择不同的价格-数量组合，实现了自我选择（Self-selection），产量比单一价格垄断更高。

7.4 三级价格歧视

三级价格歧视是指垄断厂商将消费者分为不同的群体（子市场），对不同群体收取不同的价格，但在同一群体内收取相同价格。

定价原则：

  • 在需求弹性较大的子市场定价较低
  • 在需求弹性较小的子市场定价较高
  • 不同子市场的MR相等且等于MC

数学推导：垄断厂商在两个子市场1和2中销售，总利润最大化条件：

MR₁ = MR₂ = MC(Q₁+Q₂)

由于MR = P(1 - 1/|E|)，可得：

P₁/P₂ = (1 - 1/|E₂|)/(1 - 1/|E₁|)

经典例子：

  • 学生票/老年票 vs 普通票：学生和老年人需求弹性大，票价低
  • 国内机票 vs 国际机票：国际市场弹性大
  • 早场电影优惠 vs 晚场全价：晚场需求弹性小
贵州历年高频考点：三级价格歧视的定价原则和图形分析在贵州自考中常以简答题或计算题形式出现，2021年4月、2022年4月均考过。记住关键公式：MR₁ = MR₂ = MC。

八、例题讲解

例题1：某垄断厂商面临的需求函数为P = 120 - 3Q，总成本函数为TC = Q² + 20Q + 100。

（1）求利润最大化时的产量、价格和利润

（2）求完全竞争条件下的产量和价格（假设MC即为供给曲线）

（3）计算垄断造成的无谓损失

解：

（1）MR = dTR/dQ = d(P×Q)/dQ = d(120Q - 3Q²)/dQ = 120 - 6Q

MC = dTC/dQ = 2Q + 20

利润最大化：MR = MC

120 - 6Q = 2Q + 20

100 = 8Q

Qm = 12.5

Pm = 120 - 3×12.5 = 120 - 37.5 = 82.5

利润πm = TR - TC = 82.5×12.5 - (12.5² + 20×12.5 + 100)

= 1031.25 - (156.25 + 250 + 100)

= 1031.25 - 506.25 = 525

（2）完全竞争下：P = MC

120 - 3Q = 2Q + 20

100 = 5Q

Qc = 20

Pc = 120 - 3×20 = 60

（3）无谓损失 = 三角形面积

DWL = ½ × (Pm - Pc) × (Qc - Qm) = ½ × (82.5 - 60) × (20 - 12.5)

= ½ × 22.5 × 7.5 = 84.375

例题2：实施三级价格歧视的垄断厂商面临两个子市场，子市场1的需求函数为P₁ = 100 - 2Q₁，子市场2的需求函数为P₂ = 80 - Q₂，总成本函数为TC = 10(Q₁+Q₂) + 200。求最优价格和产量。

解：

MR₁ = 100 - 4Q₁

MR₂ = 80 - 2Q₂

MC = 10

三级价格歧视条件：MR₁ = MR₂ = MC

100 - 4Q₁ = 10，得Q₁ = 22.5，P₁ = 100 - 2×22.5 = 55

80 - 2Q₂ = 10，得Q₂ = 35，P₂ = 80 - 35 = 45

总利润π = 55×22.5 + 45×35 - [10×(22.5+35) + 200]

= 1237.5 + 1575 - (575 + 200)

= 2812.5 - 775 = 2037.5

【下午：公共经济学——外部性的治理】

一、外部性的治理思路概述

外部性导致市场失灵，需要政府干预或制度创新来矫正。外部性的治理主要可分为三大类：

  • 市场方案：通过产权界定和协商（科斯定理）
  • 政府干预方案：庇古税/补贴、命令控制型管制
  • 混合方案：可交易的排污许可证

二、政府的直接管制——命令与控制

命令与控制（Command and Control, CAC） 是指政府通过法律法规直接规定经济主体的行为标准。

2.1 管制的形式

（1）技术标准：政府规定企业必须采用特定的污染控制技术

  • 例如：要求所有燃煤电厂安装脱硫装置
  • 优点：执行效果明确
  • 缺点：没有考虑到不同企业的治理成本差异，缺乏灵活性

（2）绩效标准：政府规定企业排放的最大限量

  • 例如：规定每单位产量的最大排污量
  • 优点：给企业一定的灵活性来选择污染控制方式
  • 缺点：政府需要获取企业治理成本的信息

（3）禁令：政府直接禁止某些有害行为

  • 例如：禁止使用含铅汽油、禁止生产含氟利昂的冰箱
  • 适用：危害极大且无法通过其他方式有效控制的情况

2.2 直接管制的优缺点

优点：

  • 效果直接、确定——"说停就停"
  • 在危害极其严重的情况下，禁令是最迅速的手段

缺点：

  • 信息要求高：需要政府掌握每个企业的边际治理成本信息
  • 缺乏灵活性：对所有企业"一刀切"，没有考虑治理成本的差异
  • 缺乏激励：企业达到标准后没有动力进一步减少污染
  • X-低效率：缺乏竞争压力

三、庇古税与庇古补贴（市场激励方案）

庇古（Arthur Cecil Pigou）在1920年出版的《福利经济学》中提出，通过征税和补贴来矫正外部性，使私人成本与社会成本相一致。

3.1 庇古税（Pigouvian Tax）

对产生负外部性的行为征收的税收，税额等于边际外部成本（MEC）。

原理：对污染企业每单位产出征收t = MEC的税收，使企业的私人边际成本上升到社会边际成本水平：

MPC + t = MPC + MEC = MSC

此时企业的利润最大化条件变为：MPC + t = P，企业会自动选择社会最优产量。

图形分析：

  • 征税前：企业按MPC = P生产Qₚ（产量过多）
  • 征税后：企业按MPC + t = P生产Qₛ（社会最优）
  • 税收收入R = t × Qₛ

庇古税的优点：

  • 效率性：不同治理成本的企业可以灵活选择——治理成本低的企业多治理（少交税），治理成本高的企业少治理（多交税），总体治理成本最小
  • 激励性：企业有持续动力开发更清洁的生产技术以减少税负
  • 收入效应：政府获得税收收入

庇古税的缺点：

  • 信息难题：政府很难准确知道MEC的大小
  • 政治阻力：企业往往会游说反对征税
贵州历年高频考点：庇古税的原理和图形分析是贵州自考的必考内容，2020年8月、2021年10月、2022年4月均以简答题或论述题形式考查。特别要注意庇古税与后面可交易排污许可证的比较。

3.2 庇古补贴（Pigouvian Subsidy）

对产生正外部性的行为给予补贴，补贴额等于边际外部收益（MEB）。

原理：对具有正外部性的活动（如教育、研发）每单位给予s = MEB的补贴，使私人边际收益上升到社会边际收益水平：

MPB + s = MPB + MEB = MSB

此时个人按最大化原则会选择社会最优水平。

典型应用：

  • 教育补贴：政府补贴教育，使个人受教育年限达到社会最优水平
  • 研发补贴：政府补贴企业的研发活动，因为研发成果有正外部性（技术外溢）
  • 防疫补贴：补贴疫苗接种，提高接种率

四、可交易的排污许可证（Cap and Trade）

可交易的排污许可证（Tradable Pollution Permits） 是近年来广泛采用的外部性治理市场工具，兼具管制和市场激励的特点。

4.1 基本机制

  • 设定总量上限（Cap）：政府确定总的允许排污量（等于社会最优水平）
  • 发放许可证：政府向企业发放污染许可证（可免费分配或拍卖）
  • 允许交易（Trade）：企业之间可以自由买卖许可证

4.2 经济效率分析

假设有两家企业A和B，减排的单位成本不同：

  • 企业A：减排成本低（新技术，治理容易）
  • 企业B：减排成本高（旧设备，治理困难）

通过许可证交易：

  • 企业A减少污染量，将多余的许可证出售给企业B
  • 企业B购买许可证，避免高成本的减排
  • 交易价格介于两家企业的边际治理成本之间

最终结果：在给定的总排污上限下，治理成本最小化——所有企业的边际治理成本趋于相等（等于许可证的市场价格）。

与庇古税的比较：

比较维度庇古税可交易排污许可证
价格政府设定税率（价格确定）由市场决定许可证价格
数量由市场决定减排量（数量不确定）政府设定排污上限（数量确定）
信息要求需要知道MEC（难度大）需要知道社会最优排污量（但可以不那么精确，可调整）
不确定性减排量不确定，可能过多或过少排污量确定，但价格不确定
动态激励有持续减排激励有持续减排激励
政治可行性企业反对（直接成本）相对容易接受（初始免费分配）

关键：在不确定条件下，如果边际社会成本曲线（MSC）比较陡峭（即污染损害的边际成本随污染量增加而急剧上升），则数量工具（许可证）优于价格工具（税收）；如果边际治理成本曲线比较陡峭，则价格工具（税收）优于数量工具。这就是韦茨曼定理（Weitzman Theorem）的核心思想。

4.3 实际应用

全球最大的实践：欧盟排放交易体系（EU ETS）——全球最大的碳排放权交易市场，覆盖电力、钢铁、炼油等高排放行业。

中国实践：中国自2013年起在深圳、北京、上海等七个省市开展碳排放权交易试点，2021年启动全国碳排放权交易市场，首批纳入发电行业。

贵州历年高频考点：可交易排污许可证的机制和优点在贵州自考中常以简答题或论述题形式出现，2022年10月刚考过"比较庇古税和可交易排污许可证的异同"。

五、各种治理方案的比较

治理方案理论基础优点缺点
科斯定理产权理论无需政府干预，尊重市场自发秩序交易成本高时无效，搭便车问题

六、例题讲解

例题：假设某行业有两家企业，企业1的边际治理成本函数为MC₁ = 2Q₁，企业2的边际治理成本函数为MC₂ = 4Q₂（其中Q是污染减少量）。政府决定将总污染减少量定为30单位。请分析：

（1）如何以最小总成本实现30单位的污染减少？各自的减少量和总成本是多少？

（2）如果政府采用免费发放可交易排污许可证的方式实现该目标，许可证市场会如何运作？

解：

（1）最小成本的条件是各企业的边际治理成本相等：MC₁ = MC₂

2Q₁ = 4Q₂

Q₁ = 2Q₂

且Q₁ + Q₂ = 30

2Q₂ + Q₂ = 30

3Q₂ = 10

Q₂ = 10，Q₁ = 20

总治理成本：

TC₁ = ∫₀²⁰ 2Q dQ = Q²|₀²⁰ = 400

TC₂ = ∫₀¹⁰ 4Q dQ = 2Q²|₀¹⁰ = 200

TC = 400 + 200 = 600

（2）如果政府发放30单位的可交易排污许可证：

  • 企业1的治理成本较低，会多治理污染，出售多余的许可证
  • 企业2的治理成本较高，会购买许可证
  • 许可证的均衡价格在MC₁和MC₂之间，最终使MC₁ = MC₂ = 许可证价格
  • 当MC₁ = MC₂ = P时，Q₁ + Q₂ = 30

2Q₁ = 4Q₂，Q₁ = 2Q₂

代入3Q₂ = 30，Q₂ = 10，Q₁ = 20

P = MC₁ = 2×20 = 40（许可证均衡价格）

  • 这就是科斯定理在环保领域的应用——通过产权交易实现效率

经济学原理部分

1.（单选题） 垄断厂商利润最大化的条件是：

A. P = MC

B. MR = MC

C. AR = MC

D. P = AC

答案：B

解析：垄断厂商利润最大化的条件是MR = MC，这与完全竞争厂商相同。但区别在于，完全竞争市场中P = MR，所以条件简化为P = MC；垄断市场中MR < P，所以条件是MR = MC，此时P > MC。

2.（单选题） 自然垄断产生的主要原因是：

A. 政府对特定企业的特许经营权

B. 企业控制了关键资源

C. 显著的规模经济

D. 专利权保护

答案：C

解析：自然垄断是指由于规模经济的存在，一个企业生产全部市场需求的平均成本低于多个企业分别生产的平均成本。A（特许经营权）是政府创造的垄断，B（资源控制）是资源垄断，D（专利）是政府创造的垄断。自然垄断的关键特征是长期平均成本递减和成本弱增性。

3.（多选题） 垄断造成的效率损失包括：

A. 消费者剩余减少

B. 无谓损失

C. 生产者剩余增加

D. 产量低于完全竞争水平

E. 价格高于完全竞争水平

答案：ABCDE

解析：垄断通过限产提价获取超额利润，导致：消费者剩余减少（部分转化为生产者剩余，部分成为无谓损失）、生产者剩余增加（但小于消费者剩余的减少）、产量低于完全竞争水平（Qm < Qc）、价格高于完全竞争水平（Pm > Pc）、产生无谓损失（DWL为社会净损失）。

4.（计算题） 某垄断厂商的总成本函数为TC = 50 + 20Q，面临的需求函数为P = 100 - 2Q。求：

（1）利润最大化时的产量、价格和利润

（2）垄断造成的无谓损失

答案与解析：

（1）TR = P×Q = 100Q - 2Q²

MR = dTR/dQ = 100 - 4Q

MC = dTC/dQ = 20

MR = MC：100 - 4Q = 20

Qm = 20

Pm = 100 - 2×20 = 60

利润πm = 60×20 - (50 + 20×20) = 1200 - 450 = 750

（2）完全竞争下：P = MC

100 - 2Q = 20

Qc = 40

Pc = 20

DWL = ½ × (Pm - Pc) × (Qc - Qm) = ½ × (60 - 20) × (40 - 20) = ½ × 40 × 20 = 400

5.（简答题） 垄断厂商实行三级价格歧视时如何定价？请简述其定价原则。

答案：三级价格歧视是指垄断厂商将消费者分为不同群体（子市场），对不同群体收取不同价格。定价原则是：在各子市场上，边际收益相等且等于总的边际成本，即MR₁ = MR₂ = MC。由于MR = P(1 - 1/|Ed|)，因此需求弹性越大的子市场定价越低，需求弹性越小的子市场定价越高。通过这种方式，垄断厂商从不同弹性的消费者群体中获取更多消费者剩余，实现利润最大化。三级价格歧视需要满足三个条件：厂商有市场势力、不同群体需求弹性不同、市场可以有效分割防止转售。

公共经济学部分

1.（单选题） 庇古税的核心思想是：

A. 对污染企业进行罚款

B. 征收等于边际外部成本的税收

C. 对污染企业实行国有化

D. 免费发放污染许可证

答案：B

解析：庇古税是对产生负外部性的活动征收的税收，税额等于边际外部成本（MEC），使私人成本上升到社会成本水平，从而矫正市场失灵。注意庇古税区别于罚款——罚款是惩罚性的，而庇古税是矫正性的。

2.（单选题） 与直接管制相比，可交易排污许可证制度的主要优势是：

A. 更容易确定排污上限

B. 可以实现治理总成本最小化

C. 不需要政府监督

D. 企业不会有减排动力

答案：B

解析：可交易排污许可证制度允许企业在许可证市场上交易，治理成本低的企业会多减排并出售多余许可证，治理成本高的企业会购买许可证以减少减排量，最终使所有企业的边际治理成本相等（等于许可证价格），实现总治理成本最小化。A错误，确定上限同样需要信息；C错误，政府仍需监督执行；D错误，许可证制度同样有减排动力。

3.（多选题） 以下属于庇古税/补贴应用的是：

A. 对香烟征收高额消费税

B. 对大学生提供国家助学金

C. 对企业研发费用给予税收抵免

D. 要求工厂安装脱硫装置

E. 对污染企业征收排污费

答案：ABCE

解析：A香烟征收高额消费税是针对吸烟的负外部性（二手烟损害他人健康）征收的庇古税；B国家助学金是针对教育的正外部性提供的庇古补贴；C研发税收抵免是针对技术外溢的正外部性提供的补贴；E排污费是针对污染的负外部性征收的庇古税。D要求安装脱硫装置属于命令控制型管制，不是激励型的庇古方案。

4.（简答题） 比较庇古税和可交易排污许可证在治理环境污染方面的异同。

答案：相同点：两者都是基于市场的激励型环境政策工具，都能实现治理总成本最小化和持续减排激励。不同点：（1）价格vs数量：庇古税通过设定税率（价格）来影响污染量，最终减排量由市场决定；可交易许可证通过设定总量上限（数量）来控制污染，最终许可证价格由市场决定。（2）信息要求：庇古税需要政府知道边际外部成本来确定税率；可交易许可证需要政府知道社会最优排污量来确定上限。（3）不确定性：庇古税下减排量不确定，许可证下价格不确定。（4）政治可行性：庇古税面临较大的政治阻力（企业反对增税），可交易许可证特别是免费发放的许可证更容易被企业接受。根据韦茨曼定理，当边际社会成本曲线较陡峭时，数量工具（许可证）更优；当边际治理成本曲线较陡峭时，价格工具（庇古税）更优。

5.（简答题） 简述用科斯定理解决外部性问题需要满足什么条件？这些条件在现实中为什么难以实现？

答案：科斯定理指出，只要产权界定清晰且交易成本为零，当事人之间通过自愿协商就可以实现资源的帕累托最优配置。需要满足两个核心条件：（1）产权界定清晰——明确谁拥有污染权或清洁权；（2）交易成本为零——包括信息成本、谈判成本、执行成本等。在现实中，这些条件难以实现因为：（1）交易成本往往很高，特别是涉及众多利益相关方时（如空气污染涉及成千上万居民）；（2）信息不对称——双方都可能隐瞒真实成本和收益以获取更有利的谈判结果；（3）搭便车问题——在涉及多方的集体谈判中，每个人都不愿承担谈判成本；（4）策略性行为——一方可能故意拖延谈判以获取更优条件；（5）初始产权分配涉及公平问题——将污染权赋予企业还是居民关系到收入分配。因此，科斯定理虽然提供了重要的理论洞见，但在实际外部性治理中往往需要政府干预的配合。

【今日学习提示】

  • 垄断市场是高频计算题考点，必须熟练运用MR = MC的利润最大化条件进行产量、价格和利润的计算。
  • 垄断的无谓损失计算要掌握：DWL = ½ × ΔP × ΔQ，并理解垄断如何通过限产提价导致效率损失。
  • 三级价格歧视的定价规则（MR₁ = MR₂ = MC）和需求弹性与价格的关系（弹性大→价格低）是重要考点。
  • 庇古税与可交易排污许可证的比较是公共经济学的大题考点，经常以论述题形式出现，需要掌握两者的机制、优缺点和适用条件。
  • 韦茨曼定理（MSC陡峭→选择数量工具，MC治理陡峭→选择价格工具）是较深入的分析框架，在论述题中运用可以提升答案质量。

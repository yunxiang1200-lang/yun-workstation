【上午：经济学原理（中级）——完全竞争市场：短期均衡】

一、完全竞争市场的含义与条件

完全竞争市场（Perfectly Competitive Market） 是指一种不受任何阻碍和干扰的市场结构，是经济学中市场结构的理想模型。它需要满足以下四个严格条件：

1. 市场上有大量买者和卖者。每个参与者都是价格接受者（Price Taker），即单个买者或卖者的交易量相对于整个市场来说微不足道，无法影响市场价格。这就好比农贸市场中成千上万的菜农，任何一位菜农的蔬菜供给量变动不会影响整个市场的菜价。

2. 产品是同质的（Homogeneous Product）。所有厂商生产的产品在质量、规格、包装等方面完全相同，消费者无法区分产品来自哪个厂商。例如，大米、小麦等农产品，不同农户生产的大米几乎没有差别。

3. 资源完全自由流动（Free Entry and Exit）。厂商可以无障碍地进入或退出该行业，不存在任何进入壁垒（如专利、政府特许、规模经济等）。这意味着当行业有利可图时，新厂商会迅速涌入；当行业亏损时，原有厂商可以迅速撤出。

4. 完全信息（Perfect Information）。所有市场参与者都掌握与交易相关的全部信息，包括产品的价格、质量、生产技术等。消费者知道哪里有最低价格，厂商知道最先进的生产技术。

贵州历年高频考点：完全竞争市场的四个条件几乎每年都考，常以多选题或简答题形式出现。2021年4月、2022年10月均考查了"价格接受者"的概念。

二、完全竞争厂商面临的需求曲线

在完全竞争市场中，单个厂商面临的需求曲线是一条水平线，即具有完全弹性（Elasticity = ∞）。这是因为厂商是价格接受者，只能按市场决定的价格P出售产品，若厂商试图以高于P的价格出售，消费者会立即转向其他厂商购买；而厂商也没有必要以低于P的价格出售，因为在P的价格下他可以卖出任意数量的产品。

图形描述：

  • 整个市场的需求曲线D是一条向右下方倾斜的曲线（符合需求定律）
  • 但单个厂商面临的需求曲线d是一条位于市场价格P*处的水平线
  • 这意味着P = MR = AR，即价格等于边际收益等于平均收益

数学推导：

  • 总收益（TR） = P × Q，由于P是常数，TR是一条从原点出发的射线
  • 平均收益（AR） = TR / Q = P，AR曲线与需求曲线重合
  • 边际收益（MR） = dTR / dQ = P，MR曲线也与需求曲线重合
  • 因此在完全竞争市场中：P = MR = AR = d

三、完全竞争厂商的短期均衡

3.1 利润最大化的条件

厂商的目标是利润最大化（Profit Maximization）。利润函数为：

  • π = TR - TC
  • 利润最大化的必要条件（一阶条件）：MR = MC
  • 在完全竞争市场中，MR = P，因此利润最大化条件简化为：P = MC

为什么要满足MR = MC？我们可以这样理解：

  • 当MR > MC时，多生产一单位产品带来的收益大于成本，增加产量可以增加利润
  • 当MR < MC时，多生产一单位产品带来的收益小于成本，减少产量可以增加利润
  • 只有当MR = MC时，利润达到最大值

二阶条件：d²π/dQ² < 0，即MC曲线的斜率大于MR曲线的斜率（MC从下方穿过MR）。

3.2 短期均衡的三种情况

在短期内，厂商有固定成本（FC），不能自由退出市场。根据市场价格P与平均成本的关系，短期均衡可分为三种情况：

情况一：获得超额利润（P > SAC）

当市场价格高于厂商的平均总成本（SAC）时，厂商获得超额利润（经济利润）。

  • 均衡条件：P = SMC，且P > SAC
  • 利润量：π = (P - SAC) × Q*，即图中矩形面积
  • 此时厂商有动力扩大生产，但受限于短期生产能力

情况二：获得正常利润（P = SAC）——盈亏平衡点

当市场价格等于厂商的平均总成本最低点时，厂商获得正常利润（经济利润为零）。

  • 盈亏平衡点（Break-even Point）是SAC曲线的最低点
  • 此时P = SAC = SMC，厂商的经济利润为零，但包括了所有隐性成本（正常利润）
  • 之所以叫"正常利润"，是因为厂商获得了足以留在行业中的回报

情况三：亏损但继续生产（AVC < P < SAC）

当市场价格低于SAC但高于平均可变成本（AVC）时，厂商处于亏损状态，但继续生产。

  • 为什么亏损还要生产？因为固定成本是沉淀成本（Sunk Cost），无论是否生产都已支出
  • 只要P > AVC，厂商的收益除了弥补全部可变成本外，还能弥补一部分固定成本
  • 停产的话，全部固定成本都会亏损，亏损额 = FC
  • 继续生产的话，亏损额 = FC - (P - AVC) × Q，小于FC
  • 因此继续生产比停产损失更小

情况四：停止营业点（P = AVC）——停业点（Shutdown Point）**

  • 停业点是AVC曲线的最低点
  • 当P = AVC的最低点时，厂商的收益刚好弥补全部可变成本，固定成本全部亏损
  • 此时生产与不生产的结果相同，亏损都等于全部固定成本

情况五：停产（P < AVC）

当市场价格低于AVC的最低点时，厂商生产不仅无法弥补固定成本，连可变成本都无法全部弥补，此时应当立即停产，亏损止于固定成本。

贵州历年高频考点：停止营业点和盈亏平衡点的区别是贵州自考的必考内容，2020年8月、2021年10月、2022年4月均以单选题或名词解释形式考查。特别注意：短期停业点 ≠ 长期退出点。

3.3 完全竞争厂商的短期供给曲线

完全竞争厂商的短期供给曲线就是SMC曲线位于AVC曲线最低点以上的部分。

  • 这是因为厂商的利润最大化条件P = MC决定了在每一个市场价格P下，厂商愿意并且能够提供的产量Q
  • 当P ≥ AVC最小值时，厂商会生产，供给量与价格呈正相关
  • 当P < AVC最小值时，厂商停产，供给量为零

整个行业的短期供给曲线是所有厂商短期供给曲线的水平加总。

四、例题讲解

例题1：某完全竞争厂商的总成本函数为TC = Q³ - 6Q² + 30Q + 40，求：

（1）该厂商的SMC、AVC、SAC函数

（2）该厂商的停止营业点

（3）当市场价格P = 66时，厂商的最优产量和利润

解：

（1）SMC = dTC/dQ = 3Q² - 12Q + 30

AVC = TVC/Q = (Q³ - 6Q² + 30Q)/Q = Q² - 6Q + 30

SAC = TC/Q = Q² - 6Q + 30 + 40/Q

（2）停止营业点是AVC的最低点，AVC' = 2Q - 6 = 0，得Q = 3

代入AVC函数：AVC最小 = 3² - 6×3 + 30 = 9 - 18 + 30 = 21

即当P = 21时，厂商处于停止营业点

（3）利润最大化条件：P = SMC

66 = 3Q² - 12Q + 30

3Q² - 12Q - 36 = 0

Q² - 4Q - 12 = 0

(Q + 2)(Q - 6) = 0

Q = 6（舍去负值）

利润π = TR - TC = 66×6 - (6³ - 6×6² + 30×6 + 40)

= 396 - (216 - 216 + 180 + 40)

= 396 - 220

= 176

因此当P = 66时，最优产量为6单位，利润为176（获得超额利润）。

【下午：公共经济学——公共产品理论】

一、公共产品的定义与特征

公共产品（Public Goods） 是指具有非竞争性（Non-rivalry）和非排他性（Non-excludability）的产品。这是公共经济学的核心概念，由美国经济学家保罗·萨缪尔森（Paul Samuelson）在1954年发表的《公共支出的纯理论》中首次系统阐述。

1.1 两大基本特征

特征一：非竞争性（Non-rivalry in Consumption）

非竞争性是指一个人对某种产品的消费不会减少其他人对该产品的消费数量或质量。换句话说，增加一个消费者的边际成本为零。

举例：灯塔信号——一艘船使用灯塔导航并不妨碍其他船只同时使用；国防——新增一名公民享受国防保护并不会降低原有公民的保护程度；电视信号——一个人收看电视节目不会影响他人收看。

特征二：非排他性（Non-excludability in Consumption）

非排他性是指无法将某人排除在某种产品的消费之外，或者排除的成本高得不可行。也就是说，技术上无法实现排他，或者排他的经济成本过高。

举例：国防——国家无法只保护交税的公民而不保护未交税的公民；空气污染治理——改善了空气质量无法只让部分人呼吸；街道照明——不能只照亮付费的路人。

1.2 产品分类矩阵

根据是否具备非竞争性和非排他性，可将产品分为四类：

分类排他性（有）排他性（无）
竞争性（有）私人物品（食品、衣物、汽车）公共资源（公共牧场、渔场、地下水）
竞争性（无）俱乐部产品（有线电视、收费公路、健身房）纯公共产品（国防、灯塔、基础研究）
  • 纯公共产品（Pure Public Goods）：同时具备非竞争性和非排他性，如国防、灯塔、基础科学研究
  • 准公共产品（Quasi-public Goods）：只具备其中一个特征，包括：
  • 俱乐部产品（Club Goods）：有排他性但无竞争性，如有线电视、收费公路
  • 公共资源（Common Resources）：有竞争性但无排他性，如公共渔场、公共牧场
贵州历年高频考点：产品分类矩阵是高频考点，2020年8月、2021年4月、2022年10月均以单选题或多选题形式考查。特别注意俱乐部产品和公共资源的区分。

二、公共产品与市场失灵

2.1 搭便车问题（Free Rider Problem）

由于公共产品具有非排他性，每个人都希望他人付费购买公共产品，而自己免费享用。这种"搭便车"行为导致市场无法有效提供公共产品。

搭便车问题的数学表述：

假设一个社区有n个人，公共产品的总供给量为G，第i个人的贡献为gᵢ，G = Σgᵢ。

第i个人的效用函数为：Uᵢ(xᵢ, G)，其中xᵢ是私人物品消费量。

预算约束为：xᵢ + gᵢ = wᵢ（收入）。

每个人最大化自己效用的结果是贡献不足（Under-provision），因为每个人都希望别人多贡献而自己"搭便车"。

2.2 公共产品导致的市场失灵

市场失灵（Market Failure） 是指市场机制无法实现资源配置的帕累托最优（Pareto Optimality）。公共产品导致的市场失灵表现为：

  • 供给不足：由于搭便车行为，私人部门提供的公共产品数量远低于社会最优水平
  • 价格信号缺失：公共产品的非竞争性使得边际成本为零，但市场价格无法为零（厂商无法收回成本）
  • 显示偏好困难：消费者没有动机真实表达对公共产品的偏好（偏好隐瞒问题）

三、公共产品的有效供给条件

3.1 萨缪尔森条件（Samuelson Condition）

对于纯公共产品，有效供给条件是所有消费者的边际替代率之和等于生产的边际转换率：

ΣMRSᵢ = MRT

其中MRSᵢ是第i个消费者对公共产品和私人物品的边际替代率，MRT是生产中的边际转换率。

与私人物品的有效供给条件（每个人的MRS都等于MRT）不同，公共产品的有效供给条件要求所有人的MRS之和等于MRT。这是因为公共产品可以被所有人同时消费，每个人的边际收益需要加总起来与边际成本比较。

3.2 林达尔均衡（Lindahl Equilibrium）

林达尔均衡是瑞典经济学家埃里克·林达尔（Erik Lindahl）提出的公共产品自愿交换模型。该模型试图模拟市场竞争机制来确定公共产品的供给量和每个人的"税收价格"。

  • 假设每个人根据自己从公共产品中获得的边际收益支付不同的"税收价格"
  • 当每个人对公共产品的需求与供给达到一致时，就实现了林达尔均衡
  • 林达尔均衡是帕累托最优的，且实现了"受益原则"——每个人按其受益程度付费

然而，林达尔均衡在实际中难以实现，因为存在偏好隐瞒问题——消费者有激励低报自己的真实偏好以降低自己的税收价格。

贵州历年高频考点：萨缪尔森条件和林达尔均衡在贵州自考中经常以简答题或名词解释形式出现，2021年10月考过"萨缪尔森条件的含义"，2022年4月考过"林达尔均衡的基本思想"。

经济学原理部分

1.（单选题） 在完全竞争市场中，单个厂商面临的需求曲线是：

A. 向右下方倾斜的曲线

B. 向左下方倾斜的曲线

C. 一条水平线

D. 一条垂直线

答案：C

解析：完全竞争厂商是价格接受者，只能按市场决定的价格出售产品，因此面临的需求曲线是一条位于市场价格处的水平线（完全弹性）。选项A描述的是整个市场的需求曲线，不是单个厂商的需求曲线。

2.（单选题） 完全竞争厂商短期均衡时，如果P < AVC的最低点，厂商应当：

A. 继续生产，因为可以弥补部分固定成本

B. 减少产量，使P = MC

C. 立即停产

D. 增加产量，以摊薄固定成本

答案：C

解析：当P < AVC的最低点时，厂商生产不仅无法弥补固定成本，连可变成本都无法全部收回。此时继续生产的亏损大于停产的亏损（停产的亏损等于全部固定成本），因此应当立即停产。这是贵州自考的高频考点。

3.（多选题） 完全竞争市场的条件包括：

A. 市场上有大量买者和卖者

B. 产品存在差异性

C. 资源完全自由流动

D. 买卖双方具有完全信息

E. 存在较高的进入壁垒

答案：ACD

解析：完全竞争市场的四个条件是：大量买者和卖者、产品同质（无差异）、资源自由流动、完全信息。选项B（产品存在差异性）是垄断竞争市场的特征，选项E（高进入壁垒）是垄断市场的特征。注意区分不同市场结构的特征。

4.（计算题） 已知完全竞争市场中某厂商的短期成本函数为STC = 0.1Q³ - 2Q² + 15Q + 10，当前市场价格P = 20，求该厂商利润最大化时的产量和利润。

答案与解析：

（1）求SMC函数：SMC = dSTC/dQ = 0.3Q² - 4Q + 15

（2）利润最大化条件：P = SMC

20 = 0.3Q² - 4Q + 15

0.3Q² - 4Q - 5 = 0

两边乘以10：3Q² - 40Q - 50 = 0

使用求根公式：Q = [40 ± √(1600 + 600)] / 6 = [40 ± √2200] / 6 = [40 ± 46.9] / 6

Q = 14.48 或 Q = -1.15（舍去）

故Q ≈ 14.5

（3）利润：π = TR - TC = 20×14.5 - (0.1×14.5³ - 2×14.5² + 15×14.5 + 10)

= 290 - (0.1×3048.6 - 2×210.25 + 217.5 + 10)

= 290 - (304.9 - 420.5 + 217.5 + 10)

= 290 - 111.9

= 178.1

该厂商利润最大化产量约为14.5单位，利润约为178.1。

5.（简答题） 简述为什么完全竞争厂商的短期供给曲线是SMC曲线在AVC最低点以上的部分。

答案：完全竞争厂商利润最大化的条件是P = SMC。当市场价格P变化时，厂商会根据P = SMC的条件选择最优产量Q*。当P ≥ AVC的最低点时，厂商的收益可以弥补全部可变成本和部分固定成本，因此厂商会选择生产，对应的SMC曲线上的点（P, Q）就是供给曲线上的点。当P < AVC的最低点时，厂商生产连可变成本都无法弥补，因此选择停产，供给量为零。因此，完全竞争厂商的短期供给曲线就是SMC曲线上位于AVC曲线最低点以上的部分，体现了价格与供给量之间的正向关系。

2.（单选题） "搭便车问题"主要源于公共产品的：

A. 竞争性

B. 非竞争性

C. 排他性

D. 非排他性

答案：D

解析：搭便车问题源于公共产品的非排他性。因为无法将不付费者排除在消费之外，所以每个人都有激励不付费而享受他人提供的公共产品，导致市场供给不足。

解析：准公共产品是只具备非竞争性或非排他性其中一个特征的产品。有线电视和收费公路有排他性但无竞争性（俱乐部产品），公共渔场有竞争性但无排他性（公共资源）。A国防是纯公共产品，D面包是私人物品。

4.（简答题） 简述萨缪尔森条件的内容及其经济含义。

答案：萨缪尔森条件是纯公共产品帕累托最优供给的条件，表示为ΣMRSᵢ = MRT，即所有消费者对公共产品与私人物品的边际替代率之和等于公共产品与私人物品生产的边际转换率。经济含义是：公共产品的社会边际收益（所有消费者边际收益之和）等于社会边际成本。与私人物品不同，公共产品可以被所有人同时消费，因此需要将每个人的边际收益加总来与边际成本比较。这是判断公共产品是否实现有效配置的重要标准。

5.（简答题） 什么是林达尔均衡？它为什么在实际中难以实现？

答案：林达尔均衡是林达尔提出的公共产品自愿交换模型，通过模拟市场竞争机制确定公共产品的供给量和每个人的税收价格。在均衡状态下，每个人根据自己的边际收益支付不同价格，且所有人对公共产品供给量达成一致，实现帕累托最优。然而在实际中难以实现，因为存在偏好隐瞒问题：理性的消费者有激励低报自己对公共产品的真实偏好，以降低自己的税收价格，结果导致公共产品供给不足。这就是"搭便车"行为阻碍了林达尔均衡的实现。

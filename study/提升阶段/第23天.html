【上午：经济学原理（中级）——寡头市场（上）】

一、寡头市场的定义与特征

寡头市场（Oligopoly Market） 是指少数几家厂商控制整个行业生产和销售的市场结构。"寡头"一词源于希腊语"oligos"（少数）和"polein"（销售）。寡头市场是介于垄断竞争和完全垄断之间的一种市场结构，也是现实经济中最为常见的市场结构之一。

寡头市场的基本特征：

  • 少数几家大厂商：行业内只有少数几家厂商，每家厂商的市场份额都很大。经济学通常认为，当CR₄（前四家厂商集中度）> 40%或HHI（赫芬达尔指数）> 1000时，该市场属于寡头市场
  • 产品可以同质或差异化：寡头市场分为纯粹寡头（产品同质，如钢铁、水泥）和差别寡头（产品差异化，如汽车、家电）
  • 进入壁垒较高：规模经济、巨额资本需求、专利保护、品牌忠诚度等构成显著的进入障碍
  • 相互依存（Interdependence）：这是寡头市场最显著的特征。由于厂商数量少，每个厂商的决策都会显著影响其他厂商的利润，因此每个厂商在做决策时必须考虑竞争对手的反应

关键概念：相互依存（Mutual Interdependence）

寡头厂商之间具有策略互动（Strategic Interaction）的特征，即一个厂商的价格、产量、广告等决策会显著影响其他厂商的利益，从而引起竞争对手的回应。这类似于下棋——你的每一步都要考虑对手的反应。

由于这一特征，寡头市场没有一个统一的均衡模型。不同的假设条件（竞争对手如何反应）导致不同的模型。

贵州历年高频考点：寡头市场的基本特征特别是"相互依存"在贵州自考中常以单选题或多选题形式考查，2021年4月、2022年10月均涉及。注意区分寡头与垄断竞争的主要区别——相互依存。

二、寡头市场的衡量指标

2.1 集中度（Concentration Ratio, CR）

CRₙ 表示行业内规模最大的前n家厂商的市场份额之和（通常用销售额或产量衡量）。

CR₄ = 前4家厂商的市场份额之和

判断标准：

  • CR₄ ≥ 60%：高度集中的寡头市场
  • CR₄在40%-60%之间：中度集中的寡头市场
  • CR₄ < 40%：竞争性市场

局限性：集中度没有反映厂商规模的分布情况和不平等程度。

2.2 赫芬达尔指数（Herfindahl-Hirschman Index, HHI）

HHI 是行业内所有厂商市场份额的平方和。HHI = ΣSᵢ²（其中Sᵢ是第i家厂商的市场份额，以百分比表示）。

特点：

  • HHI的取值范围：0（完全竞争）到10000（完全垄断，一家厂商占100%）
  • 当市场份额相同时，厂商数量越少，HHI越大
  • 给予大厂商更大的权重（平方），更灵敏地反映市场份额的不平等

美国司法部的标准：

  • HHI < 1500：市场集中度低
  • HHI 1500-2500：市场集中度中等
  • HHI > 2500：市场高度集中

举例：

  • 4家厂商各占25%：HHI = 4×625 = 2500
  • 1家占70%，其余30家各占1%：HHI = 4900 + 30×1 = 4930
  • 10家各占10%：HHI = 10×100 = 1000
市场类型HHI范围CR₄范围

垄断竞争< 1000< 40%

三、寡头市场的基本模型（上）

3.1 古诺模型（Cournot Model）

古诺模型由法国经济学家奥古斯丁·古诺（Augustin Cournot）在1838年提出，是寡头理论的第一个正式模型。古诺模型假设每个厂商以竞争对手的产量不变为条件来决定自己的产量。

基本假设：

  • 市场上只有两家厂商（双寡头，Duopoly）
  • 产品同质
  • 每家厂商将竞争对手的产量视为给定（数量竞争）
  • 两家厂商同时做出产量决策
  • 边际成本为常数（MC₁ = MC₂ = c）

反应函数（Reaction Function）：

  • 厂商1的最优产量是厂商2产量的函数：Q₁ = R₁(Q₂)
  • 厂商2的最优产量是厂商1产量的函数：Q₂ = R₂(Q₁)

反应函数推导（以线性需求P = a - bQ和MC = c为例）：

市场总产量Q = Q₁ + Q₂，市场价格P = a - b(Q₁ + Q₂)

厂商1的利润函数：π₁ = [a - b(Q₁ + Q₂)]Q₁ - cQ₁

对Q₁求偏导并令其等于0：

∂π₁/∂Q₁ = a - 2bQ₁ - bQ₂ - c = 0

Q₁ = (a - c)/(2b) - Q₂/2

这就是厂商1的反应函数。

同理，厂商2的反应函数为：Q₂ = (a - c)/(2b) - Q₁/2

古诺-纳什均衡（Cournot-Nash Equilibrium）：

两个反应函数的交点即为古诺均衡：

Q₁ = Q₂ = (a - c)/(3b)

总产量Q = 2(a - c)/(3b)

市场价格P = a - bQ = (a + 2c)/3

每个厂商的利润π₁ = π₂ = (a - c)²/(9b)

与完全竞争和垄断的比较：

  • 完全竞争：Qc = (a - c)/b，Pc = c（P = MC）
  • 垄断：Qm = (a - c)/(2b)，Pm = (a + c)/2（MR = MC）
  • 古诺双寡头：QCournot = 2(a - c)/(3b)，PCournot = (a + 2c)/3

产量关系：Qm < Q_Cournot < Qc

价格关系：Pm > P_Cournot > Pc

重要结论：随着寡头厂商数量n的增加，古诺均衡趋近于完全竞争均衡。当n → ∞时，P → MC。

3.2 斯塔克伯格模型（Stackelberg Model）

斯塔克伯格模型由德国经济学家海因里希·冯·斯塔克伯格（Heinrich von Stackelberg）在1934年提出。该模型假设寡头市场存在领导者（Leader）和追随者（Follower）——领导者先决定产量，追随者观察到领导者的产量后再决定自己的产量。

基本假设：

  • 市场上只有两家厂商
  • 产品同质
  • 一家厂商是领导者（先行动），另一家是追随者（后行动）
  • 数量竞争——领导者决定产量，追随者根据领导者的产量决定自己的产量

求解方法——逆向归纳（Backward Induction）：

步骤一：追随者（厂商2）的反应函数

追随者将领导者的产量Q₁视为给定，最大化自身利润：

π₂ = [a - b(Q₁ + Q₂)]Q₂ - cQ₂

由MR₂ = MC₂得：a - 2bQ₂ - bQ₁ = c

Q₂ = (a - c)/(2b) - Q₁/2（与古诺模型的反应函数相同）

步骤二：领导者（厂商1）的最优产量

领导者知道追随者的反应函数，将其代入自己的利润函数：

π₁ = [a - b(Q₁ + Q₂)]Q₁ - cQ₁

将Q₂ = (a - c)/(2b) - Q₁/2代入：

π₁ = [a - b(Q₁ + (a - c)/(2b) - Q₁/2)]Q₁ - cQ₁

π₁ = [a - b(Q₁/2 + (a - c)/(2b))]Q₁ - cQ₁

π₁ = [a - bQ₁/2 - (a - c)/2]Q₁ - cQ₁

π₁ = [(a + c)/2 - bQ₁/2]Q₁ - cQ₁

对Q₁求导并令其等于0：

∂π₁/∂Q₁ = (a + c)/2 - bQ₁ - c = 0

(a - c)/2 = bQ₁

Q₁* = (a - c)/(2b)

代入追随者反应函数：Q₂* = (a - c)/(2b) - (a - c)/(4b) = (a - c)/(4b)

均衡结果比较：

变量古诺模型斯塔克伯格模型
领导者产量(a-c)/(3b)(a-c)/(2b)
追随者产量(a-c)/(3b)(a-c)/(4b)
总产量2(a-c)/(3b)3(a-c)/(4b)
价格(a+2c)/3(a+3c)/4
领导者利润(a-c)²/(9b)(a-c)²/(8b)
追随者利润(a-c)²/(9b)(a-c)²/(16b)

关键结论：

  • 先动优势（First-mover Advantage）：在斯塔克伯格模型中，领导者获得更高的产量和更高的利润
  • 总产量高于古诺模型，价格低于古诺模型——对消费者更有利
  • 追随者的利润低于古诺均衡——后动劣势
贵州历年高频考点：古诺模型的计算题在贵州自考中非常重要，2020年8月、2021年4月、2022年4月连续考到。必须能够熟练地推导反应函数和求解古诺均衡。斯塔克伯格模型的"先动优势"也常考。

四、寡头市场的串谋——卡特尔

4.1 卡特尔（Cartel）的定义

卡特尔是指同一行业内几家寡头厂商通过公开或秘密的协议，联合决定产量和价格，以获取垄断利润的组织。卡特尔是最典型的串谋（Collusion）形式。

4.2 卡特尔的不稳定性——囚徒困境

卡特尔面临的核心问题是成员背叛的激励：

  • 当所有成员都遵守协议（限制产量）时，各方获得高利润
  • 但如果一个成员偷偷扩大产量，它可以获得更高的利润（因为价格仍然维持在较高水平，而它的销量增加了）
  • 如果其他成员也这样做，协议崩溃，价格下降，各方利润降低

这种博弈结构类似于囚徒困境（Prisoner's Dilemma）：

厂商B遵守协议背叛
厂商A 遵守(10, 10)(2, 15)
厂商A 背叛(15, 2)(5, 5)
  • （遵守, 遵守）：双方都维护卡特尔，各得利润10（合作解）
  • （遵守, 背叛）：A守约B背叛，A得2，B得15
  • （背叛, 遵守）：A背叛B守约，A得15，B得2
  • （背叛, 背叛）：双方都背叛，各得5（非合作解）

纳什均衡是（背叛, 背叛）——虽然双方合作（遵守协议）总利润更高，但每个厂商都有单方面背叛的激励。因此卡特尔天然存在不稳定性。

4.3 维持卡特尔的必要条件

要使卡特尔稳定，需要满足以下条件：

  • 有效的进入壁垒——防止新厂商进入侵蚀利润
  • 成员数量少且集中——便于协商和监督
  • 同质产品——易于设定统一价格和配额
  • 有效的惩罚机制——对背叛者构成可信威胁
  • 需求相对稳定——有利于长期合作关系

实际案例：OPEC（石油输出国组织） 是最著名的国际卡特尔。OPEC通过设定各成员国的产量配额来控制全球石油供应，影响国际油价。但OPEC也经常面临成员国超配额生产的背叛问题。

五、例题讲解

例题1（古诺模型计算）：某寡头市场只有两家厂商，面临的市场需求函数为P = 100 - Q，两家厂商的成本函数分别为TC₁ = 10Q₁，TC₂ = 10Q₂。求：

（1）两家厂商的反应函数

（2）古诺均衡时的产量、价格和利润

解：

（1）厂商1的利润函数：π₁ = [100 - (Q₁+Q₂)]Q₁ - 10Q₁ = 100Q₁ - Q₁² - Q₁Q₂ - 10Q₁ = 90Q₁ - Q₁² - Q₁Q₂

∂π₁/∂Q₁ = 90 - 2Q₁ - Q₂ = 0

Q₁ = 45 - 0.5Q₂ ← 厂商1的反应函数

厂商2的利润函数：π₂ = [100 - (Q₁+Q₂)]Q₂ - 10Q₂ = 90Q₂ - Q₂² - Q₁Q₂

∂π₂/∂Q₂ = 90 - 2Q₂ - Q₁ = 0

Q₂ = 45 - 0.5Q₁ ← 厂商2的反应函数

（2）联立反应函数：

Q₁ = 45 - 0.5Q₂

Q₂ = 45 - 0.5Q₁

代入：Q₁ = 45 - 0.5(45 - 0.5Q₁) = 45 - 22.5 + 0.25Q₁

0.75Q₁ = 22.5

Q₁ = 30

Q₂ = 45 - 0.5×30 = 30

总产量Q = 60

价格P = 100 - 60 = 40

利润π₁ = 40×30 - 10×30 = 1200 - 300 = 900

利润π₂ = 900

比较：

  • 完全竞争：P = MC = 10，Q = 90，利润 = 0
  • 垄断：MR = 100 - 2Q = 10，Qm = 45，Pm = 55，πm = 2025
  • 古诺双寡头：Q = 60，P = 40，各得利润900（总利润1800）

古诺双寡头的总产量（60）介于垄断（45）和完全竞争（90）之间，价格（40）介于垄断（55）和完全竞争（10）之间。

例题2（斯塔克伯格模型计算）：在例题1的基础上，假设厂商1是领导者，厂商2是追随者，求斯塔克伯格均衡。

解：

追随者（厂商2）的反应函数：Q₂ = 45 - 0.5Q₁

领导者（厂商1）的利润函数：

π₁ = [100 - (Q₁ + Q₂)]Q₁ - 10Q₁

将Q₂ = 45 - 0.5Q₁代入：

π₁ = [100 - Q₁ - (45 - 0.5Q₁)]Q₁ - 10Q₁

= [100 - Q₁ - 45 + 0.5Q₁]Q₁ - 10Q₁

= [55 - 0.5Q₁]Q₁ - 10Q₁

= 55Q₁ - 0.5Q₁² - 10Q₁

= 45Q₁ - 0.5Q₁²

∂π₁/∂Q₁ = 45 - Q₁ = 0

Q₁ = 45

Q₂ = 45 - 0.5×45 = 22.5

总产量Q = 45 + 22.5 = 67.5

价格P = 100 - 67.5 = 32.5

领导者利润π₁ = 45×45 - 0.5×45² = 2025 - 1012.5 = 1012.5

追随者利润π₂ = (100 - 67.5)×22.5 - 10×22.5 = 32.5×22.5 - 225 = 731.25 - 225 = 506.25

验证先动优势：领导者利润1012.5 > 追随者利润506.25，先动优势明显。

一、公共选择理论的分析框架

公共选择理论运用经济学方法分析政治决策过程，其基本分析框架可以概括为：

政治市场（Political Market）的三类参与者：

  • 投票者（Voters）：相当于商品市场的消费者，通过投票表达对公共产品的需求
  • 政治家（Politicians）：相当于商品市场的生产者和供给者，通过提供政策方案争取选票
  • 官僚（Bureaucrats）：相当于具体执行者，负责公共政策的执行

二、寻租理论的深化

2.1 寻租与创租

寻租（Rent-seeking） 是公共选择理论的核心概念之一，指通过影响政府决策获取经济租金的非生产性行为。政府创租的方式主要有三种：

（1）无意创租（Accidental Rent Creation）

政府出于"好心"干预经济，却无意中创造了"租金"（超额利润）。例如：政府为了扶持幼稚产业设置关税壁垒，结果国内厂商获得垄断利润，形成了租金；政府发放出租车牌照限制数量，牌照本身成为有价证券（租金）。

（2）被动创租（Passive Rent Creation）

政府受利益集团影响而主动创造租金。例如：律师协会游说政府提高律师资格考试难度，减少律师供给，提高律师行业收入；药品生产企业游说政府延长专利保护期。

（3）主动创租（Active Rent Creation）

政府官员利用手中的权力"设租"——主动设置某种制度障碍，然后以权谋私。这是最恶劣的创租行为，是腐败的典型表现。例如：官员故意延迟审批，然后向企业索取"好处费"加快审批；政府设置进出口配额，然后向企业收取"配额费"。

贵州历年高频考点：创租的三种形式在贵州自考中常以简答题或多选题形式考查，2021年4月考过"政府创租的类型"。

2.2 寻租的社会成本——塔洛克四边形

塔洛克四边形（Tullock Rectangle） 是经济学家戈登·塔洛克（Gordon Tullock）提出的概念。传统垄断理论认为，垄断造成的效率损失（无谓损失）是图中的三角形区域。但塔洛克指出，为获取或维持垄断而投入的全部寻租支出也是一种社会成本。

塔洛克四边形的推理：

  • 垄断利润（图中的矩形AB面积）是吸引企业寻租的"诱饵"
  • 企业为了获得这个垄断利润，愿意投入的资源最多可以等于垄断利润的数额
  • 这些投入（游说、法律费用、公关支出等）是非生产性的，不创造任何社会价值
  • 因此，寻租的社会总成本 = 无谓损失（三角形） + 寻租投入（四边形）

这意味着垄断的社会成本比传统理论估计的大得多。传统分析只考虑了无谓损失（三角形），而塔洛克指出还要加上寻租支出（四边形面积），这个面积在极端情况下可以等于垄断利润的全部。

2.3 寻租的层次

寻租不仅发生在争夺现有租金，还发生在多个层次：

  • 第一层次寻租：直接争夺政府创造的租金（如争夺垄断经营权）
  • 第二层次寻租：争夺创租权的寻租（如争夺制定政策的权力）
  • 第三层次寻租：为改变寻租规则而进行的寻租（如修宪级寻租）

每层寻租都消耗资源，使得寻租的社会总成本可能极其巨大。

三、宪政经济学与立宪选择

3.1 布坎南的立宪选择理论

宪政经济学（Constitutional Economics） 也是布坎南的重要贡献，关注的是规则的选择（选择的规则）而非规则下的选择（在既定规则下的选择）。

两个层次的决策：

  • 立宪层次（Constitutional Level）：制定游戏规则——决定什么样的决策规则是好的（如采用简单多数还是绝对多数？）
  • 操作层次（Operational Level）：在既定规则下进行具体决策（如是否增加教育支出？）

布坎南的核心观点：与其在既定规则下寻找最优政策，不如改进决策规则本身。好的规则比好的政策更重要，因为好的规则能够在不同环境下产生好的结果。

立宪选择的标准：

  • 一致性同意（Unanimous Consent）：理想情况下，宪法规则应当获得所有人的一致同意（因为没人知道自己在未来的具体位置——无知之幕）
  • 罗尔斯的"无知之幕（Veil of Ignorance）"：在不知道自己将处于何种地位的情况下，人们会更倾向于选择公平的规则

3.2 公共选择理论的启示

公共选择理论对现实政治经济制度设计的启示：

  • 限制政府规模：政府不是"仁慈的专制者"，政府官员也会追求自身利益，因此需要对政府权力进行制约
  • 财政约束：通过预算平衡规则、税收限制等约束政府行为
  • 分权与制衡：将权力分散到不同部门，相互制衡
  • 促进竞争：在公共服务领域引入竞争机制（如凭单制、外包）
  • 透明度：提高决策透明度，降低寻租空间

四、公共选择理论中投票与经济政策的相互作用

4.1 投票与经济政策的关系

公共选择理论研究投票机制如何影响经济政策的形成：

投票机制对经济政策的影响：

  • 多数投票规则倾向于中位投票人的偏好
  • 利益集团通过游说和捐款影响政策方向
  • 政治家为了连任倾向于短期、可见度高的政策
  • 官僚利用信息优势推动预算最大化

4.2 政府规模扩张的原因

公共选择理论解释了为什么政府规模（财政支出占GDP的比重）长期呈上升趋势——瓦格纳法则（Wagner's Law）：

  • 官僚预算最大化倾向（尼斯坎南模型）
  • 财政幻觉（Fiscal Illusion）：投票者低估公共产品的成本（税负隐蔽）
  • 利益集团推动：特殊利益集团游说增加特定支出项目
  • 政策惯性：已有项目难以取消
  • 搭便车问题：反对增税的利益分散，支持增支的利益集中
贵州历年高频考点：政府规模扩张的原因（瓦格纳法则与公共选择理论的解释）在贵州自考中常以简答题形式考查，2022年4月考过"为什么政府规模会不断扩张？"

五、公共选择理论评述

5.1 公共选择理论的贡献

  • 填补了政府行为的分析空白：传统经济学分析市场行为，公共选择理论分析了政府行为
  • 打破了"仁慈政府"的神话：政府官员和市场中的人一样是理性经济人
  • 提供了分析制度设计的工具：为宪法设计、选举制度设计提供了理论基础
  • 解释了政府失灵的原因：将政府失灵内生于政治决策过程

5.2 公共选择理论的批评

  • 过于悲观：把人视为纯粹的自利者，忽视了利他主义和公共精神
  • 同构假设可能不成立：政治领域和经济领域的动机可能不同
  • 忽视制度和文化差异：不同国家的政治制度和文化传统差异很大
  • 难以实证检验：公共选择理论的很多命题难以通过实证数据进行检验

经济学原理部分

1.（单选题） 寡头市场最显著的特征是：

A. 产品差异化

B. 厂商之间的相互依存

C. 自由进出

D. 产品同质

答案：B

解析：寡头市场最显著的特征是相互依存——由于厂商数量少，每个厂商的决策都会显著影响其他厂商，因此必须考虑竞争对手的反应。A（产品差异化）是垄断竞争的特征；C（自由进出）是完全竞争和垄断竞争的特征；D（产品同质）可能是寡头的特征，但不是最显著的。

2.（单选题） 在古诺模型中，随着寡头厂商数量增加，均衡价格和产量将趋于：

A. 垄断市场

B. 完全竞争市场

C. 垄断竞争市场

D. 维持不变

答案：B

解析：古诺模型的一个重要结论是，随着厂商数量n的增加，总产量趋近于完全竞争水平（P = MC），价格趋近于MC。当n → ∞时，古诺均衡→完全竞争均衡。这一结论说明竞争越充分，市场越有效率。

3.（多选题） 以下哪些是寡头市场的特征：

A. 少数几家大厂商

B. 较高的进入壁垒

C. 相互依存

D. 大量小厂商

E. 厂商之间可能存在串谋

答案：ABCE

解析：寡头市场的特征包括：少数大厂商（A）、高进入壁垒（B）、相互依存（C）、可能的串谋行为（E）。D（大量小厂商）是垄断竞争或完全竞争的特征，不是寡头市场的特征。

4.（计算题——古诺模型） 某双寡头市场面临的需求函数为P = 200 - 2Q，其中Q = Q₁ + Q₂。两家厂商的成本函数分别为TC₁ = 20Q₁，TC₂ = 20Q₂。求：

（1）古诺均衡时各厂商的反应函数、产量、价格和利润

（2）如果两家厂商串谋组成卡特尔，求卡特尔的总产量、价格和各厂商的产量、利润

（3）说明卡特尔为什么不稳定

答案与解析：

（1）厂商1的利润函数：π₁ = [200 - 2(Q₁+Q₂)]Q₁ - 20Q₁ = 200Q₁ - 2Q₁² - 2Q₁Q₂ - 20Q₁ = 180Q₁ - 2Q₁² - 2Q₁Q₂

∂π₁/∂Q₁ = 180 - 4Q₁ - 2Q₂ = 0

Q₁ = 45 - 0.5Q₂ ← 厂商1的反应函数

同理，厂商2的反应函数：Q₂ = 45 - 0.5Q₁

联立求解：Q₁ = 45 - 0.5(45 - 0.5Q₁) = 45 - 22.5 + 0.25Q₁

0.75Q₁ = 22.5

Q₁ = 30，Q₂ = 30

总产量Q = 60，价格P = 200 - 2×60 = 80

各厂商利润：π₁ = 80×30 - 20×30 = 2400 - 600 = 1800

π₂ = 1800

（2）卡特尔（串谋）：最大化总利润

总利润π = 200 - 2(Q₁+Q₂) - 20(Q₁+Q₂)

令Q = Q₁+Q₂，π = (200 - 2Q)Q - 20Q = 180Q - 2Q²

MR = 180 - 4Q，MC = 20

MR = MC：180 - 4Q = 20

Q = 40

P = 200 - 2×40 = 120

总利润π = 180×40 - 2×40² = 7200 - 3200 = 4000

假设按产量均分：Q₁ = Q₂ = 20，各得利润2000

（3）卡特尔不稳定的原因：虽然串谋时各厂商可得利润2000（高于古诺的1800），但每个厂商都有单方面背叛的激励。假设厂商1遵守协议生产20，厂商2背叛增产：Q₂ = 45 - 0.5×20 = 35（根据厂商2的反应函数）

此时总产量Q = 20 + 35 = 55，P = 200 - 2×55 = 90

厂商2的利润π₂ = 90×35 - 20×35 = 3150 - 700 = 2450（高于2000）

厂商1的利润π₁ = 90×20 - 20×20 = 1800 - 400 = 1400（低于2000）

因此厂商2有强烈的背叛激励，而厂商1在知道对方会背叛时也会选择背叛（防止损失更大），最终卡特尔的合作解崩溃，回到古诺非合作解。这就是囚徒困境在寡头市场中的体现。

5.（简答题） 比较古诺模型和斯塔克伯格模型的异同。

答案：相同点：（1）都是寡头市场的数量竞争模型；（2）都假设产品同质；（3）都以利润最大化为目标。不同点：（1）行动顺序不同——古诺模型假设两家厂商同时决定产量，斯塔克伯格模型假设领导者先决定产量，追随者后决定；（2）信息结构不同——古诺模型中各厂商不知道对方的产量，斯塔克伯格模型中追随者知道领导者的产量；（3）结果不同——斯塔克伯格模型中领导者的产量和利润更高（先动优势），追随者的产量和利润更低（后动劣势），而古诺模型中两家厂商均等；（4）总产量不同——斯塔克伯格总产量高于古诺，价格低于古诺。

公共经济学部分

1.（单选题） "财政幻觉"是指：

A. 政府财政收入增长快于经济增长

B. 投票者低估公共产品的税收成本

C. 财政支出总是超过预算

D. 税收收入被高估

答案：B

解析：财政幻觉（Fiscal Illusion）是公共选择理论的概念，指投票者倾向于低估公共产品的税收成本（因为税负隐蔽，如间接税、通货膨胀税等），从而支持超出社会最优水平的公共支出。这是政府规模扩张的原因之一。

2.（单选题） 根据塔洛克四边形理论，寻租的社会成本包括：

A. 只有无谓损失

B. 无谓损失加上寻租投入

C. 只有寻租投入

D. 无谓损失减去寻租投入

答案：B

解析：塔洛克认为，寻租的社会总成本不仅包括传统分析中的无谓损失（三角形区域），还包括为获取或维持垄断而投入的全部寻租支出（四边形面积）。在极端情况下，寻租支出可以接近甚至等于全部垄断利润，使得垄断的社会成本远大于传统估算。

3.（多选题） 政府规模不断扩张的原因包括：

A. 官僚追求预算最大化

B. 财政幻觉

C. 利益集团的推动

D. 政府运行效率提高

E. 政策惯性和已有项目难以取消

答案：ABCE

解析：公共选择理论认为政府规模扩张的原因包括：官僚预算最大化（A，尼斯坎南模型）、财政幻觉（B，低估成本）、利益集团推动（C，追加支出）、政策惯性（E，已有项目难以取消）。D（效率提高）不会导致规模扩张，相反效率提高通常会降低成本。

4.（简答题） 简述塔洛克四边形的内容及其对垄断社会成本分析的意义。

答案：塔洛克四边形是指塔洛克提出的关于寻租社会成本的理论。传统垄断理论认为垄断造成的效率损失（社会成本）仅为图中的无谓损失三角形。但塔洛克指出，企业为获取或维持垄断地位而投入的全部寻租支出也是社会成本——这些资源被用于游说、法律费用、公关等非生产性活动，不创造任何社会价值。在图形上，垄断利润的矩形面积就是寻租支出的上限，它加上无谓损失三角形构成了垄断的全部社会成本。这一理论的意义在于：垄断的社会成本远大于传统经济学的估计，而且寻租行为造成资源浪费，使社会陷入"寻租社会"的低效率陷阱。

5.（简答题） 简述布坎南宪政经济学的基本思想。

答案：布坎南的宪政经济学是公共选择理论的重要分支，关注"立宪层次"的规则选择。基本思想包括：（1）两个层次的决策——"立宪层次"制定游戏规则，"操作层次"在既定规则下决策。好的规则比好的政策更重要，因为好的规则能在不同环境下产生好的结果。（2）一致性同意标准——理想情况下，宪法规则应当获得所有人的一致同意，因为"无知之幕"（罗尔斯的概念）下人们不知道自己的未来地位，会倾向于选择公平、有效的规则。（3）限制政府权力——基于对政治过程中自利行为的分析，应当通过宪法规则约束政府权力，防止政府扩张和寻租。（4）财政约束——通过宪法层面的预算平衡规则、税收限制等约束政府行为。宪政经济学为现代宪政改革和制度设计提供了理论依据。

【上午】经济学原理（中级）第6章：成本分析

一、成本的概念

1. 显性成本与隐性成本

显性成本（Explicit Cost）：企业支付给外部生产要素所有者的货币支出，如原材料费、工人工资、租金等。这些成本在会计账目上有明确记录。

隐性成本（Implicit Cost）：企业使用自有生产要素应获得但未实际支付的报酬，如自有资金的利息、企业主放弃的工资收入等。隐性成本在会计账上不体现，但在经济决策中必须考虑。

举例：小张用自己的店面开店，不付租金。从会计角度看，店面成本为0。但从经济学角度看，如果店面出租每月可得5000元租金，这5000元就是隐性成本（机会成本）。

2. 经济成本、会计成本与机会成本的关系

  • 会计成本 = 显性成本（会计账目记录）
  • 经济成本 = 显性成本 + 隐性成本
  • 机会成本 = 经济成本（因为都体现了"放弃的次优选择"的价值）

经济利润与会计利润的区别：

利润类型公式说明
会计利润总收益 - 会计成本（显性成本）大于经济利润
经济利润总收益 - 经济成本（显性+隐性）也称为"超额利润"
正常利润企业家才能的隐性成本经济利润=0时，企业仍获得正常利润
核心考点：经济利润 = 0 ≠ 企业不赚钱！此时企业获得了正常利润（即企业家才能的正常报酬）。经济利润为零意味着企业刚好赚到了和次优选择一样多的钱。

贵州高频考点：区分会计利润和经济利润、正常利润的概念，几乎是每年的必考选择题。

二、短期成本分析

1. 短期成本的分类

成本类型符号定义公式
总固定成本TFC不随产量变化的成本TFC = 常数
总可变成本TVC随产量变化而变化的成本TVC = f(Q)
总成本TC固定成本与可变成本之和TC = TFC + TVC
平均固定成本AFC每单位产品分摊的固定成本AFC = TFC / Q
平均可变成本AVC每单位产品分摊的可变成本AVC = TVC / Q
平均总成本ATC每单位产品的总成本ATC = TC / Q = AFC + AVC
边际成本MC增加一单位产量所增加的总成本MC = ΔTC / ΔQ

2. 短期成本曲线及其形状

（1）TFC、TVC、TC曲线

  • TFC：一条水平直线（与Q轴平行），不随产量变化
  • TVC：从原点出发，先以递减速率上升（边际报酬递增阶段），后以递增速率上升（边际报酬递减阶段），呈S形
  • TC：与TVC形状相同，但在纵轴上向上平移TFC的距离

  • AFC：向右下方倾斜（产量越大，每单位分摊的固定成本越少），呈双曲线状
  • AVC：先下降后上升，呈U形（先边际报酬递增阶段下降，后递减阶段上升）
  • ATC：先下降后上升，呈U形（位于AVC上方，两者差距为AFC）
  • MC：先下降后上升，呈U形（下降更快，上升也更陡峭）

3. 成本曲线之间的关系（U形成本曲线的成因）

U形成本曲线的原因：边际报酬递减规律。

  • 当MP递增时，MC递减（产出增加快于成本增加）
  • 当MP递减时，MC递增（产出增加慢于成本增加）
  • MC的最低点对应MP的最高点

MC与AVC、ATC的关系：

  • MC < AVC → AVC递减
  • MC = AVC → AVC达到最小值（MC穿过AVC的最低点）
  • MC > AVC → AVC递增
  • MC < ATC → ATC递减
  • MC = ATC → ATC达到最小值（MC穿过ATC的最低点）
  • MC > ATC → ATC递增
记忆要点：MC曲线一定穿过AVC和ATC的最低点。这与MP穿过AP最高点的原理一样——"边际值拉动平均值"。

三、长期成本分析

1. 长期总成本（LTC）

长期总成本（Long-run Total Cost，LTC） 是指在所有生产要素都可变的条件下，生产各种产量所需的最小成本。

长期中，企业可以根据产量调整所有要素投入量，因此 长期成本是短期成本的下包络线——长期中企业可以选择最优的工厂规模。

2. 长期平均成本（LAC）

长期平均成本（Long-run Average Cost，LAC） = LTC / Q

LAC曲线的形状：呈U形（与短期ATC类似，但成因不同）


成本
↑
|   SAC1  SAC2  SAC3  SAC4
|  \    / \    / \    /
|   \  /   \  /   \  /
|    \/     \/     \/
|     \     /\     /
|      \   /  \   /   LAC
|       \ /    \ /
|V_V_→ Q
  • LAC是无数条短期平均成本（SAC）曲线的 下包络线
  • LAC上的每一点都代表该产量下的最低平均成本
  • 规模报酬递增阶段：LAC递减（产出增加快于成本增加）
  • 规模报酬不变阶段：LAC水平
  • 规模报酬递减阶段：LAC递增（管理成本上升）

3. LAC曲线U形的原因——规模经济与规模不经济

与短期不同（短期U形源于边际报酬递减），长期U形源于规模经济。

概念定义原因
规模经济产量↑ → LAC↓分工细化、专业化设备、批量采购折扣、管理效率
规模不经济产量↑ → LAC↑管理协调困难、信息传递扭曲、官僚主义

规模经济与规模报酬的区别：

  • 规模报酬是 实物量 概念（投入与产出的实物比例）
  • 规模经济是 货币量 概念（考虑了要素价格变化、管理效率等因素）

4. 长期边际成本（LMC）

长期边际成本（Long-run Marginal Cost，LMC） 是指长期中增加一单位产量所增加的总成本。

  • LMC曲线穿过LAC的最低点（LMC = LAC时，LAC最小）
  • 在LAC下降阶段：LMC < LAC
  • 在LAC上升阶段：LMC > LAC

5. 学习曲线（Learning Curve）

学习曲线（也称经验曲线）反映了 累积产量增加导致平均成本下降 的现象。随着工人和管理者经验的积累，生产效率提高，成本下降。


平均成本
↑

|     \
|      \

学习效应与规模经济的区别：

  • 学习效应：时间维度——随累积产量增加，经验积累降低成本
  • 规模经济：规模维度——随当期产量增加，分摊固定成本、提高效率

四、成本函数与生产函数的关系

成本函数和生产函数是 互为对偶关系（Duality）：

  • 当边际报酬递增时（MP↑），边际成本递减（MC↓）
  • 当边际报酬递减时（MP↓），边际成本递增（MC↑）

数学关系：

$$

MC = \frac{w}{MP_L}

$$

其中w为工资率。这个关系说明：

  • MP_L越高，MC越低（生产效率高→成本低）
  • MP_L越低，MC越高（生产效率低→成本高）

五、收益与利润最大化

1. 总收益、平均收益与边际收益

概念符号定义公式
总收益TR销售产品获得的全部收入TR = P × Q
平均收益AR每单位产品的销售收入AR = TR / Q = P
边际收益MR多销售一单位产品增加的收入MR = ΔTR / ΔQ

在完全竞争市场：P = AR = MR（水平的需求曲线）

在不完全竞争市场：P > MR（MR曲线在需求曲线下方）

2. 利润最大化条件

利润（π） = 总收益 - 总成本 = TR - TC

利润最大化的必要条件（一阶条件）：

$$

MR = MC

$$

二阶条件（确保是最大值）：

$$

\frac{dMR}{dQ} < \frac{dMC}{dQ}

$$

即：MR曲线斜率 < MC曲线斜率（在交点处，MC上升快于MR下降）

经济含义：

  • 如果 MR > MC：增产量 → 利润增加 → 应继续增产
  • 如果 MR < MC：减产量 → 利润增加 → 应减产
  • MR = MC 时：利润最大
贵州高频考点：利润最大化条件 MR = MC 是微观经济学的核心命题，在各类题型中反复出现，必须牢记。

3. 短期停业决策

在短期，企业即使亏损也可能继续生产，只要 价格（平均收益）大于平均可变成本（AVC）。

  • P > ATC：盈利
  • AVC < P < ATC：亏损但仍继续生产（可以弥补部分固定成本）
  • P < AVC：停业（收入连可变成本都覆盖不了）

停业点（Shutdown Point）：P = AVC的最低点。

【下午】公共经济学第1-2章复习与综合

一、第1章核心要点回顾

1. 公共经济学的研究对象

公共经济学研究 公共部门（政府）的经济行为及其经济效应，包括：

  • 政府如何筹集收入（税收、公债）
  • 政府如何安排支出（购买性支出、转移性支出）
  • 政府如何调节经济（财政政策、货币政策）

2. 政府三大经济职能（马斯格雷夫）

职能核心问题政策工具
资源配置职能效率公共产品供给、外部性矫正、反垄断
收入分配职能公平累进税、社会保障、转移支付
经济稳定职能稳定财政政策（增减税收/支出）、货币政策

3. 混合经济

现代经济的典型特征是 市场机制与政府干预并存。市场在资源配置中起 基础性 作用，政府在此基础上矫正市场失灵。

4. 帕累托最优与卡尔多-希克斯标准

  • 帕累托最优：无法在不使任何人变差的情况下使任何人变好
  • 帕累托改进：至少一人变好，无人变差
  • 卡尔多-希克斯标准：受益者的所得 > 受损者的所失

5. 公共经济学的效率标准

效率与公平的权衡是公共经济学的核心问题。奥肯的漏桶实验生动地说明了这一点。

一、经济学原理练习题

（一）单项选择题

第1题：经济学中的"正常利润"属于（ ）

A. 显性成本

B. 隐性成本

C. 会计成本

D. 经济利润

答案：B

解析：正常利润是企业家才能的报酬，属于隐性成本（机会成本的一部分）。它不被计入会计成本，但在经济成本中必须考虑。当经济利润=0时，企业获得了正常利润。

第2题：当边际成本低于平均总成本时，平均总成本（ ）

A. 递增

B. 递减

C. 不变

D. 达到最小值

答案：B

解析：当MC < ATC时，新增一单位产品的成本低于平均成本，会"拉低"平均值，因此ATC递减。当MC = ATC时，ATC达到最小值。当MC > ATC时，ATC递增。这是"边际值拉动平均值"的基本规律。

第3题：短期中，企业的最低停业条件是（ ）

A. P < ATC

B. P < AVC

C. P < MC

D. P < AFC

答案：B

解析：短期中，如果价格（平均收益）低于平均可变成本（P < AVC），每生产一单位产品连可变成本都收不回来，越生产亏损越大，应停业。P < ATC但仍大于AVC时，虽然亏损，但可以弥补部分固定成本，继续生产比停业好。

第4题：在长期中，LAC曲线呈U形的原因是（ ）

A. 边际报酬递减规律

B. 规模经济与规模不经济

C. 边际效用递减规律

D. 边际替代率递减

答案：B

解析：长期平均成本曲线U形的原因不是边际报酬递减（那是短期的原因），而是规模经济（产量扩大使LAC下降）和规模不经济（产量过大使LAC上升）的综合结果。A是短期成本U形的原因。

第5题：利润最大化的条件是（ ）

A. TR = TC

B. MR = MC

C. AR = AC

D. P = ATC

答案：B

解析：无论市场结构如何，利润最大化的条件都是边际收益等于边际成本（MR = MC）。当MR > MC时增加产量可以增加利润，当MR < MC时减少产量可以增加利润，只有MR = MC时利润最大。A、C、D是盈亏平衡条件。

（二）多项选择题

第6题：以下关于经济利润的描述，正确的是（ ）

A. 经济利润 = 总收益 - 经济成本

B. 经济利润也称为超额利润

C. 经济利润为0时，企业应该停业

D. 经济利润包含了正常利润

答案：A、B

解析：A正确，经济利润=总收益-经济成本（包括显性成本和隐性成本）。B正确，经济利润超过正常利润的部分是超额利润。C错误，经济利润为0意味着企业获得了正常利润，在长期竞争性市场中这是常态。D错误，经济利润中不包含正常利润，因为正常利润已经作为隐性成本被扣除了。

第7题：短期成本曲线中，呈U形的是（ ）

A. AFC

B. AVC

C. ATC

D. MC

答案：B、C、D

解析：AVC、ATC和MC曲线均呈U形（先下降后上升），这是由边际报酬递减规律决定的。AFC曲线始终向右下方倾斜（产量越大，固定成本摊得越薄），不是U形。

（三）简答题

第8题：简述MC曲线与AVC曲线和ATC曲线的关系，并画图说明。

答案：

（1）MC曲线与AVC曲线的关系：

  • MC < AVC时，AVC递减
  • MC = AVC时，AVC达到最小值（MC穿过AVC的最低点）
  • MC > AVC时，AVC递增

（2）MC曲线与ATC曲线的关系：

  • MC < ATC时，ATC递减
  • MC = ATC时，ATC达到最小值（MC穿过ATC的最低点）
  • MC > ATC时，ATC递增

（3）图形特征：


成本
↑
|   MC穿过AVC和ATC的最低点
|  /
| /  ATC
|/  /
|  /  AVC

MC曲线最先达到最低点，然后上升，依次穿过AVC和ATC的最低点。这是因为平均成本包含固定成本的分摊，所以ATC最低点位于AVC最低点的右上方。

（四）计算题

第9题：某企业的短期总成本函数为 TC = 100 + 10Q + Q²。

（1）写出TFC、TVC、AFC、AVC、ATC、MC的表达式。

（2）求AVC的最小值及其对应的产量。

（3）如果产品市场价格为30元，求利润最大化产量和最大利润。

答案：

（1）TC = 100 + 10Q + Q²

TFC = 100

TVC = 10Q + Q²

AFC = 100/Q

AVC = 10 + Q

ATC = 100/Q + 10 + Q

MC = dTC/dQ = 10 + 2Q

（2）AVC最小值条件：d(AVC)/dQ = 0

AVC = 10 + Q

d(AVC)/dQ = 1 > 0（AVC单调递增，最小值在Q=0处）

但注意，Q=0时AVC=10。

实际上，由生产函数特征，更加合理的情况：

令 MC = AVC：10 + 2Q = 10 + Q → Q = 0

所以AVC最小值在Q=0时，AVC_min = 10。

（3）利润最大化条件：MR = MC

完全竞争市场中，MR = P = 30

MC = 10 + 2Q

30 = 10 + 2Q

2Q = 20

Q = 10（利润最大化产量）

最大利润 π = TR - TC = P×Q - (100 + 10Q + Q²)

= 30×10 - (100 + 10×10 + 10²)

= 300 - (100 + 100 + 100)

= 300 - 300

= 0

经济利润为0，企业获得正常利润。

第10题（拓展）：接上题，如果市场价格下降到18元，企业是否应该继续生产？

答案：

利润最大化：MR = MC

18 = 10 + 2Q

Q = 4

此时：

TR = 18×4 = 72

TC = 100 + 10×4 + 4² = 100 + 40 + 16 = 156

利润 = 72 - 156 = -84（亏损）

检查停业条件：P = 18，AVC = 10 + Q = 10 + 4 = 14

P = 18 > AVC = 14，虽然亏损，但可以弥补部分固定成本

继续生产的亏损 = 84

停业的亏损 = TFC = 100

继续生产比停业少亏损16，所以应该继续生产。

（二）多项选择题

第6题：市场失灵的主要表现包括（ ）

答案：A、B、C

（三）名词解释

第8题：解释"搭便车"问题。

答案：

搭便车（Free Rider）是指在公共产品消费中，人们不付费或少付费而享受公共产品利益的行为。由于公共产品具有非排他性，无法阻止不付费者消费，每个人都想"搭便车"，导致市场无法通过自愿交易有效提供公共产品。这是市场失灵的重要表现，也是政府必须介入提供公共产品的根本原因。

第9题：解释"帕累托最优"。

答案：

帕累托最优（Pareto Optimality）是经济学中衡量资源配置效率的理想状态。当资源配置达到帕累托最优时，在不使任何人境况变差的条件下，不可能使任何人的境况变得更好。如果某种变动能使至少一人变好而无人变差，称为"帕累托改进"。当所有帕累托改进都已实现时，就达到了帕累托最优。

（四）简答题

第10题：比较政府干预的三种矫正负外部性措施的优缺点。

答案：

（1）庇古税：

  • 优点：将外部成本内部化，通过价格信号引导企业行为，同时增加政府收入。
  • 缺点：需要政府准确知道边际外部成本的信息（现实中很难确定合适的税率）。

（2）行政管制（排放标准）：

  • 优点：效果确定，直接规定最大排放量，执行简单。
  • 缺点：缺乏弹性，所有企业适用同一标准，忽视了不同企业减排成本的差异，效率较低。

（3）可交易排污许可证：

  • 优点：总量控制有明确的环境目标，市场交易使许可证流向减排成本最高的企业（效率高），激励企业技术创新以降低减排成本。
  • 缺点：初始分配存在公平问题（拍卖还是免费发放），需要有效的监管和执行机制。

第17章 简单国民收入决定（下）——三部门与四部门经济

一、三部门经济中的均衡国民收入

三部门经济（居民 + 企业 + 政府）

总需求 AD = C + I + G

总供给 AS = Y = C + S + T

均衡条件： Y = C + I + G 或 I + G = S + T

其中：

  • G： 政府购买支出
  • T： 税收（定量税T₀或比例税tY）

二、引入政府后的乘数

1. 政府购买支出乘数（Government Expenditure Multiplier）

k_G = ΔY / ΔG = 1 / (1 - b)

其中b为MPC。

2. 税收乘数（Tax Multiplier）

k_T = ΔY / ΔT = -b / (1 - b)

税收乘数为负，说明增税会减少国民收入。

3. 平衡预算乘数（Balanced Budget Multiplier）

kB = kG + k_T = 1/(1-b) + (-b)/(1-b) = (1-b)/(1-b) = 1

含义： 政府同时增加相同数额的税收和政府购买，国民收入增加量与政府支出增加量相等，即平衡预算乘数为1。

贵州历年高频考点： 各种乘数的计算，特别是平衡预算乘数=1，常以选择题和计算题出现。

【例题17.1】 已知消费函数C = 100 + 0.8Yd（Yd为可支配收入），定量税T = 100，政府购买G = 200，投资I = 150。求：

（1）均衡国民收入

（2）政府购买乘数、税收乘数、平衡预算乘数

解：

（1）Y_d = Y - T = Y - 100

C = 100 + 0.8(Y - 100) = 100 + 0.8Y - 80 = 20 + 0.8Y

Y = C + I + G = (20 + 0.8Y) + 150 + 200 = 370 + 0.8Y

Y - 0.8Y = 370

0.2Y = 370

Y = 1850

（2）MPC = b = 0.8

k_G = 1/(1-b) = 1/0.2 = 5

k_T = -b/(1-b) = -0.8/0.2 = -4

kB = kG + k_T = 5 + (-4) = 1

三、四部门经济中的均衡国民收入

四部门经济（居民 + 企业 + 政府 + 国外部门）

AD = C + I + G + (X - M)

假设进口函数 M = M₀ + mY（m为边际进口倾向）

均衡条件： Y = C + I + G + X - (M₀ + mY)

对外贸易乘数： k_X = 1 / (1 - b + m)

由于m > 0，对外贸易乘数小于封闭经济中的乘数。

第18章 IS-LM模型（上）——产品市场均衡

一、IS曲线的推导

IS曲线（Investment-Saving Curve） 描述了产品市场均衡（I = S）条件下，利率r与国民收入Y之间的关系。

产品市场均衡条件： I(r) = S(Y)

推导思路：

  • 投资是利率的减函数：I = I₀ - dr（d为投资对利率的敏感度）
  • 储蓄是收入的增函数：S = -a + (1-b)Y
  • 均衡条件：I₀ - dr = -a + (1-b)Y

IS曲线方程：

Y = (a + I₀ - dr) / (1 - b)

或写作：

r = (a + I₀)/d - (1-b)Y/d

IS曲线的斜率： 斜率为负（利率下降 → 投资增加 → 收入增加）

IS曲线的移动：

  • 政府购买G增加 → IS右移（ΔY = k_G × ΔG）
  • 税收T增加 → IS左移（ΔY = k_T × ΔT）
  • 自主性投资增加 → IS右移
贵州历年高频考点： IS曲线的推导、斜率和移动，常以简答题和计算题出现。

【例题18.1】 已知消费函数C = 200 + 0.75Y，投资函数I = 300 - 25r，求IS曲线方程。

解：

S = Y - C = Y - (200 + 0.75Y) = -200 + 0.25Y

均衡条件：I = S

300 - 25r = -200 + 0.25Y

0.25Y = 500 - 25r

Y = 2000 - 100r

所以IS曲线方程为 Y = 2000 - 100r。

当r = 5时，Y = 2000 - 500 = 1500；当r = 10时，Y = 2000 - 1000 = 1000。

二、IS曲线以外的点

  • IS曲线右侧（如A点）： I < S，产品市场供过于求，Y将下降
  • IS曲线左侧（如B点）： I > S，产品市场供不应求，Y将上升

三、LM曲线的推导（引入货币市场）

LM曲线（Liquidity Preference-Money Supply Curve） 描述了货币市场均衡（L = M）条件下，利率r与国民收入Y之间的关系。

货币需求——凯恩斯流动性偏好理论：

L = L₁(Y) + L₂(r) = kY - hr

其中：

  • L₁ = kY： 交易性货币需求（与收入正相关）
  • L₂ = -hr： 投机性货币需求（与利率负相关）
  • k： 货币需求对收入的敏感度
  • h： 货币需求对利率的敏感度

货币供给： M = M₀（外生变量）

货币市场均衡条件： M₀ = kY - hr

LM曲线方程：

r = (kY - M₀) / h

或：

Y = (M₀ + hr) / k

LM曲线的斜率： 斜率为正（收入增加 → 交易性货币需求增加 → 利率上升）

LM曲线的三个区间：

  • 凯恩斯区间（水平）： 利率极低，流动性陷阱，h → ∞
  • 中间区间（向右上倾斜）： 正常情况
  • 古典区间（垂直）： 利率极高，h → 0
贵州历年高频考点： LM曲线的推导和三个区间，特别是"流动性陷阱"的概念。

【例题18.2】 已知货币需求函数L = 0.2Y - 10r，名义货币供给M = 200，价格水平P = 1。求LM曲线方程。

解：

实际货币供给 = M/P = 200/1 = 200

货币市场均衡：L = M/P

0.2Y - 10r = 200

10r = 0.2Y - 200

r = 0.02Y - 20

所以LM曲线方程为 r = 0.02Y - 20。

当Y = 1500时，r = 30 - 20 = 10；当Y = 1000时，r = 20 - 20 = 0。

四、产品市场和货币市场的同时均衡：IS-LM模型

IS-LM模型将产品市场和货币市场结合起来，确定均衡利率和均衡国民收入。

联立IS曲线方程和LM曲线方程：

  • IS: Y = (a + I₀ - dr) / (1 - b) 或 r = (a + I₀)/d - (1-b)Y/d
  • LM: r = (kY - M₀) / h 或 Y = (M₀ + hr) / k

解联立方程组得到均衡的Y和r。

贵州历年高频考点： IS-LM均衡的计算是必考计算题！

【例题18.3】 已知产品市场：C = 100 + 0.8Y，I = 150 - 10r，G = 200。

货币市场：L = 0.2Y - 5r，M = 200，P = 1。

求均衡国民收入和利率。

解：

（1）IS曲线：

Y = C + I + G = (100 + 0.8Y) + (150 - 10r) + 200 = 450 + 0.8Y - 10r

0.2Y = 450 - 10r

Y = 2250 - 50r ... IS方程

（2）LM曲线：

L = M/P

0.2Y - 5r = 200

5r = 0.2Y - 200

r = 0.04Y - 40 ... LM方程

（3）联立求解：

将LM代入IS：Y = 2250 - 50(0.04Y - 40)

Y = 2250 - 2Y + 2000

3Y = 4250

Y = 1416.67

r = 0.04 × 1416.67 - 40 = 56.67 - 40 = 16.67

所以均衡国民收入Y = 1416.67，均衡利率r = 16.67。

【下午：公共经济学——第8章 财政体制与转移支付】

一、财政管理体制概述

财政管理体制（Fiscal System） 是指国家在中央与地方政府之间划分财政收支范围和管理权限的制度。

核心问题： 财权与事权的匹配

基本原则：

  • 统一领导、分级管理
  • 财权与事权相匹配
  • 效率原则
  • 公平原则

二、政府间事权划分

事权（Expenditure Responsibility）： 各级政府的支出责任。

划分原则：

  • 全国性公共物品（国防、外交、货币政策）→ 中央政府
  • 地方性公共物品（城市维护、地方教育）→ 地方政府
  • 跨区域公共物品（交通干道、环境保护）→ 中央与地方共同承担

中国的事权划分（简表）：

事权类别中央地方共同
国防外交✓
宏观经济管理✓
教育✓
医疗卫生✓
社会保障✓
城市基础设施✓
地方治安✓

三、政府间财权划分

财权（Revenue Authority）： 各级政府组织收入的权力。

税种划分原则：

  • 与宏观经济稳定相关的税种（所得税）→ 中央
  • 税基分布不均匀的税种（资源税）→ 中央
  • 税基流动性强的税种（增值税）→ 中央
  • 税基流动性弱的税种（房产税）→ 地方
  • 受益性税种（城市维护建设税）→ 地方

中国现行税种划分：

  • 中央税： 关税、消费税
  • 地方税： 房产税、城镇土地使用税、土地增值税、车船税
  • 共享税： 增值税（中央50%：地方50%）、企业所得税（中央60%：地方40%）、个人所得税（中央60%：地方40%）

四、转移支付制度

转移支付（Transfer Payment）： 上级政府将部分财政收入无偿转移给下级政府使用的制度。

目的：

  • 弥补纵向财政缺口（中央收入多、支出少；地方收入少、支出多）
  • 弥补横向财政差距（富裕地区和贫困地区的财力差距）
  • 矫正外部性（地方政府提供具有跨区域外溢性的公共服务）
  • 实现特定政策目标

分类：

1. 一般性转移支付（无条件拨款）

  • 不指定用途
  • 用于均衡地区间财力差距
  • 计算公式：标准财政支出 - 标准财政收入

2. 专项转移支付（有条件拨款）

  • 指定具体用途（如教育、医疗、环保）
  • 可要求地方配套资金
  • 体现中央的政策意图
贵州历年高频考点： 一般性转移支付与专项转移支付的区别，常考名词解释和简答题。

五、中国的财政体制沿革

  • 统收统支（1949-1979）： 中央高度集权
  • 财政包干（1980-1993）： 中央与地方"分灶吃饭"
  • 分税制改革（1994至今）： 按税种划分中央与地方收入

1994年分税制改革的核心内容：

  • 按税种划分中央与地方收入
  • 建立中央对地方的税收返还制度
  • 建立规范的转移支付制度
  • 提高中央财政收入占全国财政收入的比重
贵州历年高频考点： 1994年分税制改革的核心内容，常以简答题出现。

六、政府间财政关系理论

蒂布特模型（Tiebout Model）： "用脚投票"理论——居民通过在不同地区之间迁移来选择自己偏好的公共物品组合，从而促进地方政府之间的竞争，提高公共物品供给效率。

奥茨分权定理（Oates' Decentralization Theorem）： 如果地方政府能够提供与当地居民偏好相匹配的公共物品，则分权提供比集权提供更有效率。

经济学原理答案

1. B

解析：平衡预算乘数 kB = kG + k_T = 1/(1-b) + (-b)/(1-b) = (1-b)/(1-b) = 1。即政府同时增加相等数额的税收和政府购买，国民收入的增加量等于政府支出的增加量。

2. A

解析：IS曲线向右下方倾斜，反映了利率与国民收入的反向关系。当利率下降时，投资成本降低，投资增加，通过乘数效应使国民收入增加。

3. C

解析：LM曲线向右上方倾斜，反映了利率与国民收入的正向关系。当国民收入增加时，交易性货币需求增加，在货币供给不变的情况下，利率上升以维持货币市场均衡。

4. A

解析："流动性陷阱"（Liquidity Trap）是凯恩斯提出的概念，指当利率降低到极低水平时，人们预期利率只会上升不会下降，因此无论增加多少货币供给，人们都会持有而不用于购买债券，导致货币需求无限大，货币政策失效。

5. C

解析：政府购买乘数 kG = 1/(1-0.75) = 1/0.25 = 4。ΔY = kG × ΔG = 4 × 100 = 400。

6. ABDE

解析：IS曲线反映产品市场均衡，右移因素包括政府购买增加、税收减少、自主性投资增加、边际消费倾向提高等。货币供给变化影响LM曲线，不影响IS曲线。

7. ABC

解析：LM曲线分为三个区间：凯恩斯区间（水平，利率极低，流动性陷阱）、中间区间（向右上倾斜，正常情况）、古典区间（垂直，利率极高）。

8. 答案要点：

IS曲线（Investment-Saving Curve）表示产品市场均衡（I = S）条件下利率与国民收入之间的关系。IS曲线向右下方倾斜，利率越低，投资越多，国民收入越高。IS曲线上的每一点都满足产品市场均衡。

LM曲线（Liquidity Preference-Money Supply Curve）表示货币市场均衡（L = M）条件下利率与国民收入之间的关系。LM曲线向右上方倾斜，收入越高，交易性货币需求越大，利率越高。LM曲线上的每一点都满足货币市场均衡。

IS-LM模型将产品市场和货币市场结合起来，两曲线的交点决定了均衡利率和均衡国民收入，此时两个市场同时达到均衡。

9. 计算过程：

（1）IS曲线：

Y_d = Y - T = Y - 100

C = 200 + 0.8(Y - 100) = 200 + 0.8Y - 80 = 120 + 0.8Y

Y = C + I + G = (120 + 0.8Y) + (150 - 10r) + 200 = 470 + 0.8Y - 10r

0.2Y = 470 - 10r

Y = 2350 - 50r ... IS方程

（2）LM曲线：

L = M/P

0.2Y - 5r = 300/1 = 300

5r = 0.2Y - 300

r = 0.04Y - 60 ... LM方程

（3）联立求解：

将LM代入IS：Y = 2350 - 50(0.04Y - 60)

Y = 2350 - 2Y + 3000

3Y = 5350

Y = 1783.33

r = 0.04 × 1783.33 - 60 = 71.33 - 60 = 11.33

均衡国民收入Y = 1783.33，均衡利率r = 11.33。

10. 答案要点：

三部门经济中的乘数类型：

（1）政府购买支出乘数 k_G = 1/(1-b)：政府购买增加1单位，国民收入增加1/(1-b)单位。政策含义：增加政府购买是刺激经济的有效手段。

（2）税收乘数 k_T = -b/(1-b)：税收增加1单位，国民收入减少b/(1-b)单位。政策含义：减税可以刺激经济增长。

（3）平衡预算乘数 kB = kG + k_T = 1：政府同时增加相同数额的税收和政府购买，国民收入增加量等于政府支出增加量。政策含义：即使保持预算平衡，政府扩张也能促进经济增长。

政策含义总结：在萧条时期，政府应增加支出、减少税收（扩张性财政政策）；在过热时期，政府应减少支出、增加税收（紧缩性财政政策）。

公共经济学答案

1. B

解析：2016年营改增全面推开后，增值税的分享比例调整为中央50%、地方50%。1994年分税制改革时增值税中央分享75%、地方25%。

2. B

解析：一般性转移支付（无条件拨款）的主要目标是均衡地区间财力差距，促进基本公共服务均等化，不指定具体用途。

3. C

解析：消费税属于中央税。增值税和企业所得税是共享税，房产税是地方税。

4. A

解析：蒂布特模型（Tiebout Model）认为，居民可以通过在不同地区之间迁移（"用脚投票"）来选择自己偏好的公共物品组合，从而促进地方政府之间的竞争，提高公共物品供给效率。

5. B

解析：2002年所得税分享改革后，企业所得税中央分享60%、地方分享40%。个人所得税也按此比例分享。

6. ABCE

解析：转移支付的目的包括弥补纵向财政缺口、弥补横向财政差距、矫正外部性、实现特定政策目标等。增加地方财政收入是手段而非目的。

7. ACE

解析：专项转移支付的特征包括：指定用途、政策导向性强、可要求地方配套资金。但地方自主权小（B错误），均等化效果不如一般性转移支付（D错误）。

8. 名词解释：

分税制（Tax-sharing System）是指按税种划分中央与地方财政收入的一种财政管理体制。中国从1994年开始实行分税制改革，核心内容包括：按税种划分中央与地方收入（中央税、地方税、共享税），建立中央对地方的税收返还制度，建立规范的转移支付制度。分税制提高了中央财政收入占全国财政收入的比重，增强了中央政府的宏观调控能力。

9. 答案要点：

一般性转移支付与专项转移支付的区别：

（1）用途不同：一般性转移支付不指定用途，地方可自主安排；专项转移支付指定具体用途，地方须按规定使用。

（2）地方自主权不同：一般性转移支付的地方自主权大；专项转移支付的地方自主权小。

（3）均等化效果不同：一般性转移支付的均等化效果好，可直接用于平衡地区财力差距；专项转移支付的均等化效果较弱。

（4）政策导向性不同：一般性转移支付的政策导向性强；专项转移支付的政策导向性强（体现中央特定政策意图）。

（5）监管要求不同：一般性转移支付的监管相对简单；专项转移支付的监管要求更高。

10. 答案要点：

背景：1994年分税制改革前，中国实行财政包干体制，导致中央财政收入占全国财政收入的比重持续下降（从1984年的40.5%下降到1993年的22%），中央宏观调控能力弱化，"两个比重"（中央财政收入占全国财政收入比重、全国财政收入占GDP比重）过低。

核心内容：

（1）按税种划分中央与地方收入：中央税（关税、消费税）、地方税（房产税、土地增值税等）、共享税（增值税中央75%：地方25%）。

（2）建立中央对地方的税收返还制度：以1993年为基期，保证地方既得利益。

（3）建立规范的转移支付制度。

（4）分设国税和地税两套征管机构。

意义：

（1）提高了"两个比重"，增强了中央宏观调控能力。

（2）建立了规范化的财政分配关系。

（3）促进了统一市场的形成。

（4）为公共财政体系的建立奠定了基础。

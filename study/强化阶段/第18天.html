【上午：经济学原理（中级）——第21-22章 财政货币政策与失业通货膨胀】

第21章 财政政策与货币政策

一、财政政策

财政政策（Fiscal Policy） 是政府通过调整税收和政府支出来影响总需求，从而实现宏观经济目标的政策。

财政政策工具：

  • 政府购买支出（G）
  • 税收（T）
  • 转移支付（TR）
  • 公债
1.1 自动稳定器（Automatic Stabilizers）

自动稳定器是指不需要政府主动干预，经济系统本身能自动调节、减缓经济波动的机制。

主要自动稳定器：

  • 累进所得税： 经济繁荣时，收入增加进入更高税率档次，税收自动增加，抑制过热；经济衰退时相反。
  • 社会保障和失业救济： 经济衰退时失业救济支出增加，维持消费；经济繁荣时减少。
  • 农产品价格支持制度
贵州历年高频考点： 自动稳定器的概念和形式，常考选择题和名词解释。
1.2 斟酌使用的财政政策（Discretionary Fiscal Policy）
  • 扩张性财政政策： 增加G、减少T → 治理衰退
  • 紧缩性财政政策： 减少G、增加T → 治理过热

政策时滞（Time Lag）：

  • 认识时滞：从问题发生到被认识到的时间
  • 决策时滞：从认识到决策的时间
  • 执行时滞：从决策到实施的时间
  • 效果时滞：从实施到产生效果的时间
贵州历年高频考点： 财政政策的时滞问题及其对政策效果的影响，常考简答题。
1.3 功能财政与平衡预算
  • 年度平衡预算： 每个财政年度收支平衡
  • 周期平衡预算： 一个经济周期内收支平衡
  • 功能财政（Functional Finance）： 以经济稳定为目标，不必追求预算平衡
1.4 公债

公债是政府为弥补财政赤字而发行的债券。

公债的经济影响：

  • 李嘉图等价定理（Ricardian Equivalence）： 消费者意识到今天的公债意味着未来的税收，因此增加储蓄减少消费，抵消财政政策的扩张效果。
  • 公债的负担：代际转移问题

二、货币政策

货币政策（Monetary Policy） 是中央银行通过调节货币供给和利率来影响总需求的政策。

2.1 货币政策工具
工具定义作用机制
法定存款准备金率商业银行必须缴存的准备金比例调整货币乘数
再贴现率商业银行向央行借款的利率影响商业银行借款成本
公开市场业务央行在金融市场上买卖政府债券最常用、最灵活的工具

公开市场业务操作：

  • 买进债券 → 货币供给增加 → 利率下降 → 投资增加 → Y增加
  • 卖出债券 → 货币供给减少 → 利率上升 → 投资减少 → Y减少
贵州历年高频考点： 三大货币政策工具及其作用机制，常考选择题和简答题。
2.2 货币乘数

货币乘数（Money Multiplier）：

m = 1 / rd

其中rd为法定存款准备金率。

货币供给： M = m × B（B为基础货币）

基础货币（Monetary Base）： 流通中的现金 + 商业银行准备金

完整货币乘数公式：

m = (1 + cr) / (rd + cr + re)

其中：

  • cr = 现金漏出率（现金/存款）
  • rd = 法定存款准备金率
  • re = 超额存款准备金率
贵州历年高频考点： 货币乘数的计算、基础货币和货币供给的关系，常考计算题。

【例题21.1】 法定存款准备金率为10%，现金漏出率为15%，超额存款准备金率为5%。计算货币乘数。

解：

m = (1 + cr) / (rd + cr + re) = (1 + 0.15) / (0.10 + 0.15 + 0.05) = 1.15 / 0.30 = 3.83

即货币乘数约为3.83，每增加1元基础货币，货币供给增加约3.83元。

2.3 货币政策传导机制

央行调整货币供给 → 利率变化 → 投资和消费变化 → 总需求变化 → 产出和价格变化

凯恩斯传导机制： M↑ → r↓ → I↑ → Y↑

货币主义传导机制： M↑ → 资产价格变化 → 支出增加 → Y↑

2.4 货币政策规则
  • 单一规则（弗里德曼）： 按固定比率增加货币供给
  • 泰勒规则（Taylor Rule）： 根据通胀缺口和产出缺口调整利率

第22章 失业与通货膨胀

一、失业

1.1 失业的定义与测量

失业（Unemployment） 是指有劳动能力、愿意工作且正在寻找工作但未找到工作的状态。

失业率 = 失业人数 / 劳动力人数 × 100%

劳动力 = 就业人数 + 失业人数

1.2 失业的类型
类型原因特点
摩擦性失业劳动者在换工作过程中的暂时失业正常现象，不可避免
结构性失业产业结构变化导致技能不匹配长期性，需要再培训
周期性失业经济衰退导致总需求不足宏观调控的重点
季节性失业季节变化导致可预测

自然失业率（Natural Rate of Unemployment）： 摩擦性失业和结构性失业之和，即经济在潜在产出水平下的失业率。

充分就业（Full Employment）： 失业率等于自然失业率的状态，不是零失业。

贵州历年高频考点： 四种失业类型的区分、自然失业率概念，常考选择题和简答题。
1.3 奥肯定律（Okun's Law）

奥肯定律描述了失业与实际GDP之间的关系：

ΔY / Y = -β × (u - u*)

其中：

  • ΔY/Y：实际GDP偏离潜在GDP的百分比
  • u：实际失业率
  • u*：自然失业率
  • β：奥肯系数（通常约为2 ~ 3）

经济含义： 失业率每上升1个百分点，实际GDP约下降2~3个百分点。

贵州历年高频考点： 奥肯定律的计算和应用，常考选择题和计算题。

【例题22.1】 某国自然失业率为5%，奥肯系数为2.5，当前失业率为8%。计算实际GDP相对于潜在GDP的损失。

解：

ΔY / Y = -2.5 × (8% - 5%) = -2.5 × 3% = -7.5%

实际GDP低于潜在GDP的7.5%。

二、通货膨胀

2.1 通货膨胀的定义与测量

通货膨胀（Inflation） 是指商品和服务的价格水平持续上升的现象。

衡量指标：

  • CPI（消费者价格指数）： 一篮子消费品的价格变化
  • PPI（生产者价格指数）： 生产环节的价格变化
  • GDP平减指数： 所有最终产品和服务的价格变化

通货膨胀率 = (当期价格指数 - 基期价格指数) / 基期价格指数 × 100%

2.2 通货膨胀的类型
按程度按原因
温和通胀（< 10%）需求拉动型通胀
奔腾通胀（10% - 100%）成本推动型通胀
恶性通胀（> 50%/月）结构性通胀

需求拉动型通胀（Demand-pull Inflation）： AD右移 → P↑（"过多的货币追逐过少的商品"）

成本推动型通胀（Cost-push Inflation）： AS左移 → P↑ Y↓（工资推动、原材料涨价）

2.3 通货膨胀的经济效应
  • 再分配效应：
  • 债权人受损，债务人受益
  • 固定收入者受损（退休人员）
  • 持有现金者受损
  • 产出效应：
  • 未预期到的温和通胀可能短期内刺激产出
  • 恶性通胀破坏经济
  • 鞋底成本（Shoe-leather Cost）： 频繁去银行取钱
  • 菜单成本（Menu Cost）： 频繁调整价格
  • 税收扭曲： 名义收入增加导致税负增加
贵州历年高频考点： 通货膨胀的再分配效应（债权人和债务人的影响），常考选择题。
2.4 菲利普斯曲线（Phillips Curve）

短期菲利普斯曲线： 失业率与通货膨胀率之间存在交替关系（负相关）

长期菲利普斯曲线： 在自然失业率处垂直——长期中通胀与失业无关

弗里德曼的预期扩展菲利普斯曲线：

π = πᵉ - β(u - u*)

其中：

  • π：实际通货膨胀率
  • πᵉ：预期通货膨胀率
  • u：实际失业率
  • u*：自然失业率

政策含义： 短期可以通过提高通胀来降低失业率；但长期中，预期调整后，失业率回到自然率，通胀上升。

贵州历年高频考点： 菲利普斯曲线的含义、短期与长期的区别，常考简答题和论述题！

【例题22.2】 某国自然失业率为6%，菲利普斯曲线方程为 π = πᵉ - 0.4(u - 6%)。如果预期通胀为3%，政府希望将通胀率降低到1%，需要将失业率提高到多少？

解：

π = πᵉ - 0.4(u - 6%)

1% = 3% - 0.4(u - 6%)

0.4(u - 6%) = 3% - 1% = 2%

u - 6% = 2% / 0.4 = 5%

u = 11%

需要将失业率提高到11%（牺牲率）。

【下午：公共经济学——第10章 公共经济政策】

一、公共经济政策的目标

公共经济政策（Public Economic Policy） 是政府为了实现一定的经济社会目标而制定的经济政策。

四大目标：

  • 经济增长： 保持经济持续稳定增长
  • 物价稳定： 控制通货膨胀，保持币值稳定
  • 充分就业： 降低失业率
  • 国际收支平衡： 维持汇率稳定和外汇储备

目标之间的冲突：

  • 经济增长与物价稳定（菲利普斯曲线关系）
  • 充分就业与国际收支平衡（米德冲突）
贵州历年高频考点： 四大政策目标及其冲突，常考简答题。

二、公共经济政策的类型与工具

1. 财政政策

  • 扩张性财政政策： 增加政府支出、减少税收
  • 紧缩性财政政策： 减少政府支出、增加税收

2. 货币政策

  • 扩张性货币政策： 降低准备金率、降低再贴现率、买进债券
  • 紧缩性货币政策： 提高准备金率、提高再贴现率、卖出债券

3. 收入政策

  • 工资和价格管制
  • 工资-价格指导线
  • 税收激励政策

4. 产业政策

  • 产业结构调整
  • 技术创新支持
  • 国有企业改革

三、宏观经济政策的理论基础

凯恩斯主义：

  • 市场不能自动实现充分就业
  • 政府应积极干预经济
  • 财政政策优先于货币政策

货币主义（弗里德曼）：

  • 市场机制有效
  • 长期菲利普斯曲线垂直
  • 主张单一货币规则

新古典综合派：

  • 结合凯恩斯主义和古典经济学
  • 短期凯恩斯、长期古典

供给学派：

  • 减税刺激供给
  • 拉弗曲线
  • 放松管制
贵州历年高频考点： 各学派对财政政策和货币政策有效性的不同观点，常考简答题和论述题。

四、政策协调与搭配

蒙代尔-弗莱明模型：

  • 在开放经济中，财政政策和货币政策的有效性取决于汇率制度
  • 固定汇率制：财政政策有效，货币政策无效
  • 浮动汇率制：货币政策有效，财政政策无效

丁伯根原则： 要同时实现N个独立政策目标，政府至少需要N种独立的政策工具。

政策时滞与应对：

  • 内部时滞：认识时滞 + 决策时滞
  • 外部时滞：执行时滞 + 效果时滞
  • 一般来说，货币政策内部时滞短（央行决策快）、外部时滞长；财政政策内部时滞长（立法程序慢）、外部时滞短。

五、中国供给侧结构性改革

背景： 中国经济进入新常态，面临结构性矛盾（产能过剩、杠杆率高、库存多）

五大任务（"三去一降一补"）：

  • 去产能： 化解过剩产能（钢铁、煤炭）
  • 去库存： 减少房地产库存
  • 去杠杆： 降低企业负债率
  • 降成本： 降低企业制度性交易成本
  • 补短板： 加强创新、扶贫、环保等薄弱环节
贵州历年高频考点： 供给侧结构性改革的核心内容，"三去一降一补"的具体含义，常考论述题。

【今日练习题答案与解析】

经济学原理答案

1. C

解析：公开市场业务（Open Market Operations）是中央银行在金融市场上买卖政府债券的行为，是最常用、最灵活、最精确的货币政策工具。央行可以随时进行小规模操作，对市场的冲击较小。

2. B

解析：自然失业率是指经济处于潜在产出水平时的失业率，等于摩擦性失业率和结构性失业率之和。自然失业率不等于零，因为摩擦性失业和结构性失业在任何经济体中都会存在。

3. B

解析：奥肯定律指出，失业率每上升1个百分点，实际GDP下降约2~3个百分点（奥肯系数通常为2~3）。具体数值因国家、时期不同而有所差异。

4. B

解析：需求拉动型通货膨胀（Demand-pull Inflation）是由于总需求过度增长，"过多的货币追逐过少的商品"，导致价格水平上升。工资上涨和原材料涨价属于成本推动型通胀的原因。

5. C

解析：长期菲利普斯曲线在自然失业率处垂直，表明长期中失业率与通货膨胀率之间不存在交替关系。无论通货膨胀率多高，长期失业率都会回到自然失业率水平。

6. ABD

解析：自动稳定器是指无需政府主动干预就能自动调节经济的机制，包括累进所得税（繁荣时自动多征税，衰退时自动少征税）、失业救济金（衰退时自动增加支出）和农产品价格支持制度。政府购买和公债发行属于斟酌使用的财政政策工具。

7. ABCDE

解析：通货膨胀的再分配效应：债权人受损（收回的货币购买力下降）、债务人受益（实际债务减少）、固定收入者受损（实际收入下降）、持有现金者受损（现金购买力下降）、政府受益（因其为最大债务人，且纳税人进入更高税率档次）。

8. 答案要点：

（1）法定存款准备金率：央行调整商业银行必须缴存的准备金比例。提高准备金率→减少可贷资金→减少货币供给；降低准备金率→增加可贷资金→增加货币供给。作用强烈但缺乏灵活性。

（2）再贴现率：央行调整商业银行向央行借款的利率。提高再贴现率→商业银行借款成本上升→减少借款→减少货币供给；降低再贴现率效果相反。

（3）公开市场业务：央行在金融市场上买卖政府债券。买进债券→向市场投放货币→增加货币供给；卖出债券→从市场收回货币→减少货币供给。最常用因可灵活控制操作规模。

10. 答案要点：

短期菲利普斯曲线：

（1）向右下方倾斜，失业率与通胀率负相关。

（2）通胀上升→实际工资下降→企业增加雇佣→失业率下降。

（3）政策含义：政府可以通过提高通胀率来降低失业率（取舍关系）。

长期菲利普斯曲线：

（1）在自然失业率处垂直，失业率与通胀率无关。

（2）工人预期到通胀后调整工资要求→实际工资不变→失业率回到自然率。

（3）政策含义：长期中失业率由劳动市场结构决定，货币政策不能永久降低失业率。

区别总结：

（1）形状：短期向右下倾斜，长期垂直。

（2）预期作用：短期预期未调整，长期预期完全调整。

（3）取舍关系：短期存在，长期不存在。

政策含义：短期可利用通胀与失业的取舍关系进行需求管理；长期应关注供给侧改革以降低自然失业率。

公共经济学答案

1. A

解析：公共经济政策的四大目标是经济增长、物价稳定、充分就业和国际收支平衡。其中物价稳定和充分就业属于内部均衡目标，国际收支平衡属于外部均衡目标。经济增长既是目标也是结果。

2. B

解析：蒙代尔-弗莱明模型（Mundell-Fleming Model）分析开放经济中政策有效性：浮动汇率制下，货币政策有效（货币供给变化影响汇率和净出口），财政政策无效（财政扩张导致本币升值，挤出净出口）。固定汇率制下相反。

3. B

解析：供给侧结构性改革的核心是调整供给结构，通过优化资源配置、提高生产效率、增加有效供给来推动经济增长。与需求侧管理不同，供给侧改革注重长期增长潜力。

4. B

解析：丁伯根原则（Tinbergen's Rule）指出，政府要实现N个独立的政策目标，至少需要N种独立的政策工具。政策目标和政策工具的数量必须匹配，且工具之间不能相互冲突。

5. B

解析："去杠杆"是指降低企业负债率（杠杆率），防范和化解金融风险。企业的过度负债是系统性风险的重要来源。

6. ABCD

解析：宏观经济政策目标之间的冲突：经济增长与物价稳定（高增长常伴随通胀）、充分就业与国际收支平衡（米德冲突）、物价稳定与充分就业（菲利普斯曲线关系）、经济增长与国际收支平衡（增长带动进口增加导致逆差）。这些冲突使政策选择需要权衡。

7. ABCDE

解析：供给侧结构性改革的五大任务是"三去一降一补"：去产能（化解过剩产能）、去库存（减少房地产库存）、去杠杆（降低企业负债率）、降成本（降低企业制度性交易成本）、补短板（加强创新、扶贫、环保等薄弱环节）。

8. 名词解释：

菲利普斯曲线（Phillips Curve）是由经济学家菲利普斯提出的描述失业率与通货膨胀率之间关系的曲线。短期菲利普斯曲线向右下方倾斜，表明失业率与通胀率之间存在交替关系（负相关），即失业率越低，通胀率越高。长期菲利普斯曲线在自然失业率处垂直，表明长期中失业率与通胀率无关，任何通胀率下失业率都会回到自然失业率水平。该曲线对宏观经济政策有重要指导意义，但也受到"滞胀"现象的挑战。

9. 答案要点：

凯恩斯主义与货币主义在宏观经济政策上的主要分歧：

（1）市场机制的有效性：

  • 凯恩斯主义：市场不能自动实现充分就业，存在有效需求不足。
  • 货币主义：市场机制基本有效，经济具有内在稳定性。

（2）财政政策与货币政策：

  • 凯恩斯主义：财政政策优先，货币政策效果有限（尤其是在流动性陷阱中）。
  • 货币主义：财政政策有挤出效应，货币政策对长期通胀有决定性影响。

（3）菲利普斯曲线：

  • 凯恩斯主义：短期和长期都存在通胀与失业的交替关系。
  • 货币主义：短期存在交替，长期不存在（垂直的长期菲利普斯曲线）。

（4）政策主张：

  • 凯恩斯主义：积极干预，斟酌使用财政政策和货币政策。
  • 货币主义：主张单一货币规则（按固定比率增加货币供给），反对积极干预。

（5）政策时滞：

  • 凯恩斯主义：认为可以通过预测来克服时滞问题。
  • 货币主义：认为时滞会导致政策"火上浇油"或"雪上加霜"，加剧经济波动。

10. 答案要点：

背景：

（1）中国经济进入新常态，从高速增长转向中高速增长。

（2）经济结构性问题突出：产能过剩严重（钢铁、煤炭等行业）、房地产库存高企、企业负债率过高（杠杆率高）、生产成本上升、创新能力不足等。

（3）传统需求侧刺激（"四万亿"）效果递减，单纯依靠扩大总需求难以解决结构性问题。

"三去一降一补"主要内容：

（1）去产能：化解钢铁、煤炭等行业过剩产能，处置"僵尸企业"。

（2）去库存：减少三四线城市房地产库存，推进城镇化。

（3）去杠杆：降低企业负债率，防范金融风险。

（4）降成本：降低企业税费负担、融资成本、制度性交易成本。

（5）补短板：加强创新驱动、精准扶贫、生态环保、基础设施等薄弱环节。

经济意义：

（1）推动经济增长方式转变：从要素驱动转向创新驱动。

（2）优化产业结构：淘汰落后产能，发展新兴产业。

（3）防范金融风险：降低杠杆率，维护金融稳定。

（4）提高全要素生产率：通过改革释放制度红利。

（5）促进长期可持续发展：解决深层次结构性矛盾。

第13天：要素市场理论（劳动与资本）+ 公共支出理论

【上午：经济学原理（中级）——第12-13章 要素市场理论】

第12章 要素市场理论（上）：劳动市场

一、要素市场概述

要素市场（Factor Market）是指生产要素（劳动、资本、土地、企业家才能）进行交易的市场。与产品市场不同，要素市场的需求是派生需求（Derived Demand），即企业对要素的需求来源于消费者对最终产品的需求。

要素市场与产品市场的区别：

  • 产品市场：需求方是消费者，供给方是企业
  • 要素市场：需求方是企业，供给方是要素所有者（居民）

二、劳动市场需求

1. 边际收益产品（MRP, Marginal Revenue Product）

MRP = MP × MR

其中：

  • MP（Marginal Product）= 边际产量
  • MR（Marginal Revenue）= 边际收益

2. 边际要素成本（MFC, Marginal Factor Cost）

MFC = 增加一单位要素所增加的总成本

利润最大化用工原则： MRP = MFC

在完全竞争的要素市场中，W（工资）= MFC，企业雇佣劳动直到 MRP = W。

贵州历年高频考点： 边际收益产品MRP的计算是高频计算题考点。给定生产函数和产品价格，求最优劳动雇佣量。

【例题12.1】 某企业生产函数为 Q = 10L - 0.5L²，产品价格 P = 2，工资率 W = 10。求利润最大化的劳动雇佣量。

解：

  • MP = dQ/dL = 10 - L
  • MRP = MP × P = (10 - L) × 2 = 20 - 2L
  • 利润最大化条件：MRP = W
  • 20 - 2L = 10
  • 2L = 10
  • L = 5

所以最优劳动雇佣量为5单位。

三、劳动市场供给

个人劳动供给曲线——向后弯曲：

工资率上升对劳动供给有两种效应：

  • 替代效应： 工资上升，闲暇的机会成本上升，劳动者增加工作时间
  • 收入效应： 工资上升，劳动者收入增加，对闲暇的消费增加，减少工作时间

当工资较低时，替代效应 > 收入效应，劳动供给随工资上升而增加（曲线向右上方倾斜）。当工资较高时，收入效应 > 替代效应，劳动供给随工资上升而减少（曲线向左上方弯曲）。因此个人劳动供给曲线呈向后弯曲形状。

贵州历年高频考点： 向后弯曲的劳动供给曲线的"收入效应>替代效应"部分，常以简答题出现。

四、劳动市场均衡

  • 完全竞争劳动市场：工资由市场供求决定，企业是工资接受者
  • 不完全竞争劳动市场：
  • 买方垄断： 只有一个买方（企业），企业可以压低工资
  • 工会垄断： 工人联合起来提高工资
  • 双边垄断： 买方和卖方都有垄断力量

五、工资差异的原因

  • 补偿性工资差异： 工作条件差的工作需要更高工资来补偿
  • 人力资本差异： 教育、培训、经验不同导致生产率不同
  • 能力差异： 天赋和能力不同
  • 歧视： 基于种族、性别等的非市场因素
  • 效率工资： 企业支付高于市场出清水平的工资以提高生产率

第13章 要素市场理论（下）：资本市场

一、资本与利息

资本（Capital） 是指用于生产的生产资料，包括机器、设备、厂房等。利息是资本要素的价格。

资本的边际产品价值（VMP）： VMP = MP × P

二、资本需求——投资决策

1. 现值的概念

现值（PV, Present Value）是指未来一笔钱在现在的价值。

PV = FV / (1 + r)ⁿ

其中：

  • FV = 未来价值
  • r = 利率（贴现率）
  • n = 年数

2. 净现值法（NPV, Net Present Value）

NPV = Σ(Rt / (1 + r)^t) - C₀

其中：

  • Rt = 第t年的收益
  • C₀ = 初始投资
  • r = 贴现率

决策规则： NPV > 0，则项目可行。

贵州历年高频考点： NPV的计算是必考计算题，要熟练掌握贴现公式。

【例题13.1】 某投资项目需要初始投资100万元，未来3年每年的收益分别为40万、50万、60万，贴现率为10%。计算NPV并判断是否值得投资。

解：

  • NPV = 40/(1.1)¹ + 50/(1.1)² + 60/(1.1)³ - 100
  • = 40/1.1 + 50/1.21 + 60/1.331 - 100
  • = 36.36 + 41.32 + 45.08 - 100
  • = 122.76 - 100
  • = 22.76（万元）

NPV = 22.76 > 0，值得投资。

三、资本供给——储蓄决策

储蓄决策是跨期消费选择问题。消费者在当期消费和未来消费之间进行权衡。

跨期预算约束：

C₁ + C₂/(1+r) = Y₁ + Y₂/(1+r)

四、土地与租金

经济租金（Economic Rent） 是指对生产要素的支付超过其保留收益的部分。

准租金（Quasi-rent） 是指在短期内固定要素的收益。

地租的决定： 土地的供给完全无弹性（垂直），地租完全由需求决定。

五、收入分配与洛伦兹曲线

洛伦兹曲线（Lorenz Curve） 描述了人口百分比与收入百分比之间的关系。

基尼系数（Gini Coefficient）： G = A / (A + B)

  • G = 0 表示绝对平等
  • G = 1 表示绝对不平等
  • 一般取值范围：0.3 ~ 0.5
贵州历年高频考点： 基尼系数的含义和计算、洛伦兹曲线的理解常考选择题和简答题。

【下午：公共经济学——第6章 公共支出理论】

一、公共支出的概念与分类

公共支出（Public Expenditure） 是指政府为履行其职能而支出的财政资金。

分类方式：

  • 按经济性质：
  • 购买性支出： 政府购买商品和服务的支出（如国防、教育、基建）
  • 转移性支出： 政府无偿转移给居民和企业的支出（如社保、补贴）
  • 按政府职能：
  • 经济建设支出
  • 社会文教支出
  • 国防支出
  • 行政管理支出
  • 按受益范围：
  • 一般性公共支出
  • 专项支出

二、公共支出规模的增长趋势

瓦格纳法则（Wagner's Law）： 随着经济发展，公共支出占GDP的比重不断上升。

原因：

  • 政治因素： 政府职能扩张
  • 经济因素： 工业化导致市场失灵增多
  • 社会因素： 城市化、人口老龄化

三、公共支出增长的理论解释

  • 皮考克-威斯曼替代效应理论：
  • 在危机（战争、经济危机）时期，公共支出会跳跃式增长
  • 危机过后，公共支出不会回到原来的水平
  • "替代效应"：危机期间私人支出被公共支出替代
  • 鲍莫尔的成本病理论（Baumol's Cost Disease）：
  • 经济分为进步部门（制造业，生产率增长快）和非进步部门（服务业/政府，生产率增长慢）
  • 非进步部门的单位成本不断上升，导致公共支出增长
  • 公共选择理论：
  • 官僚行为理论： 官僚追求预算最大化
  • 中间选民理论： 政治家迎合中间选民偏好
  • 利益集团理论： 利益集团推动有利于自己的支出

四、购买性支出分析

1. 政府消费性支出

  • 国防支出：纯公共物品
  • 行政管理支出：维持政府运转
  • 教科文卫支出：具有正外部性

2. 政府投资性支出

  • 基础设施建设（交通、能源、通信）
  • 具有乘数效应，带动私人投资

五、转移性支出分析

1. 社会保障支出

  • 社会保险（养老保险、医疗保险、失业保险）
  • 社会救助（最低生活保障）
  • 社会福利

2. 财政补贴

  • 价格补贴
  • 企业亏损补贴
  • 出口退税
贵州历年高频考点： 购买性支出与转移性支出的区别、瓦格纳法则、鲍莫尔成本病理论，常考名词解释和简答题。

六、公共支出效益分析

成本-效益分析法（Cost-Benefit Analysis, CBA）：

  • 比较项目的全部社会收益与社会成本
  • 选择净效益最大的项目
  • 关键在于：如何衡量无形成本和收益（如环境价值、生命价值）

步骤：

  • 确定项目方案
  • 识别成本和收益
  • 量化成本和收益（货币化）
  • 计算净现值或内部收益率
  • 选择最优方案

【例题6.1】 某市政府考虑建设一座桥梁，建设成本为5000万元，每年维护成本为200万元，预计每年产生社会效益800万元，桥的使用寿命为20年，贴现率为5%。计算该项目的净现值。

解：

  • 初始成本 = 5000万元
  • 每年净收益 = 800 - 200 = 600万元
  • 年金现值系数 = [1 - (1.05)^(-20)] / 0.05 = 12.462
  • 收益总现值 = 600 × 12.462 = 7477.2万元
  • NPV = 7477.2 - 5000 = 2477.2万元

NPV > 0，项目可行。

经济学原理答案

1. B

解析：完全竞争要素市场中，企业是价格接受者，工资W等于MFC。利润最大化条件为MRP = MFC，因此MRP = W。

2. C

解析：当工资较低时，替代效应大于收入效应，劳动供给随工资上升而增加（曲线向右上方倾斜）。当工资较高时，收入效应大于替代效应，劳动供给随工资上升而减少（曲线向左上方弯曲）。因此劳动供给曲线呈向后弯曲形状。

3. C

解析：基尼系数介于0和1之间。0表示绝对平等，1表示绝对不平等。

4. A

解析：MP = dQ/dL = 20 - 2L

MRP = MP × P = (20 - 2L) × 3 = 60 - 6L

利润最大化条件：MRP = W

60 - 6L = 30

6L = 30

L = 5

5. C

解析：土地的自然供给是固定的，不受价格影响，因此供给曲线是完全无弹性的（垂直）。

6. ABCD

解析：技术进步（E）影响的是劳动需求而非供给。人口规模、劳动参与率、工作时间和人力资本都是影响劳动供给的因素。（注意：教材中对劳动供给因素的具体表述有所不同，此题按照常见教材选择。）

7. ABCD

解析：经济租金是支付给要素的超过其保留收益的部分。供给越缺乏弹性，经济租金越大。土地的供给完全无弹性，因此地租全部是经济租金。经济租金不会影响要素供给（因为即使没有租金，要素也会被提供到保留收益水平）。生产者剩余是另一个概念，不完全相同。

8. 答案要点：

向后弯曲的劳动供给曲线是指：当工资率较低时，劳动供给量随工资上升而增加（曲线向右上方倾斜）；但当工资率达到一定水平后，劳动供给量随工资上升反而减少（曲线向左上方弯曲），整个曲线呈现向后弯曲的形状。

原因在于工资率变动对劳动供给产生的两种效应：

（1）替代效应：工资率上升意味着闲暇的机会成本提高，劳动者会增加工作时间替代闲暇，使劳动供给增加。

（2）收入效应：工资率上升使劳动者收入增加，对闲暇的消费增加，从而减少工作时间，使劳动供给减少。

当工资率较低时，替代效应大于收入效应，劳动供给增加；当工资率较高时，收入效应大于替代效应，劳动供给减少。

9. 计算过程：

NPV = 60/(1.08)¹ + 70/(1.08)² + 80/(1.08)³ + 90/(1.08)⁴ - 200

1/(1.08)¹ = 0.9259

1/(1.08)² = 0.8573

1/(1.08)³ = 0.7938

1/(1.08)⁴ = 0.7350

NPV = 60 × 0.9259 + 70 × 0.8573 + 80 × 0.7938 + 90 × 0.7350 - 200

= 55.55 + 60.01 + 63.50 + 66.15 - 200

= 245.21 - 200

= 45.21（万元）

NPV = 45.21 > 0，该项目值得投资。

10. 答案要点：

在完全竞争要素市场中，企业是产品和要素的价格接受者。

（1）产品的边际收益等于价格：MR = P

（2）要素的边际收益产品：MRP = MP × MR = MP × P = VMP

（3）要素的边际要素成本：MFC = W（工资率）

（4）利润最大化的要素使用量条件：MRP = MFC

（5）即 VMP = W，也就是 MP × P = W

（6）当VMP > W时，企业增加要素投入可增加利润；当VMP < W时，企业减少要素投入可增加利润；当VMP = W时，企业实现利润最大化。

公共经济学答案

1. B

解析：购买性支出是政府购买商品和服务的支出，如国防支出。养老保险、财政补贴、失业救济都属于转移性支出。

2. B

解析：瓦格纳法则指出，随着经济发展，公共支出占GDP的比重不断上升，描述的是公共支出的增长规律。

3. B

解析：鲍莫尔的"成本病"理论认为，非进步部门（如政府服务）的劳动生产率增长慢于进步部门（如制造业），但工资水平会向进步部门看齐，导致单位成本上升。

4. C

解析：成本-效益分析法中，净现值NPV大于0时项目可行，表示项目的社会收益大于社会成本。

5. C

解析：社会保障支出是政府无偿转移给居民的支出，属于转移性支出。基础设施建设支出、教育支出、国防支出属于购买性支出。

6. AB

解析：公共支出按经济性质可分为购买性支出和转移性支出。CDE是按其他标准的分类。

7. ABD

解析：瓦格纳认为公共支出增长的原因包括：政府职能扩张（政治因素）、工业化导致市场失灵增多（经济因素）、城市化和人口老龄化（社会因素）。CE不是瓦格纳的主要观点。

8. 名词解释：

瓦格纳法则（Wagner's Law）是由德国经济学家阿道夫·瓦格纳提出的公共支出增长理论。该法则指出，随着工业化进程和经济发展，国家职能不断扩大，公共支出占国民生产总值的比重呈不断上升趋势。瓦格纳从政治因素（政府职能扩张）、经济因素（市场失灵增多）和社会因素（城市化、人口老龄化）三个方面解释了这一趋势。

9. 答案要点：

购买性支出和转移性支出的区别：

（1）性质不同：购买性支出是政府以等价交换方式购买商品和服务；转移性支出是政府无偿转移资金。

（2）对资源配置的影响：购买性支出直接影响资源配置（政府直接消耗资源）；转移性支出间接影响资源配置（通过改变个人收入影响消费）。

（3）对收入分配的影响：购买性支出对收入分配影响间接；转移性支出直接改变收入分配格局。

（4）对GDP的影响：购买性支出直接计入GDP；转移性支出不计入GDP。

（5）政府职能体现：购买性支出体现政府配置资源职能；转移性支出体现政府收入再分配职能。

10. 答案要点：

公共支出增长的主要理论解释包括：

（1）瓦格纳法则：随着经济发展，公共支出占GDP比重不断上升。原因：政府职能扩张、市场失灵增多、城市化与人口老龄化。

（2）皮考克-威斯曼替代效应理论：公共支出在危机时期跳跃式增长，危机后不会回到原来水平。存在"检查效应"——危机使人们接受更高的税收水平。

（3）鲍莫尔的成本病理论：进步部门（制造业）和非进步部门（政府服务）的劳动生产率增长不均等，导致非进步部门单位成本持续上升。

（4）公共选择理论：官僚追求预算最大化；政治家迎合中间选民；利益集团推动有利于自己的支出。

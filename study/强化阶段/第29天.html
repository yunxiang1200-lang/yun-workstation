【上午：经济学原理（中级）——第16-17章 国民收入核算与简单国民收入决定（上）】

第16章 国民收入核算

一、国内生产总值（GDP）的概念

国内生产总值（Gross Domestic Product, GDP） 是指在一定时期内（通常为一年）在一国领土范围内生产的最终产品和服务的市场价值。

理解GDP的要点：

  • 市场价值： 用货币衡量
  • 最终产品： 不包括中间产品（避免重复计算）
  • 国土原则： 在一国领土范围内（GNP是国民原则）
  • 一定时期： 流量概念
  • 合法生产： 不包括非法交易和地下经济

二、GDP的三种核算方法

1. 支出法（最常用）

GDP = C + I + G + (X - M)

其中：

  • C（消费）： 居民消费支出（耐用品、非耐用品、服务）
  • I（投资）： 固定资产投资 + 存货投资（总投资 = 净投资 + 折旧）
  • G（政府购买）： 政府消费性支出 + 政府投资性支出（不包括转移支付）
  • X - M（净出口）： 出口减进口

2. 收入法

GDP = 工资 + 利息 + 租金 + 利润 + 间接税 + 折旧

3. 生产法（增加值法）

GDP = 各产业增加值之和 = 总产值 - 中间投入

贵州历年高频考点： 三种核算方法的计算、支出法各项的具体内容，必考计算题。

【例题16.1】 某国2023年数据：消费8000亿，投资3000亿，政府购买2500亿，转移支付500亿，出口2000亿，进口1800亿。折旧500亿。计算GDP。

解：

GDP = C + I + G + (X - M)

= 8000 + 3000 + 2500 + (2000 - 1800)

= 8000 + 3000 + 2500 + 200

= 13700（亿元）

注意：政府购买G = 2500，不包括转移支付500亿。

三、国民收入核算中的其他指标

  • GNP（国民生产总值）： GDP + 国外净要素收入
  • NNP（国民生产净值）： GNP - 折旧
  • NI（国民收入）： NNP - 间接税
  • PI（个人收入）： NI - 公司未分配利润 - 公司所得税 - 社会保险费 + 转移支付
  • DPI（个人可支配收入）： PI - 个人所得税

关系图： GDP → GNP → NNP → NI → PI → DPI

贵州历年高频考点： 各指标之间的换算关系，常见于选择题和简答题。

四、名义GDP与实际GDP

名义GDP（Nominal GDP）： 按当年价格计算的GDP

实际GDP（Real GDP）： 按基年价格计算的GDP

GDP平减指数 = （名义GDP / 实际GDP）× 100

实际GDP = 名义GDP / GDP平减指数 × 100

贵州历年高频考点： 名义GDP与实际GDP的换算、GDP平减指数的计算。

【例题16.2】 某国2022年名义GDP为5000亿，2023年名义GDP为5500亿，GDP平减指数从100上升到110。计算2023年的实际GDP。

解：

2023年实际GDP = 5500 / 110 × 100 = 5000（亿）

说明名义GDP增长了10%，但实际GDP不变，全部增长来自物价上涨。

五、国民收入核算的局限

  • 未包括非市场交易（家务劳动、志愿者服务）
  • 未反映收入分配状况
  • 未考虑环境破坏和资源消耗
  • 未反映闲暇的价值
  • 地下经济未计入

第17章 简单国民收入决定（上）——两部门经济

一、总需求与均衡产出

均衡产出（Equilibrium Output）： 总供给 = 总需求

在两部门经济（居民+企业）中：

  • 总需求AD = C + I
  • 总供给AS = C + S
  • 均衡条件：I = S

二、消费函数与储蓄函数

凯恩斯消费函数（Keynesian Consumption Function）：

C = a + bY

其中：

  • a： 自主性消费（收入为0时的消费，> 0）
  • b： 边际消费倾向（MPC, Marginal Propensity to Consume），0 < b < 1

边际消费倾向（MPC）： MPC = ΔC / ΔY

平均消费倾向（APC）： APC = C / Y

储蓄函数：

S = Y - C = Y - (a + bY) = -a + (1 - b)Y

边际储蓄倾向（MPS）： MPS = ΔS / ΔY = 1 - b

MPC + MPS = 1

贵州历年高频考点： MPC和MPS的关系、消费函数的计算，常以选择题和计算题出现。

三、投资函数

在两部门经济中，投资I被假定为外生变量（由利率等外部因素决定，与当前收入无关）。

I = I₀（自主性投资）

贵州历年高频考点： 注意简化的两部门模型中I是外生变量。

四、均衡国民收入的决定

1. 收入-支出法（总需求法）

均衡条件：Y = AD = C + I

Y = a + bY + I₀

Y - bY = a + I₀

Y(1 - b) = a + I₀

Y = (a + I₀) / (1 - b)

2. 投资-储蓄法（I = S法）

均衡条件：I = S

I₀ = -a + (1 - b)Y

(1 - b)Y = a + I₀

Y = (a + I₀) / (1 - b)（结果相同）

五、乘数效应

投资乘数（Investment Multiplier）：

k = ΔY / ΔI = 1 / (1 - MPC) = 1 / MPS

经济含义： 投资增加1单位，国民收入增加1/(1-MPC)单位。

举例： 若MPC = 0.8，则k = 1/(1-0.8) = 5。投资增加100亿，国民收入增加500亿。

贵州历年高频考点： 乘数的计算和应用是必考计算题！

【例题17.1】 已知消费函数C = 200 + 0.75Y，投资I = 100。

（1）求均衡国民收入

（2）求投资乘数

（3）若投资增加到150，求新的均衡国民收入

解：

（1）Y = C + I = 200 + 0.75Y + 100

Y - 0.75Y = 300

0.25Y = 300

Y = 1200

（2）k = 1 / (1 - 0.75) = 1 / 0.25 = 4

（3）ΔI = 150 - 100 = 50

ΔY = k × ΔI = 4 × 50 = 200

Y' = 1200 + 200 = 1400

验算：Y' = 200 + 0.75 × 1400 + 150 = 200 + 1050 + 150 = 1400 ✓

【下午：公共经济学——第7章 税收制度】

一、中国现行税收体系

中国现行税收体系以流转税和所得税为主体。

主要税种一览：

税种税率特点
增值税13%、9%、6%价外税，链条抵扣
消费税比例/定额特定消费品
企业所得税25%居民企业全球纳税
个人所得税3%-45%累进综合+分类征收
关税差别比例进出口商品

二、增值税

增值税（Value-Added Tax, VAT）： 对商品和服务流转过程中产生的增值额征收的流转税。

纳税人： 一般纳税人（可抵扣进项）和小规模纳税人（简易征收）

税率：

  • 13%：货物销售、加工修理修配
  • 9%：农产品、自来水、天然气、图书、房地产等
  • 6%：金融服务、现代服务业、生活服务
  • 小规模纳税人：3%（可减按1%征收）

应纳税额 = 销项税额 - 进项税额

销项税额 = 销售额 × 税率

进项税额 = 购进额 × 税率

贵州历年高频考点： 增值税的计算（销项、进项、应纳税额）是必考计算题！

【例题7.2】 某一般纳税人企业2023年5月销售额为200万元（不含税），购进原材料100万元（不含税），增值税税率均为13%。计算该企业应缴纳的增值税。

解：

销项税额 = 200 × 13% = 26（万元）

进项税额 = 100 × 13% = 13（万元）

应纳税额 = 26 - 13 = 13（万元）

三、消费税

消费税（Consumption Tax）： 对特定消费品在生产环节征收的流转税。

征税范围： 烟、酒、化妆品、贵重首饰、鞭炮焰火、成品油、汽车轮胎、摩托车、小汽车、高尔夫球及球具、高档手表、游艇、木制一次性筷子、实木地板

计税方式：

  • 从价计征： 应纳税额 = 销售额 × 比例税率
  • 从量计征： 应纳税额 = 销售数量 × 定额税率
  • 复合计征： 应纳税额 = 从价部分 + 从量部分（如白酒、卷烟）

【例题7.3】 某酒厂生产白酒，2023年5月销售白酒10吨，每吨不含税售价为50000元。白酒消费税率为20%加0.5元/500克（即1000元/吨）。计算该酒厂应缴纳的消费税。

解：

从价税 = 10 × 50000 × 20% = 100000（元）

从量税 = 10 × 1000 = 10000（元）

消费税总额 = 100000 + 10000 = 110000（元）

四、企业所得税

企业所得税（Corporate Income Tax）： 对企业生产经营所得征收的所得税。

税率： 25%（基本税率）

税收优惠：

  • 高新技术企业：15%
  • 小型微利企业：减按20%征收（有减免政策）
  • 研发费用加计扣除

应纳税所得额 = 收入总额 - 不征税收入 - 免税收入 - 各项扣除 - 以前年度亏损

应纳税额 = 应纳税所得额 × 税率

五、个人所得税

个人所得税（Individual Income Tax）： 对个人取得的各项所得征收的所得税。

综合所得（3%-45%超额累进税率）：

  • 工资薪金所得
  • 劳务报酬所得
  • 稿酬所得
  • 特许权使用费所得

分类所得（比例税率）：

  • 经营所得：5%-35%累进税率
  • 财产租赁所得：20%
  • 财产转让所得：20%
  • 利息、股息、红利所得：20%
  • 偶然所得：20%

免征额： 每月5000元（每年60000元）

计算公式：

应纳税所得额 = 税前收入 - 5000/月 - 专项扣除（三险一金）- 专项附加扣除

应纳税额 = 应纳税所得额 × 适用税率 - 速算扣除数

贵州历年高频考点： 个人所得税综合所得的计算（含专项附加扣除）是高频计算题。

【例题7.4】 某居民个人2023年全年工资收入为18万元，三险一金全年缴纳2.4万元，专项附加扣除全年为3.6万元。计算应纳个人所得税。

解：

应纳税所得额 = 180000 - 60000 - 24000 - 36000 = 60000（元）

查税率表：60000元适用10%税率，速算扣除数2520

应纳税额 = 60000 × 10% - 2520 = 6000 - 2520 = 3480（元）

六、关税

关税（Tariff）： 对进出关境的货物和物品征收的流转税。

税率类型： 最惠国税率、协定税率、特惠税率、普通税率

完税价格： 进口货物的到岸价格（CIF）

【今日练习题答案与解析】

经济学原理答案

1. C

解析：政府发放失业救济金属于转移支付，不是购买性支出，不计入GDP。政府购买（G）只包括购买商品和服务的支出。

2. C

解析：投资乘数 k = 1 / (1 - MPC) = 1 / (1 - 0.8) = 1/0.2 = 5。

3. C

解析：股票交易属于资产转移，不产生新的最终产品和服务，不计入GDP。二手房交易的中介费属于新创造的服务，计入GDP。

4. B

解析：在两部门经济中，总供给Y = C + S，总需求AD = C + I。均衡条件为Y = AD，即C + S = C + I，因此I = S。

5. C

解析：实际GDP增长率 ≈ [(1 + 名义增长率) / (1 + 物价增长率)] - 1

= (1.08 / 1.05) - 1 = 1.02857 - 1 = 0.02857 ≈ 2.86%

6. ACD

解析：投资I包括固定资产投资（企业购买新机器、居民购买新房）和存货投资（企业增加库存）。居民购买股票是金融投资，不属于GDP中的投资。政府购买办公设备属于政府购买G。

7. ABCDE

解析：国民收入核算的局限包括：未包括非市场交易、未反映收入分配、不考虑环境破坏、未反映闲暇价值、地下经济未计入等。这些局限使得GDP不能完全准确地衡量经济福利。

8. 答案要点：

名义GDP是按当年市场价格计算的最终产品和服务的市场价值，其变动既反映产量的变动，也反映价格的变动。

实际GDP是按基年（不变）价格计算的最终产品和服务的市场价值，其变动只反映产量的变动。

GDP平减指数 = (名义GDP / 实际GDP) × 100，是衡量整体物价水平的指标，反映了相对于基年物价水平的变动。

9. 计算过程：

（1）Y = C + I = 100 + 0.8Y + 200

Y - 0.8Y = 300

0.2Y = 300

Y = 1500

（2）投资乘数 k = 1 / (1 - 0.8) = 1 / 0.2 = 5

（3）ΔY = 2000 - 1500 = 500

ΔI = ΔY / k = 500 / 5 = 100

需要增加100单位的投资。

10. 答案要点：

（1）收入-支出法：均衡条件为总产出等于总需求。

Y = AD = C + I = a + bY + I₀

移项：Y - bY = a + I₀

(1 - b)Y = a + I₀

Y = (a + I₀) / (1 - b)

（2）投资-储蓄法：均衡条件为计划投资等于计划储蓄。

由C = a + bY，S = Y - C = -a + (1 - b)Y

I = S → I₀ = -a + (1 - b)Y

(1 - b)Y = a + I₀

Y = (a + I₀) / (1 - b)

两种方法得到的结果相同。图形上，45°线法（Y = AD）和I = S法都能找到均衡点。当收入低于均衡水平时，AD > Y或I > S，收入上升；当收入高于均衡水平时，AD < Y或I < S，收入下降。

公共经济学答案

1. B

解析：增值税一般纳税人应纳税额 = 销项税额 - 进项税额，体现了链条抵扣机制。A是销项税额的计算，不扣除进项会导致重复征税。

2. C

解析：服装不属于消费税的征税范围。消费税主要针对特定消费品如烟、酒、化妆品、贵重首饰、小汽车、高档手表等。

3. B

解析：企业所得税基本税率为25%。高新技术企业可享受15%的优惠税率，小型微利企业适用20%税率。

4. C

解析：个人所得税综合所得适用3%至45%的超额累进税率，最高边际税率为45%（对应年应纳税所得额超过96万元的部分）。

5. B

解析：价外税是指税金不包含在商品价格中的税。增值税是典型的价外税，发票上价款和税款分别列示。消费税是价内税，税金包含在价格中。

6. ABCE

解析：增值税税率包括13%（基本税率）、9%（低税率，适用于农产品等）、6%（适用于现代服务业等）、0%（出口货物）。3%是小规模纳税人的征收率，不是一般纳税人的税率。

7. ABCDE

解析：个人所得税专项附加扣除项目包括：子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、3岁以下婴幼儿照护七项。

8. 名词解释：

增值税（Value-Added Tax, VAT）是以商品和服务在流转过程中产生的增值额为计税依据而征收的一种流转税。增值税实行"道道征收、环环抵扣"的机制，即每个流转环节按销售额计算销项税额，同时扣除购进环节的进项税额，最终由消费者承担全部税款。增值税是中国第一大税种，具有避免重复征税、税负公平、征管高效等优点。

9. 答案要点：

增值税进项税额抵扣机制是指一般纳税人在计算应纳税额时，可以将购进货物或接受服务时支付的增值税（进项税额）从销售货物或提供服务收取的增值税（销项税额）中扣除，仅就增值部分缴纳税款。

这一机制的意义：

（1）避免重复征税：只对每个环节的增值额征税，避免了"税上加税"。

（2）税收中性：不影响企业的生产经营决策和产业组织形式。

（3）鼓励专业化分工：企业无需自给自足，可以专注于核心业务。

（4）便于税收征管：上下游企业互相监督，形成"以票控税"的链条机制。

（5）出口退税：便于准确计算出口退税，促进国际贸易。

10. 计算过程：

（1）应纳税所得额 = 240000 - 60000（免征额）- 36000（三险一金）- 48000（专项附加扣除）

= 240000 - 60000 - 36000 - 48000

= 96000（元）

（2）查税率表：96000元属于第二级（36000-144000元），适用10%税率，速算扣除数2520

应纳税额 = 96000 × 10% - 2520 = 9600 - 2520 = 7080（元）

所以该居民2023年应纳个人所得税为7080元。

【上午：经济学原理（中级）——第14-15章 一般均衡与市场失灵】

第14章 一般均衡理论

一、局部均衡与一般均衡

局部均衡分析（Partial Equilibrium Analysis）： 在研究某一市场时，假定其他市场不变，只考察该市场的供求关系。

一般均衡分析（General Equilibrium Analysis）： 同时考察所有市场的相互作用，研究整个经济体系的均衡状态。

关键区别： 局部均衡只考虑一个市场的独立均衡；一般均衡考虑所有市场之间的相互依赖关系。

二、一般均衡的存在性

瓦尔拉斯一般均衡（Walrasian General Equilibrium）：

瓦尔拉斯认为，在完全竞争市场中，存在一组价格使得所有市场同时达到均衡。

瓦尔拉斯定律（Walras' Law）： 如果 n-1 个市场达到均衡，则第 n 个市场也必然达到均衡。

公式：ΣPi × (Qi^d - Q_i^s) = 0

即所有市场的超额需求价值之和为零。

贵州历年高频考点： 瓦尔拉斯定律的含义常以选择题或名词解释出现。

三、艾奇沃斯盒式图（Edgeworth Box）

艾奇沃斯盒式图用于分析两个消费者在两种商品之间的交换均衡。

契约曲线（Contract Curve）： 所有帕累托最优点的连线。

交换的帕累托最优条件： MRS¹XY = MRS²XY（两个消费者的边际替代率相等）

生产的帕累托最优条件： MRTS¹LK = MRTS²LK（两个生产者的边际技术替代率相等）

生产和交换的帕累托最优条件： MRSXY = MRTXY（社会边际替代率等于边际转换率）

四、帕累托最优与福利经济学两大定理

帕累托最优（Pareto Optimality）： 没有任何一个人可以在不使其他人境况变差的情况下使自己的境况变好。

福利经济学第一定理： 完全竞争市场经济的一般均衡是帕累托最优的。

福利经济学第二定理： 任何帕累托最优状态都可以通过市场机制来实现，前提是初始禀赋的合理分配。

贵州历年高频考点： 帕累托最优的定义、福利经济学两大定理，常以简答题出现。

第15章 市场失灵

一、市场失灵的概念

市场失灵（Market Failure） 是指市场机制无法实现资源的有效配置。主要原因包括：外部性、公共物品、不完全竞争、信息不对称。

二、外部性（Externality）

外部性是指一个经济主体的行为对另一个经济主体产生影响，但没有通过价格机制反映出来。

  • 负外部性： 社会成本 > 私人成本（如污染）
  • 正外部性： 社会收益 > 私人收益（如教育）

科斯定理（Coase Theorem）： 当产权明确且交易成本为零时，无论初始产权如何分配，当事人之间的谈判都会导致资源配置的帕累托最优。

解决外部性的方法：

  • 庇古税/补贴： 对负外部性征税，对正外部性补贴
  • 产权界定： 明确产权归属
  • 政府管制： 直接规定排放标准
  • 可交易许可证： 发放排污权并允许交易
贵州历年高频考点： 外部性的分类、科斯定理、庇古税，常考简答题和案例分析。

【例题15.1】 某化工厂生产带来的边际私人成本为 MPC = 10 + 2Q，边际社会成本为 MSC = 20 + 2Q，市场需求为 P = 100 - Q。求：

（1）私人最优产量

（2）社会最优产量

（3）庇古税应为多少？

解：

（1）私人最优：MR = MPC

P = 100 - Q，TR = PQ = 100Q - Q²，MR = 100 - 2Q

100 - 2Q = 10 + 2Q

4Q = 90，Q = 22.5，P = 77.5

（2）社会最优：MR = MSC

100 - 2Q = 20 + 2Q

4Q = 80，Q = 20，P = 80

（3）庇古税 t = MSC - MPC = (20 + 2Q) - (10 + 2Q) = 10（单位）

或 t = 20时MSC - MPC的值：t = 10

三、公共物品（Public Goods）

公共物品具有两个特征：

  • 非竞争性（Non-rivalry）： 一个人消费不影响他人消费
  • 非排他性（Non-excludability）： 无法阻止他人消费

分类：

  • 纯公共物品：同时具备非竞争性和非排他性（国防、路灯）
  • 准公共物品：只具备其中一个特征（公路、教育）

搭便车问题（Free-rider Problem）： 由于非排他性，人们不愿为公共物品付费，导致市场供给不足。

贵州历年高频考点： 公共物品的特征及搭便车问题，常以选择题和名词解释出现。

四、不完全竞争

垄断导致价格高于边际成本，产量低于完全竞争水平，造成无谓损失（Deadweight Loss）。

自然垄断（Natural Monopoly）： 由于规模经济，一家企业生产比多家企业生产更有效率。

五、信息不对称（Asymmetric Information）

  • 逆向选择（Adverse Selection）： 交易前信息不对称导致"劣币驱逐良币"（柠檬市场）
  • 道德风险（Moral Hazard）： 交易后信息不对称导致一方改变行为

解决方法： 信号传递（Signaling）、信息甄别（Screening）、政府监管

贵州历年高频考点： 逆向选择和道德风险的区别，常考简答题。

【下午：公共经济学——第7章 公共收入理论·税收概论】

一、公共收入的概念与分类

公共收入（Public Revenue） 是指政府为满足公共支出需要而取得的财政收入。

主要来源：

  • 税收： 最主要的形式，占财政收入90%以上
  • 公债： 政府借款
  • 收费： 使用费、规费
  • 国有资产收益： 国企利润上缴

二、税收的基本概念

税收（Taxation） 是政府依法强制、无偿地取得财政收入的形式。

税收的特征： 强制性、无偿性、固定性

税制要素：

  • 纳税人： 直接负有纳税义务的单位和个人
  • 课税对象： 对什么征税
  • 税率： 税额占课税对象的比例
  • 比例税率： 同一比例（如增值税）
  • 累进税率： 税率随收入增加而上升（如个人所得税）
  • 累退税率： 税率随收入增加而下降
  • 税基： 计税依据
  • 起征点与免征额：
  • 起征点：达到后全额征税
  • 免征额：达到后只对超出部分征税

三、税收分类

  • 按课税对象：
  • 流转税： 增值税、消费税、关税
  • 所得税： 企业所得税、个人所得税
  • 财产税： 房产税、契税
  • 行为税： 印花税、城市维护建设税
  • 按税负转嫁：
  • 直接税： 税负不能转嫁（所得税、财产税）
  • 间接税： 税负可以转嫁（增值税、消费税）
  • 按收入级次：
  • 中央税
  • 地方税
  • 中央与地方共享税

四、税收原则

1. 亚当·斯密的税收四原则：

  • 平等原则
  • 确定原则
  • 便利原则
  • 最少征收费用原则（经济原则）

2. 现代税收原则：

  • 效率原则： 税收不扭曲资源配置，或扭曲最小
  • 公平原则：
  • 横向公平： 同等收入者纳同等税收
  • 纵向公平： 高收入者纳更多税收
  • 确实原则： 税收明确、稳定
  • 便利原则： 纳税程序简便
贵州历年高频考点： 亚当·斯密税收四原则、横向公平与纵向公平，常以简答题和名词解释出现。

五、税收负担与转嫁

税收负担率 = 税额 / 收入

拉弗曲线（Laffer Curve）： 描述税率与税收收入之间的关系。税率过高反而会减少税收收入。

![拉弗曲线：税率从0上升到100%，税收收入先升后降，存在一个最优税率t*]

税负转嫁（Tax Shifting）： 纳税人将税负转移给他人的过程。

  • 前转： 向消费者转嫁（提高售价）
  • 后转： 向生产者转嫁（压低进价）
  • 税收资本化： 资产价格中包含未来税负
贵州历年高频考点： 拉弗曲线的含义、税负转嫁方式，常考简答题。

【例题7.1】 某商品的需求弹性为1.5，供给弹性为0.5，政府对每单位商品征收10元消费税。计算消费者和生产者各自承担的税额。

解：

消费者承担的份额 = 供给弹性 / (需求弹性 + 供给弹性)

= 0.5 / (1.5 + 0.5) = 0.5/2 = 0.25

生产者承担的份额 = 需求弹性 / (需求弹性 + 供给弹性)

= 1.5 / (1.5 + 0.5) = 1.5/2 = 0.75

消费者承担税额 = 10 × 0.25 = 2.5（元）

生产者承担税额 = 10 × 0.75 = 7.5（元）

结论： 需求弹性越大，消费者承担的税负越少；供给弹性越大，生产者承担的税负越少。

经济学原理答案

1. B

解析：瓦尔拉斯定律指出，所有市场的超额需求价值之和为零。即 ΣPi × (Qi^d - Q_i^s) = 0。

2. C

解析：接种疫苗不仅使接种者受益，还降低了疾病传播风险，使他人受益，属于正外部性。ABD都属于负外部性。

3. B

解析：公共物品的两个基本特征是非竞争性（一个人消费不影响他人）和非排他性（无法阻止他人消费）。

4. C

解析：科斯定理指出，当产权明确且交易成本为零时，当事人之间可以通过谈判实现资源的帕累托最优配置，无需政府干预。

5. B

解析：逆向选择发生在交易之前，由于信息不对称，买方无法区分商品质量，导致"劣币驱逐良币"（柠檬市场）。道德风险发生在交易之后。

6. ABDE

解析：市场失灵的主要原因包括外部性、公共物品、不完全竞争（垄断）、信息不对称。完全竞争不是市场失灵的原因，而是理想状态。

7. ABCDE

解析：解决外部性的方法包括庇古税/补贴、产权界定、政府管制、可交易许可证、企业合并（将外部性内部化）。

8. 答案要点：

福利经济学第一定理：在完全竞争市场中，市场机制的自发作用能够实现资源的帕累托最优配置。即任何竞争性均衡都是帕累托有效的。

福利经济学第二定理：在适当的初始资源禀赋分配条件下，任何帕累托最优状态都可以通过市场机制来实现。即政府可以通过初始分配来实现公平，然后由市场来实现效率。

9. 计算过程：

（1）垄断均衡：

TR = PQ = (100 - Q)Q = 100Q - Q²

MR = dTR/dQ = 100 - 2Q

垄断条件：MR = MC

100 - 2Q = 20 + 2Q

4Q = 80，Qm = 20

Pm = 100 - 20 = 80

（2）完全竞争均衡：

P = MC

100 - Q = 20 + 2Q

3Q = 80，Qc = 26.67

Pc = 100 - 26.67 = 73.33

（3）无谓损失：

在完全竞争时，消费者剩余 = 0.5 × (100 - 73.33) × 26.67 = 355.56

在垄断时，消费者剩余 = 0.5 × (100 - 80) × 20 = 200

消费者剩余损失 = 200 - 355.56 = 155.56（绝对值）

或者用三角形面积计算无谓损失：

无谓损失 = 0.5 × (Pm - MC(Qm)) × (Qc - Qm)

= 0.5 × (80 - 60) × (26.67 - 20)

= 0.5 × 20 × 6.67

= 66.7

10. 答案要点：

外部性分为正外部性和负外部性。

（1）负外部性（如污染）：私人成本低于社会成本，导致产量过多。

纠正方法：征收庇古税、发放可交易排污许可证、政府直接管制、明确产权（科斯定理）。

（2）正外部性（如教育）：私人收益低于社会收益，导致产量过少。

纠正方法：给予政府补贴、政府直接提供、专利保护。

一般性解决思路：核心是使外部性内部化，即让产生外部性的主体承担全部成本或获得全部收益。

公共经济学答案

1. D

解析：税收的三个基本特征是强制性、无偿性和固定性。有偿性是政府收费的特征，不是税收的特征。

2. A

解析：拉弗曲线描述的是税率与税收收入之间的关系，表明税率过高时，税基萎缩，税收收入反而下降。

3. C

解析：直接税是指税负不能转嫁的税收，由纳税人直接承担，如个人所得税、企业所得税、财产税等。增值税、消费税、关税是间接税，税负可以转嫁给最终消费者。

4. B

解析：横向公平是指处于同等经济状况的人应缴纳相同的税收。纵向公平是指经济状况不同的人应缴纳不同的税收（高收入者多缴）。

5. B

解析：税负前转是指纳税人通过提高商品价格将税负转嫁给消费者。后转是指通过压低进货价格转嫁给供应商。税收资本化是指未来税负反映在资产现值中。

6. ABCE

解析：亚当·斯密在《国富论》中提出了税收四原则：平等原则、确定原则、便利原则和最少征收费用原则。效率原则是现代税收原则，而非斯密提出的。

7. ACDE

解析：按课税对象分类，税收分为流转税（增值税、消费税等）、所得税（企业/个人所得税）、财产税（房产税、契税等）和行为税（印花税等）。直接税/间接税是按税负转嫁分类。

8. 名词解释：

拉弗曲线（Laffer Curve）是由美国供给学派经济学家阿瑟·拉弗提出的，描述税率与税收收入之间关系的曲线。该曲线呈倒U形：当税率从0开始上升时，税收收入随之增加；但当税率超过某一最优点（最优税率）后，进一步提高税率反而导致税基萎缩，使税收收入下降。当税率为100%时，无人愿意工作或投资，税收收入降为零。拉弗曲线的政策含义是：降低税率不一定会减少税收收入，反而可能通过刺激经济增长来增加税收收入。

9. 答案要点：

税收的公平原则包括横向公平和纵向公平两个方面：

（1）横向公平：指处于同等经济状况（相同收入、相同财富）的人应缴纳相同的税收。要求税收制度对所有处于相同境况的人一视同仁。

（2）纵向公平：指经济状况不同的人应缴纳不同的税收，能力强者多纳税。纵向公平的实现方式包括：

  • 累进税率制度（收入越高，税率越高）
  • 差别待遇（不同来源的收入区别对待）

实现公平原则的途径包括：合理设置起征点和免征额、采用累进税率、完善税收优惠政策等。

10. 计算过程：

（1）消费者承担份额 = Es / (Ed + Es) = 1 / (2 + 1) = 1/3

生产者承担份额 = Ed / (Ed + Es) = 2 / (2 + 1) = 2/3

消费者承担税额 = 6 × 1/3 = 2（元）

生产者承担税额 = 6 × 2/3 = 4（元）

（2）当Ed = 0.5，Es = 1时：

消费者承担份额 = 1 / (0.5 + 1) = 1/1.5 = 2/3

生产者承担份额 = 0.5 / (0.5 + 1) = 0.5/1.5 = 1/3

消费者承担税额 = 6 × 2/3 = 4（元）

生产者承担税额 = 6 × 1/3 = 2（元）

结论： 当需求弹性变小（变得更缺乏弹性）时，消费者承担的税负份额增大。弹性越小的一方承担更多税负。
